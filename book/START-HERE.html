这套书从一个现实的人生问题出发：

当你没有标准答案、资源有限、也不知道自己最后能不能成功时，一个人究竟怎样找到值得做的事，并一步步把自己变成能做成它的人？

通过独立游戏作者的人生，你能看见谋生、学习、试错和作品被市场拒绝后的变化，也能读到成功之前的积累，以及没有完成的项目。公开故事能呈现这些路径，却不能告诉你它们在所有开发者中有多常见。

想读故事，可以从下面选一个和你现在最接近的问题；不用先熟悉研究编号。

如果你更愿意像读一本书一样顺序读，目前已经有七篇跨人物章节（第六篇是跨篇章专题）：

  1. 目标不是先想清楚的
  2. 先买几个月试错
  3. 失败不是资产
  4. 技术时代不会替你做选择
  5. 市场不是最后一步
  6. 你缺的真是一支团队吗？
  7. 第一次成功以后

完整章节目录见 Chapters。

如果你更关心“像我这种处境，现在下一步应该先动什么？”，优先进入：

按你的处境进入｜先判断你现在缺的到底是什么

这个入口先问三件事： - 你已经会做什么； - 生活和家庭负担允许你试多久，退出后有什么退路； - 这次该调整项目、补能力、找伙伴、筹资金，还是改变投入程度。

如果你已经确定自己属于某种具体的人生转型处境，还可以进入 Life Risk Routes。例如：LR-001 — 名校 / 大厂高绩效者转作者型独立 专门研究能力迁移、旧评价函数、家庭与退出约束。

如果你只是想找“和我能力结构相近的人先看谁”，再进入：

按主创者能力进入｜你手里已经有什么？

技术美术、程序、策划与评论、游戏修改与服务器运营、大厂转作者、独自承担多种工作，都能找到不同的历史对照。职业相近也要继续比较实际能力与处境。

我现在根本不知道自己以后要做什么

先读跨人物章节：

  • 目标不是先想清楚的：先做一点，现实才开始回答你是谁

再读人物全文：

  • early id / DOOM
  • Gunpoint / Tom Francis

Romero、Carmack和Tom Francis走过不同的学习与职业路径。读这两篇，可以追问：玩、拆解、写作、制作、发表和外部反馈，怎样让目标逐渐具体？这些行动不构成人人必经的顺序，也不能从后来成功倒推出他们从小就知道终点。

本节关心的是：人在做过一些事情、看见现实回应之后，怎样判断是否值得投入更多人生。

我喜欢游戏、技术、写作或别的东西，但不知道这算不算“正事”

先读：

  • early id / DOOM
  • Gunpoint / Tom Francis

兴趣怎样转成能被检验的作品？ 下面是一条可能的路径：

喜欢
→ 比较
→ 拆解
→ 修改
→ 做出东西
→ 给陌生人看
→ 被现实反馈
→ 再修改

爱好可以只是娱乐。若开始比较、拆解和制作，再拿作品接受外部反馈，它就可能逐渐带来能力、作品集、判断力、合作者或职业入口；这条转换并不保证成功。

我从来没做过任何作品，甚至不知道兴趣算不算一个值得追的目标

那不意味着你需要立刻创业，或者必须证明自己被教育耽误了。也可能是过去缺少可以自己安排的时间、设备、陪你练习的人，或者你确实更喜欢当观众而不是作者。

先读第一章：目标怎样在作品和反馈中形成。这里的 Romero、梁其伟、Tom Francis 并不是规定你该模仿的成功范本；他们说明的是，兴趣如果从没获得工具、尝试和回应，便很难变成一个可以选择的方向。想看更系统的教育/家庭研究与尚未解决的分母问题，可进入中国037。

对还没开始的人，下一步可能只是一项不公开的小实验：选一个自己在乎的问题，做一点东西，看看实际结果，并允许自己决定不继续。第一次尝试不需要承担整个人生的回报义务。

我喜欢游戏，但家里不让我玩，也不相信做游戏是正经工作

可以从这几段经历读起：

  • early id / DOOM：Romero 的家庭冲突、继父买电脑与职业形成；
  • 第一章：目标不是先想清楚的。
  • 梁其伟与《雨血》 — 母亲保存了留存的童年画稿；2007年挂科、失去保研资格后，家庭压力又使制作暂停一年，2008年重新开工。研究也保留部分早年画作被毁的经历。

有些家庭反对的是玩游戏占用学习时间，却欢迎学习编程、画画和写作；有些家庭允许游戏和作品，但不愿让你承担无保障的职业风险；也有家庭不理解，却尊重成年人的选择。它们对应完全不同的问题，不能只归结为“家长不支持”。

能否接触作品、亲自动手、公开获得反馈，以及成年后能否选择职业，需要分别看。和家人发生冲突，不能证明作品会成功；准备转行时，工资、存款、住所、照护和再就业退路仍要算清楚。成年人仍有权决定自己的生活，即使作品没有成功、家人也未认可。

想进一步研究家庭控制如何让一部分潜在创作者还没入行便从样本里消失，进入 中美代际与家庭门控研究。那里也保留支持/失败的反例和历史时效限制。

家人后来终于认可了我的选择，过去的冲突就算结束了吗？

early id人物传记 保留了一条家庭变化线。按Kushner多年后写成的《DOOM启世录》，Romero的继父曾因他玩街机施暴；到1993年前后，在游戏事业已有成绩时，继父承认早年的职业判断错了，1999年又在外界争论中维护他的作品。Carmack母亲后来也会玩《Commander Keen》。这些是书中记述，不能当作同期录音。

职业判断的道歉，不等于过去的伤害已经获得完整道歉。 Romero在2025年采访中说，自己会和孩子一起玩游戏、采用不同的养育方式；这是他的自述，也不能代替孩子对关系的评价。想沿这条线继续读，可看家庭代际和解研究032，其中梁其伟的对照只记录已知态度变化，没有补写最终和解。

另外两条路径没有这样的结尾：2011年Croshaw已有游戏评论声望，却说父母仍不认可他的工作；Keith Judge得到配偶工资与储蓄支持，独立项目仍未完成，后来回到专业就业。两例见研究035。认可、实际出资和作品完成，会各自发生变化。

李远扬2017年说，家人从管束他玩游戏，转而支持他制作游戏。到2019年，《纽扣兄弟》经历数次发行仍未回本，他说家里没有施加太大压力。这里的家庭态度由他转述，不能写成家属共同受访的结论，也没有证据说明他们承诺无限填补亏损。详见《项目没有回本，家人也没有收回尊重》036。

美国开发者Gianfranco Berardi则在2010年辞职，约2012年恢复受雇工作。2013年写反思时，他转述妻子对那两年尝试的肯定。到首次全职独立十五年后的2025年，他仍未能第二次全职独立，却继续兼职开发、发售小作品，每年为自己的游戏留出一天“Indie Day”。重返工作以后，创作并没有从生活里消失；2013年的配偶支持也不能自动延伸为2025年同意再次辞职。

新加坡Joysteak的认可变化发生得更早。制作人2019年6月说，父母看见他与伙伴长期在家工作，逐渐支持制作；当时已有专业奖项和发行合作，游戏尚未正式发售。发售后工资仍不足的说法，目前仅见2019年9月采访的搜索索引摘录，正文尚未完整读取，不能据此判断后来的总收入。Joysteak与Berardi的后续详见研究037。这些公开经历让人看见获准创作、承担账单和继续谋生的不同安排，不能回答多少家庭会如此选择。

我很想辞职做自己的东西，但怕一押就是几年

先读跨人物章节：

  • 先买几个月试错：做自己的事之前，先解决谁替你付时间

再读人物全文：

  • FTL
  • early id / DOOM

Kickstarter之前，FTL的两位创作者已有职业经验，先用储蓄留出几个月做小项目，再将原型送去比赛；正面反馈促使他们尝试商业产品。early id则在Softdisk工作期间利用夜晚和周末制作《Commander Keen》，收入让全职独立成为可行选择，离职后仍有履约义务。

两组人承担风险的方式不同，却都让下一步承诺有了具体依据。阅读时可以继续问：哪些问题能先用较小的代价试出来？

不要为了证明决心，主动把一个本来可以便宜失败的问题变成昂贵失败。

我没有很多钱，甚至必须一边活着一边做

先读跨人物章节：

  • 先买几个月试错

再读人物全文：

  • Kenshi
  • Rocket League
  • FTL

三条路线完全不同：

  • Chris Hunt 用夜班工资购买个人开发时间；
  • Psyonix 为其他工作室承接合同，支付公司账单并保留一部分原创制作；
  • FTL 两位创作者先用储蓄购买一个有限实验窗口。

工资、客户合同和储蓄，给三者提供了不同的生存安排。比较这些故事时，要问清楚：谁在支付继续试错的时间，能付多久？ 玩家收入也可能在后续改变这个安排，只问有没有一次融资，无法说明项目怎样持续。

我想做的游戏已经有方向，但团队缺关键能力

你现在可能正在犹豫：自己学、先删内容、找外包、招一个专业负责人、给合伙人股权，还是融资？

先别把“有清楚的作者愿景”误当成“玩家已经验证了它”。

先读人物故事与代价：你缺的真是一支团队吗？有时应该换掉的，是游戏的做法。

想先跟随创始人的完整生活和职业故事，可读 Nomada / GRIS 与 David Wehle / The First Tree。

需要真正决定缩项目、学习、外包、合伙、招聘或融资时，再进入 LR-004：作品方向已经明确，但团队做不出来。

这里用《Gunpoint》《The First Tree》《GRIS》《The Witness》《Outer Wilds》《The Talos Principle》与《Playdead》《The Magic Circle》《Limit Theory》等正反生产史，回答同一个问题：什么证据值得付哪一级承诺成本？

另有两段更不浪漫的制作经历：加拿大Giguère首两作昂贵学费与越南SOGA夫妻二次尝试。前者有13年程序员经历与家人朋友支持，2017年两部作品发售后仍只收回相对多年制作投入很少的钱；后者据2025回忆，母亲在首作失败后鼓励继续，妻子是第二作美术、文本和社区共同作者，二作后来进入EA并获得初步销量。第二个故事因为后来成功才被我们看到，不可冒充一般失败者。

若想知道一个公开尝试到底能观察多少普通人、为什么大量没入场的人仍不可见，以及GGJ旧作品即将受到哪些档案政策影响，读038 参与者／作品／自愿调查答卷的分母审计。

我已经失败很多次了，是不是说明我不适合做这件事

先读跨人物章节：

  • 失败不是资产：只有留下下一次还能使用的东西，失败才开始值钱

再读人物全文：

  • Bills Must Be Paid
  • Rocket League
  • Josh Parnell / Limit Theory — 项目取消不等于能力消失，也不能将技术残值当作交付。
  • Question / The Magic Circle → The Blackout Club — 首作销售不够，工作室却没有消失；下一作为什么改变市场入口。

失败以后留下了什么，下一次还能不能使用？ 可以检查：

  • 更快的制作能力；
  • 一个工具；
  • 一段代码；
  • 对某个平台的知识；
  • 对某种用户反应的判断；
  • 一个以后还能重新做的问题；
  • 也可能什么都没留下。

据Rike团队复盘，《Bills Must Be Paid》本作制作约七个月；两人从2019年开始的约七年共同实践，还包括原型、未成功的作品、发行商合同与平台学习。把这些经历放回去，才能区分本作制作时间和能力积累时间。《Rocket League》的团队则早在2008年就发售过“汽车踢球”的前作；第一次没有得到后来的商业结果，玩法与团队学习仍进入了后续迭代。这些前史有可使用的部分，不等于每次失败都会留下资产，更不能保证下一作成功。

这些毕竟都是后来被媒体看见的人物。想看没有成名、只做过小作品的公开经验，还可以阅读 Week Sauce 2022.04 的18个普通参赛项目，以及 2026年18个投稿账号的公开后续回访：有人仅做了两天，有人因生活事务来不及改 Bug，有人明确不知道会不会继续，有人后来真的做出了更完整版本。这18个项目不是独立游戏行业成功率的统计分母。

我总觉得别人有了新技术就无所不能，而自己是不是已经晚了

先读跨人物章节：

  • 技术时代不会替你做选择：有人用现成工具，有人重组平台，有人自己造出窗口

再深入：

  • early id / DOOM
  • Gunpoint / Tom Francis
  • PLAYERUNKNOWN / Brendan Greene 研究档案
  • 工业革命比较实验室

回顾early id时，Carmack谈到团队一边推进渲染与引擎技术，一边围绕实际做到的能力重新设计游戏；想要的体验也会反过来推动技术。DOOM的技术窗口有他们主动创造的部分。读到这里，可以区分三种技术位置：

  • 有人继承已经扩散的工具；
  • 有人把已有技术重新组合成新用途；
  • 有人自己把技术边界向前推，给团队创造新窗口。

判断自己是否错过机会时，可以问：它具体把什么变便宜了？谁真正能用？谁看见了新的可能？谁甚至亲手创造了那个可能？

我做出来的东西明明不差，但不知道什么时候让市场进来

先读：

  • 市场不是最后一步：有时玩家、钱和反馈在“做完之前”就已经进入生产系统

再深入： - Minecraft - Factorio - Bills Must Be Paid - Brigador

这一组还可加入 Question / The Magic Circle：当期有行业声望与 IGF 提名，也不等于品类易于理解或收入足以支持组织。

有曝光，不等于市场接口有效；市场越早进入，也不等于越好。

带着一个具体问题去读：我现在最怕判断错什么？需要的是玩法反馈、需求规模、产品可理解性，还是继续制作的资金？

而且这些方法高度依赖年份。2009 Minecraft、2013 Factorio、2016 Brigador、2026 Bills Must Be Paid 处在完全不同的平台环境里。

我已经成功过一次，为什么事情反而越来越复杂

先读：第一次成功以后：钱可以买时间，也会把新的工作交给你。

先看下一步需要什么：

我需要补足哪些能力，又希望保留哪些暂不承诺的选择？

补读： - Into the Breach / Subset Games — FTL收入给小团队留下长期试原型和延迟公开的空间，他们选择做不同的游戏，并在后续加入专门协作者； - thatgamecompany — 股权融资支持扩充开发与自发行能力；投资者加入董事会，后续筹资也占用创始人的制作时间，具体条款仍需另核； - Zachtronics + Spiderweb Software — 工具、品牌与受众长期积累以后，改做不同游戏的成本会怎样变化。

先读：

  • early id / DOOM
  • Rocket League

成功后的钱与选择权可以用来维持小规模、扩大组织，也可以为不同作品留出探索时间；扩张还可能提高固定成本和协调要求。early id从DOOM走到Quake，技术与商业成绩没有替团队解决下一阶段的协调问题。读这些后续人生，仍要问：我们以后究竟要成为什么，要为此承担哪些新的成本？

读过这些经历，可以留下的八个判断

  1. 目标常常是做出来的，不是先想出来的。
  2. 兴趣只有发生转换，才会变成能力资本。
  3. 活下来本身是一项生产策略。
  4. 失败值不值钱，要看它有没有留下下一次还能使用的东西。
  5. 技术既可以被继承，也可以被重组，甚至可以被创作者自己向前推进。
  6. 市场不是最后一步；它可能很早就开始提供钱、反馈、误导和约束。
  7. 任何成功经验都有年份；机制可能耐久，具体平台打法会过期。
  8. 成功不是证明你找到了终极答案，而是给你换了一套更难的问题。
