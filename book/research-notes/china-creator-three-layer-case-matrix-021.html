0. 目的：从“观点”升级为“对照系统”

三层框架现在已经有：

  • 018：结构；
  • 019：正向/混合人物压力测试；
  • 020：失败压力测试。

但还缺一个长期可维护的“病例表”。

本文件固定三个原则：

  1. 每一层都必须同时有正向、失败、混合样本；
  2. 每一个中国机制都尽量找跨国对照，防止把全球组织问题误写成中国性格；
  3. 一个案例可以进入多个格，但必须说明它在每一格承担什么不同证据功能。

1.4 中国内部制度反例：DeepSeek把“人才能力”与“组织授权”拆开

新增 014 梁文锋 / DeepSeek。其2023/24创始人访谈显示：本土年轻人才、自下而上选题、idea早期较低资源审批门槛、潜力出现后集中资源，以及明确反对只做follow。此案例只能证明中国内部存在能够释放前沿问题所有权的组织可能性，不能证明教育/家庭/产业约束不存在。它把三层框架进一步拆成：基础能力形成 → 问题提出训练 → 毕业后problem ownership。

正式新增四个组织字段：RESOURCE_ACCESS_BEFORE_GREENLIGHT / AFFORDABLE_FAILURE_CAPACITY / FRONTIER_PROBLEM_OWNERSHIP / FIRSTHAND_ROADMAP_ACCESS。以后NExT、Supercell、id、Game Science及中国大厂组织案例尽量按同字段编码。

1.5 产业层新增可量化压力：完整团队密度，而非单个成功者数量

新增 012 将“为什么中国前沿IP可选成熟团队仍显得少”拆为可证伪命题。2025-07 Steam Top200愿望单国别快照：中国8、韩国10、波兰12、瑞典14.75；配合各国active studios/员工统计，只允许写为全球premium高关注产品管线代理，不能写为民族创造力或真实作者型团队比例。下一步目标变量固定为 FULL_CYCLE_TEAM_DENSITY 与 SECOND_ATTEMPT_CAPACITY。

1.6 日本对中国框架新增：不要只测作者数量，要测“堵路以后还有几条路”

Japan 004提出 CREATOR_ROUTE_REDUNDANCY / ROUTE_SWITCHABILITY / CAPABILITY_SPILLOVER。日本案例显示：公司内部作者化、雇员side project、同人自出版、doujin→商业、老兵离职创业、跨行业创业、publisher/event桥梁可并存。中国后续应同字段检查：潜在创作者在第一条正规路径被否后，是否仍有低成本第二/第三生产路线；不要把“存在Steam/比赛/大厂岗位”机械等同完整生态。

二、教育层矩阵：不是“谁更自由”，而是谁能把学习变成判断

A. 正向样本 1｜王妙一 / WILL

为什么放这里

019 已确认：

  • 清华软件 / 美院双学位；
  • 网易技术岗位；
  • 长期自发游戏兴趣；
  • 离开标准职业路径后仍保持明确作者性；
  • 根据“会什么 / 不会什么 / 有多少钱”反向设计项目。

机制

Formal Education Capital
+
Extracurricular Taste Formation
+
Self-directed Intake
+
Artifact Production
→
Problem Ownership survives standard success

它反驳什么

反驳：

“好学生 / 名校 / 大厂会自动消灭原创。”

它支持什么

支持：

标准训练与问题主权可以共存；真正需要追踪的是评分器之外是否存在独立兴趣、比较和作品循环。

B. 正向样本 2｜Tom Francis / Gunpoint

参见： - cases/CASE-007-gunpoint.md - book/profiles/gunpoint.md

为什么重要

Francis 没有传统开发训练，但有约九年专业游戏评论/比较经验。

他的形成路径不是：

没受正规训练 → 更自由 → 成功

而是：

大量比较作品
→ 能显式说出喜欢/讨厌什么
→ 将批评翻译为可测试规则
→ GameMaker 降低 prototype 成本
→ tester / devlog / market feedback
→ 修改判断

教育层意义

它说明一个人可以通过职业评论、长期消费、公开写作形成：

非学校型但高度结构化的 Design Education。

不是“外行优势”。

而是：

他已经完成了一套非常严密的自主课程。

C. 正向样本 3｜David Wehle / The First Tree

参见： - cases/CASE-042-the-first-tree.md

为什么重要

Wehle 不是“不会编程的普通人突然成功”。

已有：

  • Media Arts；
  • video engineering / editing / color；
  • interactive design；
  • Unity technical art；
  • 前作 shipping 经验。

真正值得记录的是：

他的教育/职业能力并不覆盖“大型传统游戏开发全部能力”，但他没有把短板当成必须补齐的职业羞耻，而是把产品改造成强项能够直接决定价值的形状。

教育层意义

能力偏科
→
不是补成平均人
→
而是找到适合偏科的产品

这应成为 Creator–Project Fit 的核心教育反例。

D. 失败样本｜飞翔的子明

参见： - china-creator-three-layer-failure-pressure-tests-020.md

已有

  • 技术能力；
  • 自主学习；
  • Game Jam；
  • 自己做项目；
  • 非标准路径。

失败暴露

  • 设计能力浅；
  • 体验定义弱；
  • “技术先行”；
  • 试玩者不理解；
  • scope 超出单人能力。

教育层结论

Learning Agency 不是 Design Judgment。

所以教育层至少必须编码四个变量：

  1. Self-directed Learning；
  2. Taste / Design Judgment；
  3. Validation Literacy；
  4. Scope Judgment。

E. 混合样本｜Stardew Valley / Eric Barone

参见： - cases/CASE-004-stardew-valley.md

为什么是混合，而不是简单成功

Barone：

  • CS 毕业；
  • 找工作受挫；
  • 最初把游戏作为学习 C# / 增强就业能力的项目；
  • 开发过程中反复重做美术、音乐、设计；
  • 最终成长为强 solo generalist。

这里出现一种不同教育模式：

Project-as-Education。

不是先学完再做。

而是：

想做项目
→
暴露能力缺口
→
为了项目学习
→
新能力反过来改变项目

但风险也很大

  • 四年以上；
  • 伴侣收入 + 兼职支撑；
  • 大量重做；
  • 高 sunk-time。

所以不能写成：

“边做边学总比系统学习好。”

只能说：

项目可以成为高强度学习环境，但前提是有异常长的 runway 与持续现实反馈。

F. 中国升学/家庭耦合的纵向 near-miss｜梁其伟 /《雨血》（2006–2010）

作为 research note 030 纳入教育—社会规范交叉格，不新增编编号 Case：

  • 真实的生产起点：先有多年绘画、设定写作，2006年RPG Maker使其转化为游戏；2007已有可玩版本。
  • 真实的制度冲突：第一份项目占用课程，挂科并按本人2014年自述失去保研资格；父母/导师/伴侣关系共同施压，2007夏至2008夏中止制作。
  • 同一个家庭并不一致：2016记者采访补证其少年某些漫画/手绘曾被家人毁弃，成年后母亲保存幸存的画册；不能把该家庭写成一贯压制或一贯保护创造。
  • 替代接入：2008留学后的同学/教授反馈及多学科创作环境给作品不同评价，2010 VeryCD/海外数字渠道提供真实玩家和商业信号；但留学成本、家庭财务、学校与导师第二方叙述未核。
  • 样本选择：这是媒体可见的成功后的 near-miss；不能证明多数没能出发的人命运或“出国才能创作”。

与王妙一（持续的游戏接触许可）、茄子（家庭不理解但允许、现金不足导致成员退出）组合，形成三种可比的 Normative Permission × Actual Academic Cost × Economic Runway × Artifacts Available，但样本仍为定向机制案例，不能计算国别/家长平均值。

招生层级反证：张兆弓2022 指游戏设计专业的入学生已预先过家庭沟通门槛，家长坚决反对但未申报者不在招生结果内。真实分母需参见 Frame D / pre-entry cohort。

三、行业版本现状矩阵：谁真正完成了“换题”

A. 正向样本 1｜Game Science

参见： - china-capability-repricing-black-myth-sultan-013.md

Formative regime

  • 腾讯 PC MMO /《斗战神》；
  • 后进入手游阶段；
  • 《百将行》取得商业现金流。

关键转折

团队没有把手游时期的成功模板继续当终点。

冯骥后来公开反思《百将行》接近成熟市场模板，不能形成长期独特性。

于是：

PC MMO team capital
+
mobile commercial survival
→
reject template-only answer space
→
large premium single-player

行业层意义

旧生产制度不一定只留下包袱；它也可能留下可以被新市场重新定价的 team capital。

但前提是：

objective function 能被重写。

B. 正向样本 2｜Double Cross / 《苏丹的游戏》

参见： - cases/CASE-038-sultans-game.md - china-capability-repricing-black-myth-sultan-013.md

关键结构

旧商业手游组织缩编以后：

  • 核心老兵保留；
  • 原商业项目组织方式被主动放松；
  • 已有小说 / 叙事 reserve 获得产品权；
  • 团队按剩余能力重构 scope；
  • demo / wishlist 提供 pre-launch reality signal。

行业层意义

这是：

Capability Repricing + Ownership Reconfiguration

不是：

“商业手游人突然觉醒。”

真正发生的是：

同样的人，在新的收入接口和更小组织里获得了不同的问题定义权。

C. 正向样本 3｜《枪火重生》

参见： - cases/CASE-039-gunfire-reborn.md - gunfire-tripwire-production-fundamentals-012.md

已确认

T9 credits 跨：

  • Producer / Director；
  • Game Designer；
  • Level Designer。

产品本身：

  • 单人可成立；
  • 4 人 coop；
  • roguelite/build 提高内容复用；
  • Early Access 早获付费玩家反馈；
  • premium 模式降低纯 PvP liquidity risk。

行业层意义

Product Ownership 离实现更近 + 商业模式适配团队能力 + 反馈早进入。

这是一种生产函数正例。

D. 跨国正向控制｜Tripwire

参见： - cases/CASE-040-tripwire-lineage.md - gunfire-tripwire-production-fundamentals-012.md

Validation Ladder

mod
→ community
→ competition
→ Epic feedback
→ prize / engine license
→ company
→ commercial release

后来 Killing Floor / Rising Storm 又重复：

外部低成本探索 → 先证明 → 再吸收工业化。

为什么它对“中国问题”重要

因为它证明：

validation-first 不是“中国年轻开发者应该学西方自由文化”。

而是：

一种具体生产制度。

E. 失败样本 1｜月下 /《铸仙之境》

参见： - china-commercial-game-training-role-origin-audit-006-tencent-producer-pressure-test.md - china-creator-three-layer-failure-pressure-tests-020.md

核心：

Exit from Organization ≠ Exit from Evaluation Function

有：

  • 腾讯制作经验；
  • 大额投资；
  • 31 人团队；
  • 多轮重大改版。

但创始人自己最终说：

创业最大的收获是不要有“乙方心态”。

行业层意义

换公司并不等于换 production regime。

F. 失败样本 2｜SYNCED / NExT

参见： - cases/CASE-041-next-synced.md - next-studios-portfolio-efficiency-audit-014.md - china-production-fundamentals-four-case-matrix-011.md

已确认问题

  • 目标持续变化；
  • 团队不断扩大；
  • 项目同时承担产品探索、AAA pipeline 练兵、组织升级和商业成功；
  • 内容/音频/资产义务极大；
  • 最终停运。

行业层意义

大组织完全可以拥有创新意图，却因为错误的资源升级顺序让探索成本越来越高。

不能写成：

NExT 不创新。

应写成：

创新制度如果不能让错误便宜地死，资源反而会提高 pivot cost。

G. 失败样本 3｜Boundary

参见： - cases/CASE-029-boundary.md - china-production-fundamentals-four-case-matrix-011.md

已确认

  • 零重力 FPS hook 成立；
  • China Hero Project；
  • 技术野心高；
  • 首日销量有兴趣证明；
  • 但纯 PvP liquidity、内容义务、长期开发、项目核心问题漂移等风险长期累积。

制作人后期自己承认：

  • 应该更早把核心流程完整跑通；
  • 小团队首作直接选 PvP 太空题材风险过高；
  • 后来不会再这样启动。

行业层意义

Market Hook ≠ Sustainable Product System。

H. 混合样本｜Sea /《安尼姆的无尽旅途》

参见： - china-commercial-game-training-role-origin-audit-006-tencent-producer-pressure-test.md

为什么是混合

Sea：

  • 腾讯魔方长期成熟制作人；
  • 离职后主动做不大众的高痛感玩法；
  • 但商业模式仍按熟悉手游逻辑开始；
  • 后来明确承认“大厂工作惯性”；
  • 再把新项目改成 1–2 人先做核心 Demo，证据足够才加人。

行业层意义

这是最适合研究：

Deliberate Unlearning

的中国案例之一。

它不是一开始就换挡成功。

而是：

通过一次昂贵失配，学会如何换挡。

四、社会版本意识 / 生存期矩阵：谁允许你活到验证

A. 正向样本 1｜Stardew Valley

参见： - cases/CASE-004-stardew-valley.md

隐藏生产条件

  • 本人影院兼职；
  • 与伴侣共同生活；
  • 很大程度依赖伴侣研究生 stipend / 校内收入；
  • 四年以上开发。

社会层意义

这不是：

“靠女友养成神作。”

而是：

伴侣关系把一个极长、极低即时回报的探索窗口变成物质上可能。

这里应编码：

  • household income；
  • shared risk；
  • low-status exploration tolerance。

B. 正向样本 2｜Hollow Knight

参见： - cases/CASE-015-hollow-knight.md

隐藏条件

  • Gibson 之前动画业务储蓄；
  • Pellen 的伴侣全职工作；
  • 另一核心程序员的伴侣也全职工作；
  • Adelaide 较低生活成本；
  • Kickstarter；
  • 后续 Indie Fund。

社会层意义

“AU$57k 做出 Hollow Knight”完全忽略了 household runway。

同一项目预算在不同家庭结构和城市成本下不是同一个生产条件。

C. 正向样本 3｜Gunpoint

参见： - cases/CASE-007-gunpoint.md

Runway

  • PC Gamer 工资；
  • 业余开发；
  • 三年逐步验证；
  • 达到预设销售阈值后才辞职。

社会层意义

正常职业可以成为 legitimacy shield 与 runway，而不是创作的反面。

这对“必须辞职证明决心”的独立游戏神话是直接反例。

D. 正向样本 4｜FTL

参见： - cases/CASE-001-ftl.md - book/profiles/ftl.md

FTL 的关键结构是：

先小规模、低预期项目 → competition / China IGF → 媒体 / 玩家验证 → Kickstarter → 承诺等级提高

社会层价值不在“家人支持”单一变量，而在：

外部 legitimacy 是逐级获得的。

创作者不必第一天就要求社会相信一个未经验证的大愿景。

E. 失败 / 混合样本｜《太吾绘卷》

参见： - china-creator-three-layer-pressure-tests-019.md

已确认

  • 家庭不理解但支持；
  • Normative Permission 较高；
  • 但团队长期无薪；
  • 程序员因经济压力退出。

社会层意义

Normative Permission ≠ Economic Runway。

这已经是三层框架的固定边界。

F. 失败压力｜《重装前哨》

参见： - cases/CASE-030-outpost-infinity-siege.md - china-creator-three-layer-failure-pressure-tests-020.md

已确认

首发失败后：

  • 投资方没有立即放弃；
  • 团队继续获得修复和更新空间。

但失败原因仍包括：

  • 玩家预期错位；
  • 技术稳定性不足；
  • 商业化目标干扰设计；
  • 团队扩大后 founder management model 失配。

社会层意义

Support is not validation。

宽容失败的意义只是：

允许继续学习。

不是：

失败自动是创新。

五、一个更准确的“英雄出发条件矩阵”

目前最稳的不是三层加法，而是六个变量同时存在：

变量 缺失后的典型风险 正向案例 失败压力
Problem Ownership 永远解别人出的题 王妙一、Gunpoint 月下早期 founder mode
Design Judgment / Taste 自由地做坏题 Gunpoint 飞翔的子明
Cheap Prototype 错误太晚暴露 Tripwire、Gunfire SYNCED、Boundary
Reality Adjudication 自嗨 / error persistence Gunpoint、FTL、EA Outpost 首发问题
Survival Time 来不及验证 Stardew、HK、Gunpoint 太吾程序员退出
Capability Scaling 永远只能手搓 Game Science、Double Cross 小团队 scope failure

因此：

原创并不是“敢想”。

而是：

敢自己出题
+
有能力判断
+
能便宜做出来
+
让现实尽早判卷
+
活得到下一轮
+
最后还能把成立的东西做大

六、每一层真正该如何写给读者

教育篇不能写

学校把你教坏了。

应该写：

如果明天没有考试、老板、教程和 benchmark，你还知道下一步该验证什么吗？

读者自测

  • 过去一年有没有一个完全没人要求你学的东西？
  • 有没有把它做成 artifact？
  • 有没有陌生人使用？
  • 别人不理解时，你会解释，还是会改？
  • 你能否区分“实现难”与“体验不成立”？

行业篇不能写

大厂经验没用。

应该写：

你的职业经验里，哪些是能力资本，哪些只是上一版本的评价函数？

读者自测

  • 我离开原公司后，第一反应还是找“老板/投资人想要什么”吗？
  • 我能直接接触玩家吗？
  • 我提出 feature 时知道实现成本吗？
  • 我会不会在核心 loop 没成立前就加人？
  • 我有没有一个可以杀掉自己的核心假设的测试？

社会篇不能写

父母不懂年轻人。

应该写：

当你还没有结果时，谁在支付你偏离标准路线的成本？

读者自测

  • 我的 runway 是工资、储蓄、伴侣收入还是父母住房？
  • 这些支持是明确的吗？
  • 我有没有把别人的无薪劳动当成“共同理想”？
  • 我失败后能不能回到就业市场？
  • 我的家人是反对项目，还是只是反对无限期无收入？

七、目前最值得补的空格

矩阵已经能工作，但仍有三个明显缺口。

1. 教育层原缺口已由 Limit Theory 显著补强

参见 CASE-054-limit-theory-fit-trap.md 与 china-creator-three-layer-missing-cells-022.md。

Josh Parnell 同时具备高教育资本、高自主性、强工程能力、长期公开开发与市场兴趣，却仍因 FIT-TRAP / product closure 失败取消项目。

因此“自由→创新”的强反压力已经存在。后续重点不再是继续找同型案例，而是比较：

  • Capability Capture Risk；
  • specialist frontier 与 product frontier 是否脱节；
  • prototype/community feedback 为什么没有及时迫使产品收敛。

1.5 新增“家里支持、行业仍失利”的中国例｜李远扬《纽扣兄弟》

036 中国李远扬与美国Berardi：商业失败后家庭许可不必撤销 补齐了社会规范 正向许可以后 仍遭遇行业/市场失败的交叉格。

2017一手访谈： 李远扬小时候被家长约束偷偷玩游戏，成年后家人改变观念支持其以游戏为职业，父母原本就鼓励其艺术教育；2017已有Ludum Dare与游戏奖项，不能说无外部认可。

2019当期访谈： 2017 EA销量数百，2018 iOS版买断营收不足回收发行预付，2019 Steam完整版销量在制作人估计中仅两三千份，仍因家庭此前认可艺术创作而无明显家庭压力；工作室现金来源还有外包、商业小项目、投资和低成本运营，非全靠家庭资助。母亲早已去世，不能把后期家属支持归因于双亲在场说话。

比较位置： FAMILY GATE PASS = YES (reported)、SHIP = YES、PRODUCT MARKET VALIDATION = WEAK AS OF 2019、SOCIAL APPROVAL AFTER COMMERCIAL DISAPPOINTMENT = REPORTED、ECONOMIC SUSTAINABILITY = MIXED CROSS-SUBSIDY；不是新 Case 编号或国家平均指标。

有用的研究对照因此变成：梁其伟(失保研→暂缓→复工)、李远扬(家庭认可→项目发行与品类转化失败)、Croshaw(职业已有声望而家庭不认可)、Berardi(项目不盈利→回就业而伴侣依然认可尝试)。社会规范与行业版本是两个独立的约束，不得归并为民族价值判断。

2. 社会层 household-economics 已形成第一批中国样本，但仍需结构化补录

022 已补入： - 《奋斗吧！领主大人》：几乎全部积蓄 + 约100万团队投入 + 婚后/生育压力 + 失败后回就业； - 《贪婪大地》：房贷、保姆、孩子、配偶失业与约3万元月家庭开支； - 《村与地下城》：储蓄 + 配偶无收入 + 孩子读书 + 裸辞一年现金单向流出； - 《伏龙记》：伴侣支持背后的 childcare / domestic labor / opportunity cost。

下一步不是继续泛搜“家人支持”，而是把同一字段反向补进已有中国 Case，并用欧美同字段做可比。

3. 行业层原缺口已由 The Magic Circle 补上

参见 CASE-048-the-magic-circle.md 与 022。

Question 的 BioShock / Thief / Dishonored 老兵： - 明确拒绝旧 AAA process-heavy objective function； - 形成三人高信任、强作者性小团队； - creator–project fit 很强； - 仍因 niche-within-niche、category legibility 与 market access 不足而商业不可持续。

因此已经可以正式保留：

deliberate unlearning + strong fit 仍不是商业成功充分条件。

八、下一步写作门槛

在开始真正的 reader-facing 《英雄为什么没有出发》正文前，至少要求：

  • 教育层：3 正 / 3 负 / 3 混；
  • 行业层：3 正 / 3 负 / 3 混；
  • 社会层：3 正 / 3 负 / 3 混；
  • 每层至少 2 个非中国控制案例；
  • 任何“文化解释”必须先通过物质条件与 production regime 排除；
  • 每个历史成功经验带年份与版本有效期；
  • 每个成功案例至少绑定一个失败反压力。

满足这些条件以后，才允许把研究笔记压缩成正式章节。
