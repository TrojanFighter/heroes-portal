0. 为什么需要这份台账

010–014 已经吸收了本轮主要理论和案例，但此前缺少一层“每个素材到底去了哪里”的 provenance。

本文件解决五个问题：

  1. 某截图/网页究竟提出了什么问题；
  2. 该问题是否已经被公开证据核验；
  3. 它现在属于 Strong / Hypothesis / Anecdote / Reject 的哪一层；
  4. 它已经落到哪个研究笔记 / Case；
  5. 还剩什么最小取证动作。

这里的 intake ID 是研究内部编号，不等于外部事实来源编号。

已知： - 2013–2014 卡牌手游高收入占比有历史数据； - 后续重度 RPG/MOBA/吃鸡等迁移可观察。

未知： - “不到八年”能否成为清晰统计窗口。

最小取证动作： 2012–2021 年品类收入/下载占比 + cohort/ARPU/榜单结构年度数据。

O-008 — “赛博地主”强命题

已知： - 中国安卓渠道高分成历史真实； - Steam / 全球直销是另一套接口。

未知： - 中国 premium indie 是否“普遍必须买二流流量”。

最小取证动作： 项目级 UA/PR/creator-outreach 花费、wishlist 来源、regional sales 对照。

5. 落库状态判断

Strong / 可直接用于后续 Claim 候选

  • production regime / ownership / feedback architecture 比职位名更值得编码；
  • large-org capability capital 与 0→1 problem selection 不是同一能力；
  • 腾讯高层公开承认 regime / scale fit；
  • NExT 早期 portfolio 有多个有效 0→1，故“全失败”不成立；
  • SYNCED 与 Boundary 都存在高 error-persistence cost，但机制不应强行同一化；
  • Gunfire Reborn 与 Tripwire 都提供较短 validation ladder 的正向 comparator；
  • T9 credits 证明最高负责人具备高 ownership span；
  • Game Science 不能被简单编码为“腾讯手游人”；
  • Hero 出售动机不能从事后结果倒推；
  • CrossStar / Sultan “9人不是从零”必须保留历史组织资本边界。

Hypothesis / 只允许作为待检命题

  • Tencent-style commercial grammar 是中国最强 hegemonic professional grammar 之一；
  • resource-mismatched emulation 广泛存在；
  • Prestige-Protected Persistence；
  • Credential Proxy Dependence；
  • Benchmark Dependence 导致肥尾创新被低估；
  • Capability Repricing 在第四代 premium 市场系统性发生；
  • China-vs-West 的商业训练—indie 制度距离差异；
  • Distribution-Induced Design Convergence。

Anecdote / A0-CHAT

  • 37岁腾讯前员工1700万仍焦虑；
  • 国内主策“基本全是执行岗”；
  • 英雄互娱“觉得 Game Science 不行所以卖”；
  • 早期黑猴员工“因没对标觉得坑爹所以走”；

  • “数值卡牌韭菜”精确八年；
  • “赛博地主前三困难”；
  • 具体群聊参与者对老板/岗位/公司的评价。

Reject / 不再使用

  • 程序员天然优于策划；
  • 腾讯完全不会创新；
  • NExT 全部创新失败；
  • Boundary 失败证明太空 FPS 无市场；
  • 大厂经验对 indie 无价值；
  • 欧美商业训练天然优于中国；
