0. 发现：一个比 GGJ 单站更大的中国游戏创作入口

由 UGDAP 大学生游戏开发联盟于 2024-05-29公布的同期材料：

  • 2024 第四届 CUSGA 面向全国31个省级单位及港澳台、海外9国、430+ 高校，主办方称有 2000+ 大学生开发者报名（persons，近似）；因此不等于纯中国大陆样本。
  • 截至 2024-05-08，主办方已收到 500+ 个完整作品（submitted projects，近似），不能据此计算每位报名者的提交概率（团队、个人口径不同）。
  • 75 个作品初赛入围（curated projects；主办方公开了名单，网页文本仅有单张长图；尚未完成人工逐条 URL / 唯一项目 ID 核对）。

2024-06-19 主办方再次发布决赛入围作品长图；同期第三方现场报道明确为40个决赛入围作品（而非40名学生），获奖名单由2024-08-04公布。只要入选是经过评审，75/40 都是按质量/表现筛过的群体。它们比媒体明星发现方法更广，但仍然不构成500+ 全部提交项目的无偏样本。

这是当前在国内可搜到的公开足够早、样本足够大、且已经间隔两年的一条项目级 longitudinal follow-up 线索。

2. 新增里程碑：完整40件决赛作品与44个提名位置已复原（2026-10-08）

完整名册（40款作品的题名、团队公示名、提名类别、稳定研究ID）： 030 — CUSGA 2024决赛40项目复原。

2024年6月19日UGDAP官方决赛公示被WePlay于6月20日以完整可搜索文字转载，包含11个奖项类别 × 每类4个候选 = 44个提名位置。严格按「标题+公示团队名」去重，重复提名4款（小鼠开车大冒险、忆时倒带、昆仑奴传、太荒岁纪），得到40项不重复的公示决赛作品，恰与2024-08-07同期现场报道“40个决赛入围作品”吻合。

这里的40/40仅说明“作品题名 + 团队公示名”的文字名册已恢复，不说明对应原始参赛ID/下载URL已逐一核验。75项初赛名单仍为单张长图，尚未完成75/75内容复原；超过500项普通投稿亦无完整公开目录。

同一团队「虚无幻象」分别以《Spirit》与《Van宁弹射物语》提名，故不同作品不能因队名相同而错误去重；而同一《昆仑奴传》提名听觉、动作，只能算一项游戏。正式追踪可先从40项高选择决赛层启动，但无法推出大陆普通学生、报名未提交者的创作概率。

3. 2024→2026 同期压力测试：一次比赛中的获奖者和未获奖者不能直接比较“人生好坏”

案例 006 提供罕见的 same-team post-graduation branching：2024年的6人毕设作品在项目展示时就被投资者发现，毕业后其他同学有留学、就业等不同职业安排；两人继续创业并切换到一个小得多的新原型，随后加入另一位程序员。到2026年该新作品取得突出商业结果。

因此至少三件事不可混淆：

  • ORIGINAL_STUDENT_GAME_SHIPPED：毕设项目《鼠鼠来了》是否以原项目名正式发售？本轮 UNKNOWN；不能因为创作者改做新游戏就写其失败。
  • TEAM_MEMBER_CONTINUES_GAME_CREATION：个别成员是否在业余/雇佣组织里继续自发创作？未受访者 UNKNOWN；就业大厂不等于放弃作者性。
  • NEW_GAME_RELEASED：《浣熊推币机》是另一个项目，不是《鼠鼠来了》继续迭代之后的商业发行。

这个例子对于「范围决策」与「队伍分裂后路径多样性」是有力的机制证据；对「中国同龄人普遍怎样」没有分母价值。成功后大量报道反过来提高了这个团队的可发现性。

4. 统一追踪方案：先预注册规则，然后扫完整名册

Phase A — restore same-stage denominator

  1. 2024 主办方图片公告的75个项目原样录入：项目标题、团队公示名、赛事年度、入围阶段、公告链接。若同名重复，以官网项目ID或确凿团队信息解歧；不依媒体报道挑入。
  2. 若能找到 500+ 全部提交作品的完整主办方导出，升格到 submission cohort；若拿不到，保留selected-75 的评审条件样本，并标注筛选偏差。
  3. 2024决赛长图提供额外选择字段，不能作为15%、8%之类未经单位统一的分子分母。切勿把画面上的同作品多奖提名计成多个游戏。

Phase B — uniform public evidence scan at 2026-10-07

对每条 project 先检查比赛官方页面 / 同期展示 / 项目自愿公布的公开主页，再固定顺序检索 Steam、itch.io、TapTap、B站公开开发日志；同名不得在没有开发者/作品确认时匹配。记录：公开继续开发、明确终止、正式发行、另起项目、无足够后续线索。每项写查询日期/平台/关键词和可复查链接。

  • NO_POST_2024_TRACE_FOUND ≠ STOPPED; NO_RELEASE_FOUND ≠ FAILED.
  • PERSONAL_AUTHORSHIP_AFTER_EMPLOYMENT 必须由本人直接、自愿公开或获同意调查，不能因未公开作品即判定作者性丧失。
  • 完全忽略「开发者家庭有没有允许创业」之类未公开私人事实。
  • 采访采样应包括有后续与无后续公开痕迹的人，所有受访者匿名自愿；拒答不得算停止创作。

Phase C — compare opportunity channels, not countries yet

能得到 selected75 后，在同一赛事内比较「2024是否通过学校/导师获得商业机构早期接触」「2026是否有原型、发行、投资公开痕迹」的共现关系，但投资者事先筛选好作品，selection into funding confounds any apparent treatment effect。融资比例与资源帮助需访谈未获资助者、且保留 refusal。对于家庭与就职，不能绕过知情同意。
