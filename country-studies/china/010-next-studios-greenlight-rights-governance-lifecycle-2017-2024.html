0. 为什么2018年的真实管理文件胜过“腾讯也有一款独立游戏”的成功个案？

NExT由腾讯体系内旧业务团队转型而来，既有薪酬/平台/专业人才，又希望得到独立工作室式创意生态。它是中国企业内部少见的公开记录了早期原创立项的筛选成本、评审规则、失败项目、项目组撤退与管理层仲裁者的长期实验。初期发生过真实的优秀产品、人才竞争和内部资源供给瓶颈；数年后持续的融资/收益压力与组织调整，让早期规则的可持续性成为需要单独验证的问题。

最重要的更新：2018年NExT负责人的公开自述不是“所有人都可以自由立项”：任何成员都可发起/组队/试作，但关键有争议项目是否继续，最后仍由上级工作室负责人沈黎承担主观终审。这同时证明“自下而上有真实实践”和“所有权/资源权有层级边界”。“自下而上 vs 自上而下”是一个具体权力组合，不是两种固定人格或民族精神。

1. 2016—2018：从一个人的旧技术/商业部门，建立可失败的试作入口

1.1 不是从零创业：原有薪酬、人员与资源重配

游戏葡萄于2018-10-16访谈沈黎和吴郁君（同期第一人称管理者）： - 沈黎自述2016年末接手《怪物猎人Online》团队及深圳原智能硬件/无人机业务团队；有旧组织劳动力与资源，不是两人白手起家；2017-03定名NExT。 - 认为腾讯已拥有多个商业成功团队，要给新单位非既定品类的差异化定位。他自述腾讯高层批准创意业务并给相当高的管理灵活度；这是被授权的内部试验，不等于完全游离于集团预算。 - 理念是“所有人都可能提出不同创意，资历不是创意的必要资格”；不限定品类或平台，但作品必须有独特长板，允许存在短板，五类候选差异化包括玩法、系统、艺术、叙事、文化/额外价值。 - 初始孵化团队通常2–5人；先用Demo展示创意，再用 Vertical Slice 证明量产品质；获通过可调用更多美术/程序和生产资源，2018访问时称单个团队约20人为上限。小创意还可走不强迫做大产品的 Playground 通道。 - 一个确凿的 employee-side→corporate project 案例：OWO /《欧呜欧》由一位在职主创业余时间先完成Demo，被管理团队认可后逐渐从原项目转出、增补合作人员并完成产品。它说明这种组织制度曾经真的把员工的私人早期创作转为公司正式项目。不能据此推所有员工都允许带走IP、继续保持私人所有权或获得项目公司股权。 - 人才画像：能跨专业完成小Demo的T型人才、关键专家和不一定自我表达但擅长支持项目的专业人员。参与创意生态不代表所有人都必须做主策或创业。

1.2 固定“100人日 review”而不是“100天后发售”

2018顾煜公开署名的NEXT Story（4）—《幽林怪谈》背后的故事之‘筛选’和上述采访可互相校验： - 每个创意累计消耗100个人日即Review；例如2人队可用约50个工作日、10人队只约10个工作日，故鼓励小团队有更长日历时间来验证，而不是越大越好。 - 此量尺是一种研发资源预算粒度，不是现实中所有项目强制只有100个人日，也不是严格A/B实验；顾煜承认起初就是概略估计。 - 管理层自述初期尝试了数十个概念，真正重点开发约十个；沈黎2018采访称累计孵化约30–40个项目，十多个进入产品化，平均在预立项前投入200多个人日。数值是约数、组织内部不同节点状态、在采访发表日的一次截面，不是全中国成功率/商业成功率；“产品化”≠“发行盈利”。 - 同时保留真正的样本缺失：被淘汰的绝大部分概念没有公开全名册、最终成本、作者/岗位、是否后来改头换面被重新提交；不能当作某群人的职业失败数量。

1.3 2018制度更关键的一步：把“Review权”与“最终仲裁权”公开区别

顾煜2018年文章描述了非常明确的权力结构： 1. 主创、小组、各领域专家和管理人员均可参加评审，提出挑战； 2. 专家会后匿名反馈，避免现场对话让尖锐负面评估被人情中和； 3. 项目组成员也匿名反馈对该游戏的支持/反对，确保能见到没有发起权的劳动者意见； 4. 若专家与项目组意见均积极，项目继续；如果任意一方出现反对，沈黎个人进行最终仲裁，判断终止/暂停、再做或继续； 5. 沈黎借电影主编/编辑部式创意判断作比喻，明确不把争议完全交由市场数据或“人人投票”。

实际权利的分布： - IDEA_ORIGIN：普通员工可有； - PLAYABLE_PROTOTYPE：小组可做； - PERFORMANCE_REVIEW_VOICE：专家+内部成员有，可能匿名； - RESOURCE_ESCALATION：专业评审和管理层决定； - FINAL_KILL_CONTINUE_ON_DISPUTE：沈黎； - EMPLOYEE_IP_OWNERSHIP：访谈未谈，不可推定主创私人享有； - PARENT_CORPORATE_CONTINUATION：NExT负责人无法保证集团永远拨预算。

因此“自下而上”不是“团队决定全部开发预算和生死”。这不是批评NExT虚假；相反是中国公司愿意公开其有边界但可操作的创新治理制度的罕见证据。也不能将最终仲裁权一概归为“专制压制”：投资风险与专家意见冲突时必须有人承担预算责任；要研究裁决正确性、异议安全及失败者回炉机会。

1.4 一次真实“先砍项目、后救创意”决策

顾煜同期叙述一个早期尚未验证核心玩法就安排10多人开发的项目：项目负责人为给所有人找工作分散了核心玩法设计精力，产生大量无用迭代；随后砍原项目/缩回小队继续孵化，下一版Demo获得认可，发展为内部代号NEXT004。文章标题与《幽林怪谈》关联，但不额外推定具体哪一段/哪个内部编号等于商店作品，除非找到清晰项目ID对应资料。

这为“项目取消=原作者失败”提供反例： - CANCEL_CURRENT_CONFIGURATION 是一个可让公司停止错误规模的决定； - CONTINUE_SAME_PROBLEM_SMALLER 是另一独立的作者性许可； - AUTHOR_RETAINED 可与 PROJECT_KILLED 并存，二者不应相互推出； - 如果裁撤同时使人才离开或者原型IP不能带走，则后果相反，须看具体个案。

不能只计被砍项目数量而不观察团队在其后有没有再制作机会。

2. 2018同一年另一面：创意工坊既要争项目，也要争职业安全与人手

顾煜2018-12-29亲署《NEXT Story（8）：饱和攻击》描述：部门内部新立项时，其他腾讯工作室能够以相对清晰的商业大项目职业路径吸引美术/引擎等专业员工转走；一些人也嫌弃小型创意游戏不够大或高端。创意小队因此一度缺少美术，原计划的跨专业组合失衡。

其内部复盘没有把原因仅归咎于“员工没有理想”： - 创意方向的长期前景和职业升迁/技术成就没有及早向员工说清楚； - 激进变动的部落/行会/监制组织结构，提高新团队的人际与流程不确定性； - 员工在稳定现金报酬、作品规模/社会声誉、可预期职业成长和创作表达之间权衡； - 管理层尝试约谈挽留，并坦承有值得纠正的管理失误。

这是2018年转型当时的反面证词：与后来2026《社会》“片段性调用”相对，连一个提供创作自由的组织也可能在职业安全与具体岗位机会的比较中输给更强工业化/商业路径。不能先假定留在大厂原团队者“失去理想”、跳到商业项目者“更缺创意”。商业化项目也可能提供宏观项目影响力、先进技术问题和更稳定生存条件。

3. 2019腾讯母体：创意立项漏斗有组织数字，但不是商业成功率

2019-02，触乐记者祝佳音在深圳访问腾讯集团高管马晓轶，其第一人称描述大腾讯游戏的粗略年度流程： - 5000人左右（当时概略游戏工作室研发组织规模）； - 约150个游戏提案/年； - 约50个以上进入立项； - 十多个走到市场测试； - 五六个上市。

定义原则： - 提案单位/申请人不明，游戏立项可跨年，数字均为高管口头约数；不能默认是严格同一年同一入组 cohort。 - “立项”不是上市，“测试”不是发售，“上市”不表示发行收入盖过成本；5或6/150不是可发布的创意成功率。 - 这也不是 NExT 的 30–40孵化 对应比例：公司层级、年份、单位和阶段均不同，不能上下拼接成一条算术漏斗。 - 可支持的硬观察是组织中既有大量发起/提案，又有至少多级资源约束与筛选，具有预算授权权利的节点并非提案者本人；这不是“腾讯永远不批准原创游戏”。

4. 2022—2024：制度存续权在哪里？2018管理宣言面对组织更替

4.1 2022—2023 NExT：早期保护伞与后期集团预算评价不是一个权力层

2023-04-11，竞核记者陈佩佩采访多位NExT员工，36氪经授权发布： - 沈黎于2022年末离开腾讯；报道认为NExT在多个部门调整中失去统一庇护和内部沟通代表，部分业务和创意工坊于2023年初前后转移/调整；有员工转职或离职。 - 受访者称腾讯体系要证明价值往往需靠营收，记者据此解释品牌口碑/招聘价值难独立覆盖持续人力成本。 - 报道表述“创意项目探索模式均宣告失败”，是记者和受访者对该组织试验长期存续的解释，不是指其所有小作品都没有市场成功。如 014 已核《疑案追声》《只只大冒险》仍是有真实玩家/销售长尾的作品；CREATIVE_ORG_ENDURANCE 与 GAME_PRODUCT_SUCCESS 是不同结果变量。 - “峰值400多人”“被掏空”取自记者/内部人，不是腾讯审计报表；业务架构/人员去向的同一时点官方证明仍未核实，不得把新组织职能转移写成法律主体已解散。

同年第二条反压力证据：2023-06-30游戏茶馆对留任NExT副总经理顾煜的采访（时间晚于记者4月文章）：他明确承认内部业绩KPI后来有要求、有项目裁撤，但说仍在研三个项目（一个临近上线、两项预研），并表示相关外界“完全解散”的传闻过强；叙述早期存在自下而上创意线与自上而下中大型品质线。所以研究必须同时记录： - 2023年4月创意工坊调整/人员流失的多名匿名员工报道； - 2023年6月组织负责人描述仍有在研项目和预算压力； - 不可合成“2023整间NExT已被关停”或“2023一切正常”。

4.2 2022米哈游 Project SH：连CEO带队的“高权限”也会终止

2022-11-24澎湃记者范佳来核实米哈游Project SH研发团队解散；公司回应是业务调整；记者获取的内部公告说希望内部转岗、无岗位时按规则补偿。报道称项目有公司创始人/CEO蔡浩宇参与，2019已公开技术项目线索。

压力测试： - TOP_CREATIVE_SPONSOR 不意味着 PERMANENT_GREENLIGHT；即使强项目发起权和组织政治资本，都可能终止耗时项目。 - 项目被砍可以出于生产效率、技术目标、市场窗口、多项目资源竞争，不能由“失败/被砍”推“高层没有作者性”或推“高层自私”。 - 员工转岗承诺也不等于每一位员工实际获得替代作品、补偿或继续创作的机会；没有后续员工 cohort。

4.3 2024腾讯“春笋/果岭”：集团再定义激励，不代表旧方案零成果

2024-05-28触乐采访腾讯高管马晓轶，其直接解释公司两个投资/自研路径： - 春笋：更靠近 从零到一，鼓励内部人员在自己有长期积累愿望的游戏类别反复尝试；他提出真正的品类深耕应允许单项目成败后仍沿同类继续。 - 果岭：支持已经有潜力、想做得更大且需要集团资源的头部项目。 - 他还描述腾讯更愿长期扶持稳定团队而非单个创作者，强调不同专业共同经过多次项目磨合，认为成熟中国市场需要更长积累。 - 同一访谈中，马晓轶主观定义买断游戏在某品类上卖到 300万份 为公司意义上的 0→1，800万份是 1→10 量级；这是高管描述自身投资尺度与战略门槛，不是全球独立开发者成功的客观必要条件，更不能拿300万标准去否认2017—19 NExT小体量玩法实验的产品成就。

与2018NExT关系不是“自由立项→制度退步”的单一路径： 1. NExT2018以有限成本给员工Demo+预立项入口； 2. 腾讯2024也在谈反复品类积累、差异化的小/中量立项； 3. 但2024立项依然需要评审/集团资源，不等于个人拥有团队预算的最终决策权； 4. 资金来源、商业目标、不同 studio 或二方工作室的实际规则很可能不同，不能拿高管的长期主义讲话统一解释所有项目。

4.4 DeepSeek对NExT提出的新问题：正式Review以前，员工到底能拿到多少资源？

014 梁文锋 / DeepSeek组织反例迫使本文件增加一层此前未单独编码的权利：RESOURCE_ACCESS_BEFORE_GREENLIGHT。NExT 2018有真实自下而上Demo入口，但100人日Review、专家/团队反馈和争议终审构成明确门控；梁文锋2024自述DeepSeek研究员可在idea早期直接调用训练卡并自行拉有兴趣同事，idea显示潜力后再由组织集中资源。两者行业、成本结构和证据来源不同，不能直接评“谁更自由”；比较目的在于区分“允许提案”与“允许在正式批准前制造足够证据”。

5.1 外部第二次机会不是一条项目内部绿灯链

011《边境》→《流浪地球：望日》与国际重组对照说明另一种 SECOND_TRY：旧产品商业失败、旧出版关系终止，但团队依靠可核专业能力/合作网络取得新IP开发合同；并非要求旧IP复活。2026新采访还出现导演掌握创作、制片人掌握资源两种权力的明确分离。与本文件NExT的100人日评审/争议经理终审成对检查，能区分 REVIEW_RIGHT, RESCOPE_RIGHT, GREENLIGHT, BUDGET, IP_CANON, GROUP_CONTINUITY。但《望日》尚未发售且仍需融资，绝不可先写组织制度取得成功。

6. 三个竞争解释和三个反证检查（不预设大厂必然坏）

Hypothesis Evidence presently supports What would falsify / alternative explanation
H1: 员工确实有新题材/玩法思路，但组织不愿承担完整风险 2018NExT真实内部创意池、筛除、PM终审、2023盈利约束；2026田野片段性调用 大量组织设有有资源保障的个人自立项；不提案可能只是本人不愿意、方向尚未成熟

H3: 商业渠道与集团高增长预期筛选独立题材 2023受访者谈收益验证，2024高管定义千万量级增长；003商业制度提供渠道史 资金回报/市场风险是普遍组织条件，Supercell也是GaaS却赋项目组权；有高预算品质游戏主动产生新机制，不能从历史结构直接认定因果

对应本书读者三种职业路径： - 个人主创 / T型制作者：能独立做Demo时，组织内部发起权确有价值；但应事先理解IP、项目终审、失败再入场，以及当资助经理离职后团队是否有持续权。 - 专家型程序/美术/设计师：大规模开发可以提供技术挑战、资深指导与稳定收入；并非必须自己立项才能有创造性或有职业价值。 - 组织经营/生产者：允许成员发起原型需要回答谁说不、按什么证据说不、失败者是否能再试、谁出成本。只有鼓励创新的宣言不是制度。

7. 文献/事实缺口与严格禁止项

仍未知： - NExT 2017—2024每年全量concept→review→预立项→立项→release的去重、项目ID和工时； - 哪些原先被否定的项目后来转为有市场价值的作品；KILL_ERROR_RATE不明； - NExT普通成员在各分支作出决定时实际有多大说“不”的安全性、离开后同类岗位去向，及项目原型IP如何归属； - 腾讯2024春笋/果岭逐项目预算、批准层级、失败继续支持权限与2026验收/产出； - 2019腾讯高管口述的150/50+/10+/5–6数据是否来自连续跨年存量而非同一年提案 cohort； - 2023 NExT是否以何种法律实体/工作室品牌维持至2026；不把员工报道写成精确关停日期； - Project SH 2022被砍的内部技术目标、员工后续专业成长及岗位流转完成率。

不允许的结论： - 30–40 idea/10+ productization = Tencent games commercial success rate; - 2019 5/150上市 = 创作者成功率; - 2023某工作室撤创意部门 = 小创意产品全部失败; - 公司CEO取消自己带的项目 = CEO无创作权; - NExT 2018本人说自由 = 所有普通成员有资源/版权/公司存续权; - 2024高管说300万零到一 = 独立游戏行业普遍生存标准; - 具备提案权 = 与委员会/管理层平分研发预算最终权.

8. 最后放回人物史：这究竟帮助读者选择什么？

这不是“腾讯是否具有创新精神”的企业形象判断，而是涉及个人一段职业人生的可预期风险：

2018年的一个程序员或美术，本来可以留在熟悉的商业游戏项目，也可以争取去一个自下而上立项、评价有意义设计而非只拼营收的创新组织；前者有更可见的大型项目历练，后者有更明确的Demo发起权、跨专业合作和不保证成功的职业叙事。NExT确实给过部分人作品上线的机会；也确实出现因为项目小、团队组织不稳和人员供给竞争而退出的员工。公司层面的创新资产并不会自动变成个人的IP/资金权益，支持创意的上级领导也可能离职。

因此衡量一段职业经历的真实产出，应问：此人积累了什么能力、参与过哪些决定、见识多少可核的市场反馈、退出后是否保有可继续独立提出问题的权利与实际条件。 而不是“进大厂=收编”或“离大厂=解放”。
