013 — 大陆创作者生命周期镜像：个人原型 → 公司化 → 第一笔钱 → 全职化 → 平台/发行

  • Program: C / 中国国情研究 × 台湾比较线
  • Status: CROSS-STRAIT COMPARATOR / PRE-CLAIM / MECHANISM CASES
  • As of: 2026-10-07
  • Taiwan counterpart: 台湾资本梯子005、2021台湾奖励队列006
  • Selection warning: 本笔记使用几条资料较完整的机制案例，不代表大陆普通开发者的比例，也不证明哪套制度整体更优。

0. 研究问题

台湾线已经拆出：

兴趣/原型 → 公司化 → 独立游戏开发奖励 → 项目投资/众筹 → 产品化/发行/平台验证 → 机构资本

大陆不能简单问“有没有同名补助”。真正可比的问题是：

一个创作者怎样从私人/业余作者变成可持续生产单位？在哪一关需要公司、现金、平台背书、发行商、投资者和监管许可？

第一轮公开证据显示，大陆至少存在四种差异很大的路径： 1. SAVINGS-FIRST：资深从业者用个人储蓄买两年开发时间； 2. PUBLIC-PROTOTYPE → PLATFORM-ACCELERATOR：个人Demo先获得公开注意，再公司化并进入平台扶持； 3. VETERAN-STUDIO-FIRST：资深工业人才先成立完整公司，再以原型进入平台项目； 4. CAMPUS-PROTOTYPE → EQUITY：学生作品/新原型经投资人筛选后获得股权资金、公司支持和海外发行。

不存在证据支持“大陆独立开发统一靠某一种资金”。

1. Path A｜《戴森球计划》：储蓄先买两年，再把发行能力外部化

Canonical case: CASE-027

CN-LIFE-E01｜2019：先验证，再辞职

触乐2021年对柚子猫的发售窗口采访： https://www.chuapp.com/article/287793.html

可直接支持： - 猫猫与周讯都已工作多年；周讯有游戏开发/程序职业经验，猫猫长期业余学习策划； - 2019年1—4月形成“从微观建造戴森球”的产品想法； - 两人在正式全职前用了数月做玩法与技术原型、市场判断及细化到天的开发计划； - 验证后才辞职、租办公室、购置设备并再招3人，形成5人核心团队。

这是一条非常清楚的：

existing capability → private prototype → quit threshold → five-person full-time studio

而不是“裸辞以后再找题目”。

CN-LIFE-E02｜第一笔真正的runway来自创始人储蓄，不是投资

同一采访明确： - 项目开始时“没有获得投资”； - 主要使用制作人周讯多年积蓄； - 预算覆盖工资、音频等外包； - 团队自己估算只能支撑约两年。

2026触乐回访进一步补充： https://www.chuapp.com/article/291217.html

  • 团队上线前现金已极度紧张；
  • 摩点众筹筹到十多万元，但第一阶段实际到账仅五万多；
  • 众筹不是开工资金，也不是完整预算替代。

因此本案最准确的资金排序是：

founder savings → full-time five-person burn → late-stage crowdfunding / publisher market support → Early Access revenue

CN-LIFE-E03｜Gamera主要进入“市场接口”，不是早期立项资本

2021触乐记录： - Gamera通过微博寻找独立团队并主动联系刚开工作室账号的柚子猫； - 协助英文发行、海外众筹、配音、封闭测试及上线市场工作； - 团队将发行专业工作交给Gamera。

目前没有证据表明Gamera在最初立项阶段为项目提供了决定性的股权/开发投资，因此不能把《戴森球计划》写成“publisher-funded development”。

对台湾的意义

这和《活侠传》的2021政府奖励路径不同： - Youthcat先承担了绝大部分早期现金风险； - 外部机构较晚进入market access； - 公司/团队能否活到发行商出现，主要靠已有职业资本和创始人储蓄。

但这不是“大陆只能靠自己”的全国结论，只是一个SAVINGS-FIRST案例。

2. Path B｜《失落之魂》：个人Demo先获得注意，平台再帮助公司化与融资

CN-LIFE-E04｜真正罕见的“solo prototype → studio”路径

PlayStation官方2025回顾： https://blog.playstation.com/2025/08/22/lost-soul-aside-pc-features-and-a-behind-the-scenes-look/

官方明确把项目描述为： - 起点是杨冰的solo prototype； - 此后在China Hero Project支持下，逐渐成长为完整ARPG与团队项目。

2025杨冰与China Hero Project负责人包波的联合采访： https://www.3dmgame.com/original/3745532.html

杨冰称： - 2016宣传片发布后不久即与SIE接触； - 随后成立公司并启动正式项目； - 早期SIE除了项目支持，还为融资背书、帮助连接投资资源； - 从个人Demo转为团队工业化开发时，团队缺乏中型项目管线经验，发生大量返工； - 后期资金/技术压力加大时，SIE进一步成为正式发行方并提供更深资金、制作、技术支持。

因此可观察链条是：

solo prototype → public trailer / visibility → platform discovery → company formation → financing connections + organizational formalization → long production → platform becomes publisher → launch

这和台湾2021奖励计划的“先公司化才能申请”方向几乎相反：这里是先有极强公开原型，平台关系随后促进公司化和融资。

CN-LIFE-E05｜但China Hero Project也不是无门槛个人补助

PlayStation中国官方当前说明： https://www.playstation.com/zh-hans-cn/china-hero-project/

计划评估重点包括： - vertical slice； - game design document； - 对提交公司和团队的审查； - 重点作品可获得开发资金； - 同时提供代码审查、中间件、QA、音频、开发协助、发行伙伴连接和市场推广。

因此《失落之魂》的solo-origin不能被误读成“任何个人都能直接申请一笔Sony补贴”。杨冰是非常高可见性的特殊发现样本；正常申请路径仍明显偏向已有团队和可玩证据。

3. Path C｜TiGames /《暗影火炬城》：资深工业团队先公司化，再进入平台扶持

CN-LIFE-E06｜不是小白创业，而是约20人老兵工作室

4Gamer 2023对TiGames CEO张弢的采访： https://www.4gamer.net/games/727/G072748/20230801013/

记录： - TiGames 2016年初成立； - 创始成员来自Epic Games、Ubisoft等，已有15年以上行业经验； - 初始团队约20人； - 张弢2007—2016从事Unreal Engine技术支持，并参与Epic Games/Tencent项目； - 团队成立背景之一是移动游戏已成为主流，而成员仍想做主机产品。

公司第一作是PSVR多人游戏，2017发布，但市场较小、表现不佳；团队没有立即解散。

CN-LIFE-E07｜第二作原型进入China Hero Project

同一采访： - 2018准备新作《暗影火炬城》； - 因此前PSVR项目已与SIE上海合作，SIE早期询问下一作； - 团队展示prototype后进入China Hero Project第二期； - 约20人用40个月完成； - 后续F.I.S.T.成功使团队扩张到约50人。

2021制作人采访进一步说明China Hero Project实际提供： - financial support； - technical support； - BitSummit/TGS/ChinaJoy展示； - Epic/CRIWARE等伙伴支持； - 早期PS5 dev kit。

https://mp1st.com/news/tigames-talks-fist-forged-in-shadow-torch-success-china-hero-project-dlc-more

对台湾的意义

这不是“个人→公司”的创业故事，而是：

industrial veterans → 20-person studio → first commercial failure/weak result → prototype → platform accelerator → international market access

它更接近台湾成熟公司申请产品化/平台商业验证，而不是《活侠传》那种两人工作室。

4. Path D｜《浣熊推币机》：毕业分流 → 小原型 → 股权投资 → 全球发行

Canonical note: 006 — CUC毕业岔路

已有证据链： - 6人大学毕设《鼠鼠来了》； - 毕业后团队分流； - 万兽与乌龙主动放弃原本负担较重的3D平台项目； - 2024-07用约2—3周制作更小的推币机原型； - 原型之后才获得开拓芯股权投资意向； - 投资方支持公司注册、办公、财务、商务等； - 再补入程序核心； - Playstack提供本地化、玩家测试、QA、宣传和部分技术外围； - 2026正式发售。

这里的组织形成几乎与《失落之魂》相反： - 不是平台从公开视频里发现个人作者； - 而是大学/导师/投资网络先形成接触； - 创作者先用极小原型证明题目； - 投资进入后才使全职商业化路径成立。

它与台湾Team9有某种结构相似性： - 都是跨能力组合； - 都存在早期专业资金/商务网络； - 钱的重要作用之一是把非全职创作转成全职生产。

但大陆案例是股权投资，Team9已核到的是项目收益分成型投资；权利成本不能混同。

5. 四条大陆路径与台湾第一轮对照

Lifecycle gate 台湾已核机制 大陆已核机制
私人/业余作者 → 可玩原型 原始鸟熊、Team9；GGJ社群 Youthcat原型；Lost Soul solo demo；CUC学生原型
原型 → 公司化 2021奖励制度要求先公司化；StormEdge称资金门槛促使成立公司 Lost Soul由平台发现后公司化；Raccoon获投阶段公司化；Youthcat工作室化

最重要的初步差异，不是“谁更支持独立游戏”

目前只能提出三个H级假说：

H-CROSS-01｜台湾公共资金把“公司化”放在较早的eligibility gate

2021台湾奖励明确要求成立未满5年的公司；个人不得先获奖再注册。

大陆目前找到的几条明星路径则更异质： - 可以先用储蓄直接成立小工作室； - 可以先做solo demo，再被平台发现后公司化； - 可以先在校园完成原型，再靠股权投资进入公司阶段； - 也可以由资深从业者直接成立20人公司。

这不证明大陆公司化更容易，而是说明外部资金入口更碎片化。

H-CROSS-02｜台湾已出现较可见的公共“奖励→投资”梯子；大陆premium indie的第一轮可见样本更依赖市场/平台/私人资本

台湾已核到： 奖励 → 产品化 → TAICCA/国发基金投资 → 平台/发行验证。

大陆当前可见： 储蓄 / school-network equity / publisher / Sony platform accelerator / commercial-project cashflow。

但“本轮未找到统一大陆公共奖励梯子”绝不等于“大陆地方政府没有游戏扶持”。必须继续核地方文化产业、科技、动漫游戏、创业与出海资金，并区分其是否真正开放给premium small-team game。

H-CROSS-03｜两边真正稀缺的可能都不是钱，而是能把钱变成production capability的中介层

台湾： - Team9的项目投资直接买回全职时间； - TAICCA后续计划把发行、平台、测试和市场绑在一起。

大陆： - China Hero的价值远超现金：技术、QA、中间件、硬件、制作管理、全球展示与发行接口； - Gamera对Youthcat提供英文化、封测、海外众筹和上线劳动； - Playstack对校园团队补市场/QA/本地化。

因此跨地区比较必须编码： money only vs money + production services vs money + market access vs money + governance/control

而不是只比“补助金额”。

6. 一个需要特别警惕的大陆选择偏差

这四案仍然高度可见： - 《戴森球计划》是爆款； - 《失落之魂》是China Hero传奇长期项目； - TiGames有平台与媒体长期曝光； - 《浣熊推币机》因2026商业成绩获得密集采访。

所以它们只能回答“哪些机制可能存在”，不能回答普通中国开发者通常如何融资。

下一步必须接回已有的： - CUSGA 500+完整提交 / 75初赛项目； - 深圳GGJ公开项目； - 开拓芯20+已投团队； - China Hero各期完整入选/发售/延期队列。

只有这些固定起点样本才能讨论分布。

7. 下一轮最值得做的三件事

  1. 正式修复CASE-027《戴森球计划》Evidence Ledger。 2021触乐已经足以核回5人、职业前史、辞职时点、储蓄两年runway、Gamera后期发行外围，原SKELETON不应继续保持全部UNKNOWN。
  2. 建立China Hero Project全项目队列。 PlayStation官方已有当前发售/开发清单；需要按第一/二/三期重建“入选时成熟度→资金/服务→发售/延期/取消”，避免只看F.I.S.T.和Lost Soul。
  3. 查大陆地方/中央公共资金的真正small-team game eligibility。 与台湾比较时只纳入能明确回答公司年限、个人能否申请、现金类型、匹配资金、IP/分润、评审成熟度和失败责任的工具。
