014 — 梁文锋 / DeepSeek：中国内部“原创组织”正向偏离样本

  • Program: C / 中国国情研究：教育社会化 × 行业组织 × 原创问题主权
  • Status: FOUNDER-INTERVIEW PRIMARY CLAIMS / POSITIVE-DEVIANT CASE / NOT AN INDEPENDENT ORGANIZATIONAL AUDIT
  • As-of: 2026-10-08
  • Related: 009 中国游戏雇员创造性劳动 / 010 NExT greenlight rights / 012 full-cycle team density / 三层案例矩阵021
  • Boundary: 梁文锋关于DeepSeek组织方式的陈述主要来自本人采访，带有创始人自我叙事偏差。未经离职员工、失败项目和完整资源分配记录独立审计，不把“扁平/自由”升级为全员事实，不把DeepSeek成功反推为中国普遍潜力已经被证明。

0. 为什么值得进入“老中研究”

梁文锋的采访描述了一种中国内部的组织安排。在他的叙述中：

  • 人才主要来自本土；
  • 很多关键研究者年轻、甚至尚未毕业；
  • 组织声称较少前置任务分工；
  • 研究员可以自下而上提出问题；
  • 早期idea出现以后，可快速调用算力和同事；
  • idea显示潜力后，再由组织向上集中资源；
  • 公司明确把“原创而非跟随”当战略目标。

这些自述为检验以下过强命题提供了一个中国内部反例，但组织实际如何运行仍需独立审计： - 中国教育必然无法产生前沿人才； - 中国年轻人必须先熬很长资历才适合拥有问题定义权； - 中国原创差距的主要原因只是缺资本； - 资源规模越大就自动越创新。

本篇围绕一个问题展开：

同样经过中国教育体系的人，为什么在某些组织里只是高性能执行者，在另一些组织里却能获得前沿问题的所有权、资源调用权和反复试错权？

1. 2023梁文锋：创新组织必须容纳低效率、失败和浪费

P1 founder interview, 36氪 / 暗涌，2023-05-25： https://www.36kr.com/p/2272896094586500

梁文锋在DeepSeek成立初期明确表达： - 创新需要尽可能少的干预和管理； - 需要自由发挥和试错空间； - 很多创新不是按计划“教出来”的； - 大公司容易被已有经验和惯性束缚； - 真正关键是适应变化，而非严格照现成方法执行； - 创新本身昂贵、低效，并伴随浪费。

要核查这种容错安排，需要知道预算、时间和再尝试权能支撑多少次失败。这里用一个组织变量记录：

AFFORDABLE_FAILURE_CAPACITY

定义：

一个组织在不把探索者永久淘汰的前提下，一年实际可以承受多少无产出原型、错误路线、失败实验和回炉项目？

游戏业对应： - NExT的100人日Demo； - Supercell kill culture； - id式低成本快速原型； - 学生Game Jam； - 独立团队的现金runway。

2. 2024梁文锋：从追赶产品到提出前沿问题

P1 founder interview, 36氪 / 暗涌，2024-07-22： https://www.36kr.com/p/2872793466982535

梁文锋将中国AI与美国的差距描述为“原创与模仿之差”，并认为： - 中国公司长期更习惯follow； - 当前中国大企业并非天然缺资本； - 更关键的问题是信心，以及如何组织高密度人才做有效创新； - 前沿创新需要站到第一手技术社区中，而不是只消费二手路线图； - “更多投入”本身不保证更多创新。

本项目的游戏研究也关注追赶型产业：团队可以围绕已知 benchmark 高效执行、优化商业表现，同时在定义下一代问题和路线上的权利仍可能偏弱。这是本篇采用的跨行业比较视角。

建议正式变量：

FRONTIER_PROBLEM_OWNERSHIP

是否处在“自己定义下一代问题”的位置，而不只是优化已知benchmark。

FIRSTHAND_ROADMAP_ACCESS

团队是否通过论文、开源、玩家社区、工具链、全球开发者网络直接参与前沿知识生产，而非长期依赖二手翻译、渠道需求和市场复刻。

3. 正式立项之前，研究者能调用哪些资源？

2024采访中梁文锋描述： - DeepSeek“全是自下而上”； - 不前置精细分工，而是自然分工； - 个人有想法可自行拉人讨论； - 研究人员调用训练集群卡无需逐层审批； - idea有潜力以后，公司再自上而下调配更多资源。

个人可以提出想法，还要有资源把想法做成可检验的东西。NExT研究此前尚未单独命名这项差别：

RESOURCE_ACCESS_BEFORE_GREENLIGHT

定义：

在正式立项/管理层批准之前，一个人或小组实际能拿到多少时间、工具、人力和基础设施来证明自己的想法？

三种组织可能都声称“人人可以提创意”，但差异巨大：

  1. 可以提建议，但没有工时和原型资源；
  2. 可以做低成本demo，但资源有明确上限；
  3. 可以较自由调用核心资源，直到idea出现潜力再集中投入。

NExT 2018更接近第2类。梁文锋自述的DeepSeek早期探索更接近第3类。

但谁可以长期占用多少算力、失败idea何时停止、发生资源冲突时谁仲裁、组织扩大后是否仍然成立，都没有独立审计，必须保持UNKNOWN。

4. 对“中国教育把人教废了”的重要反压力

2024采访中梁文锋称： - V2团队主要是本土高校应届、博士在读和毕业不久的年轻人； - 没有依赖海外归国“大牛”； - 他认为中国顶尖人才经常因社会中硬核创新机会太少而“不容易被识别”； - 选人强调热爱、好奇心和基础能力，而非单纯工作年限。

这迫使“教育层”拆开：

  1. FOUNDATIONAL_CAPABILITY
  2. PROBLEM-FRAMING_TRAINING
  3. POST-GRADUATION_PROBLEM_OWNERSHIP

DeepSeek只支持：

中国本土教育体系可以产生足以参与前沿研究的人才。

它不支持：

中国普通教育普遍鼓励非共识问题提出。

更有价值的假说是：

教育可能已经生产大量强基础能力者，但产业组织能否给予他们早期problem ownership，决定这些能力是否显现为原创成果。

这与中国游戏业“大量高执行力专业人才 vs 稀薄完整作者型团队”的问题直接相连。

5. “经验不是唯一资产”如何正确迁移到游戏业

梁文锋2023/24访谈强调： - 前沿问题不存在成熟答案； - 过多旧经验可能形成惯性； - 年轻人更容易相信自己可以试新路线； - 组织选人重视基础能力、热爱和好奇心。

但游戏业不能直接推成“新人比老制作人更适合原创”。

011《边境》恰好提供反例： - 没有成熟制作管线会产生极高延期和返工； - 产品完整度、scope、生产组织需要真实经验； - 失败项目仍会沉淀可复用production capital。

本篇主张把非共识问题的提出权与有经验的生产能力结合，让廉价原型接受现实反馈。资历本身不足以决定谁应拥有所有关键问题的定义权。

6. 团队能力比单个产品秘密更耐久

2024梁文锋认为： - 技术本身并非永久秘密； - 真正难重置的是团队、know-how与持续追赶下一代的能力； - 护城河不是一项静态成果，而是反复生产新成果的组织。

这与012的目标高度一致：

FULL_CYCLE_TEAM_DENSITY = 一个产业里，能反复提出、完成、接受市场反馈、再做下一次的稳定核心团队密度。

游戏业对应： - 《边境》失败后仍能以太空FPS能力得到新合同； - Game Science从旧项目和商业手游阶段积累团队后再进入大型单机； - Tango在公司关闭后，部分核心人和IP被新母公司保留； - NExT说明“员工有idea”与“团队长期有组织存续权”并不相同。

产品失败 ≠ 团队能力归零；产品成功 ≠ 团队一定能反复创新。

7. DeepSeek不能被用成“只要扁平就行”的成功学

必须保留五个重要混杂：

  1. Resource shell：DeepSeek来自幻方长期AI/算力投入，2023采访已记录萤火集群和万卡级A100资源。普通创业团队不具备同等保护壳。
  2. Founder technical judgment：公开材料反复强调梁文锋本人具有较强技术判断与资源调配能力；“少管理”并不等于没有高质量判断者。
  3. Selection：进入DeepSeek的人本身经过强筛选；不能把产出差异全部归于组织自由。
  4. Domain measurability：AI部分问题有loss/benchmark/训练成本等更明确反馈；游戏设计的审美、体验和市场反馈更噪声。
  5. Founder narrative bias：尚缺失败idea名册、离职员工系统访谈、资源争夺实例、冲突裁决机制和规模扩大后的组织证据。

在这些限制下，DeepSeek的用途是 POSITIVE DEVIANT / mechanism generator：提供待检验的组织机制。它尚不构成 PROVEN UNIVERSAL MANAGEMENT MODEL。

8. 对游戏组织研究新增四个正式字段

所有游戏studio组织案例新增：

  • PROBLEM_ORIGIN_RIGHT：只能建议 / 可做原型 / 可拉团队 / 可主导完整产品；
  • RESOURCE_ACCESS_BEFORE_GREENLIGHT：个人时间 / 有限内部预算 / 可自由调用共享资源 / UNKNOWN；
  • AFFORDABLE_FAILURE_CAPACITY：一次性机会 / 可重复小赌注 / 项目被砍但作者可回炉 / UNKNOWN；
  • FRONTIER_ROADMAP_ACCESS：二手市场跟随 / 直接全球参考 / 参与前沿共同体 / UNKNOWN。

并继续保留： - GREENLIGHT_RIGHT - KILL_RIGHT - PARENT_BUDGET_RIGHT - SECOND_ATTEMPT_CAPACITY - CORE_TEAM_CONTINUITY

10. 下一轮最值得研究的五个问题

P0 — DeepSeek的失败样本

找： - 哪些研究方向被停止； - idea从自由探索进入大规模训练前的真实门槛； - 算力冲突如何处理； - 失败者能不能立即转向下一题； - 离职/低绩效研究者对组织文化的不同描述。

没有这些，DeepSeek仍是成功者视角。

P0 — 中国游戏企业的 RESOURCE_ACCESS_BEFORE_GREENLIGHT

比继续统计创意提案更重要： - 员工有没有带薪原型工时？ - 能否自己拉美术/程序？ - 可以调用哪些内部工具、服务器、用户测试？ - 要到哪一步才需要VP/制作人签字？ - 被否后多久能再次提案？

P1 — 中国“优秀学生→前沿问题提出者”的转换

用DeepSeek、实验室/竞赛、游戏专业/社团做内部对照，分离教育能力形成与就业组织授权。

P1 — Catch-up regime什么时候转成 frontier regime

比较游戏、AI、无人机/机器人： - 有成熟海外benchmark时如何高速追赶； - benchmark消失以后哪些组织还能继续； - 哪些旧经验从资产变成惯性。

P2 — Full-cycle Team Density的跨行业外部效度

如果DeepSeek、DJI、Unitree等positive deviants都呈现“小核心团队 + founder技术判断 + 前期真实资源 + 年轻人问题所有权 + 非线性探索”，则可形成更强的跨行业假说；但必须加入失败样本和普通公司反例。

10.5 Pocketpair对“原创 vs 模仿”提出跨产业修正

Japan 003显示，游戏等创意产业不能直接把“原创”压成组件层首次发明。Pocketpair创始人公开拒绝对组件独创性的强执念，却通过genre组合、市场选择、Steam/community验证和生产方式形成高度差异化产品。后续跨行业研究正式区分：FRONTIER_SCIENTIFIC_ORIGINALITY / MECHANIC_COMPONENT_ORIGINALITY / RECOMBINATIVE_ORIGINALITY / MARKET_FORMAT_ORIGINALITY。梁文锋的判断在AI前沿仍有解释力，但不得机械外推到所有创意产业。

11. 可出版的限缩结论

DeepSeek提供了一个中国内部反例：本土教育与中国人才并不阻止前沿原创出现；当组织给予问题提出、早期资源调用和高成本试错的实际条件时，一部分原本难以被识别的能力可以显现。这不能推出“中国教育没问题”。

本篇因此主张调整研究的因果优先级：同时考察人才如何形成、谁拥有问题主权、正式立项前能获得哪些资源，以及失败后能否继续尝试。前沿知识网络与可负担的失败也必须进入解释；创始人访谈尚不足以分离这些条件各自的作用。
