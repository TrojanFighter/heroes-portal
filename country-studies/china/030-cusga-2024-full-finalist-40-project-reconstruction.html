3. Special audit rules learned in this transcription

Repeated nomination != separate game: four exact title+team pairs receive two category slots. Do not publish 44 finalist games.

Same team != same game: 「虚无幻象」 appears for Spirit and Van宁弹射物语, which are different published titles. This requires team/account and project/creative-work to be distinct IDs; never deduplicate solely by team.

Official stage != general population: 40 projects are both self-selected participants and selected finalists of a 500+ submitted works competition. They cannot serve as the ordinary college student’s game-writing probability. The earlier aim of recovering all 75 prelim entrants remains valuable, but 75 itself is still selected, not total submissions.

Known release from another linked person != continuation of baseline game: 《鼠鼠来了》alumni later created a different title; it must not be counted as SAME_PROJECT_SHIPPED, although it can be TEAM_MEMBER_NEW_AUTHORIAL_PROJECT if directly linked by interviews. No special status is assigned for this 40/40 snapshot so outcomes remain truly precommitted.

Absolute region: CUSGA official 2024 source included students from HK/Macau/Taiwan and overseas institutions; don’t call these 40 all Mainland-born students.

Cannot use names alone for later Steam matching: match organiser public game title, developer/team identity, gameplay/artifact, and official lineage. See AGENTS TITLE_COLLISION_EXCLUDED rule established after Taiwan 2025 ‘Backpack Dungeon’ false match.

4. Next independent follow-up

Now that 40/40 title-and-team roster is established, follow these without outcome-based recruitment:

  1. First, attempt 75 prelim list recovered from source image by human-inspected transcription with dual-pass confirmation or organiser accessible table/export. Do not auto-fill 75 from 40 finalists.
  2. If 75 unavailable, 40 finalists can be followed as a selected cohort: exact same order for all 40: 2024 organiser game footage/screenshots → contemporaneous public creator page → Steam/itch/GmHub/TapTap public store → subsequent publicly linked new works. Record search terms and date.
  3. RELEASED / DEMO / CONTINUED / NEW_CREATOR_PROJECT / NO_MATCH_AFTER_LOGGED_SEARCH / CANNOT_ID_MATCH are different outcomes. Don’t label the missing as failure.
  4. To measure creator formation, separately sample pre-entry or registration-not-submitted students, not only those 40.
  5. For Japan Game Parade 作品形式=ゲーム vs プレイ可/download, see Japan 005: even a ‘game’ page can be video-only, not playable; school exhibitions have another observable gate.

5. Results boundary

This is a verified roster-reconstruction milestone, not an outcome conversion rate. In particular 40/40 completeness applies only to the nominated-title-team public listing; it does not mean original unique app IDs, player-download links, nationalities, 2026 release outcomes or employment paths were verified.
