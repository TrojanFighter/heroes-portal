038 — 从考试成绩到第一件作品：CEPS × PISA × Game Jam 的创作者形成管道审计

  • Status: SOURCE-LED EMPIRICAL INFRASTRUCTURE / CROSS-SOURCE DENOMINATOR AUDIT / 2026-10-10
  • Parent: 037家校自主权与英雄未出发、031自主探索、032 Exam Overfit、018创作者三层约束、OQ-023
  • 核心改动：不再只依赖有代表性的创作者轶事证明教育问题，给“谁有机会制作第一份游戏”建立可核的数据来源目录、测量定义、反例压力与调查落地方案。三套资料的分母不同，不得拼接为全国流失率。
  • 知识纪律：公开页面事实≠已下载和运行微观数据；活动参与者≠普通青年人口；创造性思维测验≠自我出题能力；艺术/游戏兴趣≠注定成为商业独游作者。

0. 最重要的认知修正：四种“创造性”不是同一个东西

层次 可测的产出 现实困境 代理变量局限
Creative Thinking 在已有任务里产生、评估、修订多样想法 很多创造力测验仍由考试系统提供题目 不能直接测是否会自主定义一项人生/创作问题
Problem Ownership 能主动选择题目、寻找信息、改变目标 人可能知识充分，但缺少决定目标的权力与练习 自述“喜欢创新”不足以证明实际选择行为
Maker Conversion 兴趣→第一份完成/公开的artifact 缺设备、时间、同伴、工具、合法性或反馈渠道 只数游戏jam投稿，漏掉从未参与者
Authorial Persistence 第二/第三次尝试、真实作品迭代、组队与持续制作 第一次参与容易，长期坚持要承担生活/职业与项目风险 参赛满意度、想再参加≠实际跨年留存

因此我们的书要区分两个本质不同的问题：学生会不会在给定题目下产生新想法？学生是否有机会和权力自行决定做什么，并持续把它变成作品？

1. OECD PISA 2022 创造性思维：强反例，不是中国大陆总体证据

一手统计

OECD 2024年6月18日PISA 2022第三卷正式评估64个国家/经济体的15岁学生，衡量在书面表达、视觉表达、社会问题解决、科学问题解决任务里生成多种想法、提出创意、评估改进的表现。测试范围具有外部给出的任务条件，未直接测量学生自己选题及真实作品生命周期。

国家/经济体 创造性思维平均分（满分60） 信息出处
新加坡 41 OECD 新加坡官方简报
韩国 38 OECD 韩国官方简报
OECD平均 33 OECD 2024 第三卷
中国台北 33 OECD 中国台北官方简报
中国香港 32 OECD 中国香港官方简报

必须禁止： - 大陆未参加本轮创造性思维测试：不能借中国香港/澳门/台湾分数代表中国大陆。 - 把香港32、台湾33描述成缺乏创造力：它们在量表上大致位于OECD均值附近；报告强调相对于其数学/阅读高分，创造性思维的比较优势偏弱，并不等于绝对分数极低。 - 把整个东亚判为“应试杀死创造力”：新加坡、韩国是高学科成绩且高创意思维表现的同时存在反例，韩国内部具备一定传统升学压力，故需分开具体教学与激励机制。 - 将PISA分数与游戏创业率作个体因果回归：年龄、出生队列、国家、工具与招聘渠道、结果变量均不同，尚无微观链接和识别策略。

由此可提出的新假说：即使创造性思维表现不错，Problem Ownership和独立Maker Conversion也未必自动良好；这需要设计另外的观察/实验，而不是仅凭PISA作推论。

2. 中国人民大学 CEPS：已经存在全国学校队列，但未测游戏作者命运

已查实的数据基础设施

人大“中国教育追踪调查”（CEPS）的官方2014年7月16日基线报告明确说明：

  • 2013—2014学年基线：19,487名初一/初三学生，438个班、112所初中、28个县/区，采用学校基础的多阶段概率抽样；
  • 同期还有19,007名家长、1,412名教师及112名学校负责人参与；
  • 项目概况说明其为全国学校学生样本、具追踪性质；技术报告列出的问卷主题涵盖家庭教育、家校关系、课外活动、亲子互动、教育期望、学校设施与教师工作；
  • 公开问卷入口提供学生/家长/教师/学校多方问卷，2015年数据发布消息说明数据用于学术研究。

它能够帮助研究：家庭/学校的控制、学生自主活动与家校互动如何在不同经济和学校环境中共变；既有样本能减少只访谈大学精英/独游作者造成的选择偏差。

它没有自动给出：游戏参照积累、第一次自己立项、第一次完成游戏、jam/mod社区参与、第二次制作或最后成为独游作者的完整追踪变量。问卷具体题项尚待逐页编码；数据虽面向研究开放，目前我们并没有获取微观数据、运行统计或验证所有必要变量存在。不得把“有两万学生面板”误写为“已测量教育挡掉多少创作者”。

时间适用性：2013—2014学生所处智能手机/课外培训/游戏制作工具环境与2026不同；可用于旧出生队列比较，不能直接套为2026当代现状。

最低可执行证据工作

  1. 下载并逐题核对CEPS七/九年级学生、家长、校长、教师问卷，建立VARIABLE EXISTS / PROXY / MISSING对照表；
  2. 若有授权访问微观数据，按抽样权重与学校聚类研究自主活动、家长/学校控制、社经背景的关系；只报告现有变量实际能估计的结果；
  3. 用另行获得知情同意的现代固定队列补FIRST ARTIFACT / INITIATIVE / SECOND ATTEMPT；不得未经授权将旧CEPS个体与当代平台身份拼接。

3. Global Game Jam 2026：有规模的非考试原型入口，但不能代表普通青年

主办方的数据

GGJ 2026官方活动及Jammer调查记载约3.9万人、近1万份游戏、90多个国家。同一官方站点的年度历史页与2026年问卷报道对人数和站点数略有不同（历史页列39,069人、811站，问卷报道列39,197人、824站）。不揣测是最终结算、去重还是口径变更；对外以约3.9万表述，想精确量化须联系主办方核验同口径底表。

调查来源与局限：主办方称活动后自愿问卷收到3,535份，覆盖全体注册者约9%，问题后部回答率更低。报告称： - 28%的答卷人之前完全不认识本次队友；另28%认识一半队友； - 71%的活动站点有导师； - 88%受访者自称学到/提升了技能； - 94%受访者称提交了游戏； - 61%受访者以前参加过某种game jam，只有37%以前参加过GGJ。

这些比例是受访者或报告站点比例，不是随机抽取的一般青年样本。不能用GGJ 94%提交率推定“只要办一次jam就能让94%的孩子做出游戏”，也不能从主办方满意度计算独立游戏创业转化率。相对可靠的论点是：在有短期可实施题目、同伴、导师和公开提交流程的社区，确实存在大量非职业者完成原型的现实例证。存在性、传播规模与教育效果应分开。

中国及青少年入口不是空白

  • GGJ China 2026 CiGA上海线上站公开列有中国参与通道；北京SFK线下站记载公开报名、48小时协作、最终展示/试玩，年龄门槛14+、最大80人；广州SIA站则注明限定参与对象。
  • GGJ Next是面向10—18岁青少年的独立创作项目，不计入普通GGJ成人总体；深圳前海ARTDiCO 2026青少年站点有2026年3月的报名/活动计划。站点公告不等于已核对到场、作品数、费用及教育成效。
  • GGJ Next 2026主办方总结称含GGJ Next和18—25岁Next Gen Expert活动在内，约4,000名学生参与、覆盖70国。不能把4,000全部当成10—18岁，也不能推导中国人数。

这组事实直接反驳“中国完全没有非学校创作入口”的全称命题。它提出更精确、可测量的差别：从学校、家庭到开放社区的引导、接入成本、年龄限制、留存、第二次作品及其对家庭条件的依赖。

4. 统一分母：一次兴趣到反复制作的真实漏斗

不能把CEPS 19,487学生、PISA某经济体15岁学生、GGJ 约3.9万参加者相除、相加或作为同一队列。它们年龄、年份、覆盖范围、测量与选择机制全不同。

未来真实固定队列应对同一进入人群在各时点记录：

阶段 需要知道的分子/分母 关键分类
F0 同龄人群基线 年龄/地区/家庭/学校总样本 不预设所有人喜欢游戏或愿创作
F1 有接触 曾玩/读/观赏各品类、接触可制作工具者/总样本 兴趣与访问权分开
F2 有意愿并能选择 曾自主挑选非考试学习/创作目标者/总样本 可以主动选择不做
F3 第一次尝试 有独立/协作制作动作与过程记录者/总样本 不只收成功作品
F4 第一件完成作品 有可检查artifact者/所有起步者（同时报对总样本） 不等于商业成功
F5 第二次尝试/作品 固定观察窗口内再尝试者/首作完成者（同时报对总样本） 处理失访和退出
F6 可持续作者道路 有长期制作、合伙、收入或作者就业者/进入过F3者 按类别说明含义

失联/不进入/退出原因单独记：兴趣自然转变、课程挤压、家长否决、工具不足、没有同伴、经济支持不足、作品被否定、个人主动不愿做。不存在“没有选择做游戏＝受害者”这样的默认归因。

研究所需的实证比较：同一地区/年级/家庭收入范围内，有无老师/导师/社团、同样课时/考核负担下的F3/F4/F5过渡。需预先指定混杂因素（先前兴趣、硬件、家庭教育、学校质量）、提供置信区间、处理自选择及失访，先报告相关性，再研究真正有识别力的环境变动。

拟议试点：两校＋两个创作社区，但不是“研究已经完成”

  • 学校配对：匹配年龄、城市、家庭收入背景，比较提供课外maker/jam/自主议题时段与没有提供的校区/年级，避免只抽优等生；
  • 社区配对：选中国至少一个GGJ/CiGA或国内独立开发社区与另一个可比社群，不只收站点获奖游戏，还应记录首次参赛与退出、重复参与、实际作品；
  • 公开观察表：自行设计的调查需征得同意，未成年人经必要监护同意，并作匿名与最小必要采集；
  • 效果终点：不是“谁成功创业”，而是是否有自己定义/改变题目的真实机会、完成第一件作品的比例、同一人下一次仍敢尝试的比例、工具/人员支持对这些过渡的影响；
  • 同时测创意任务与原型行为，检查“创造性测试优秀但不动手”和“考试表现普通但能持续做作品”的实际发生率。

5. 对书稿的反向约束

可以写成有研究价值的前提： - 一些年轻人在行业出现前就不曾得到选择题目与制作作品的机会； - 国际创作活动说明非正式社区是一种可供调查的转换基础设施； - 中国也存在游戏jam与青少年活动站点，真正需要比较其覆盖率与持续性； - 东亚教育存在高学科成绩且高创造性思维分数的反例，不能做文化本质论。

仍不能写成确定性结论： - 中国教育压制了某个确定数量或比例的未来独游作者； - 新加坡或韩国一定比中国有更多商业独游作者； - PISA测试成绩代表自选目标与创作生涯； - 成绩压力/父母控制是已测量的全国独游创作人数差距的最大因； - 参与游戏jam必然增强长期作者能力，或94%普通学生参与后会出作品； - 深圳站点存在即证明整个城市所有学生都能无条件进入此类教育生态。

下一阶段最优投入：先把CEPS问卷的变量核查与GGJ/CiGA非获奖参与者和退出者的真实基数补齐，再谈因果及国别量级。若不能拿到这些数据，保留H/OPEN而不是进一步增加相同论点的英雄传记。

6. 2026-10-10 修订：创意题分数 ≠ 游戏知识语料与设计范式掌握

作者修正的来源与地位：作者依据多年游玩《铁血联盟2》（Jagged Alliance 2）与《R.U.S.E.》及国内Game Jam群聊截图提出：高考试能力+有限信息摄入可能导致“在有限材料内部高效排列组合”，但不足以产生进入游戏行业时有竞争力的新系统。截图显示部分Jam开发者对联网、枪械、素材和UI的不同完成顺序，以及多名成员对培训机构Jam履历化/预制菜的指控。仅作为内部观察与假说来源；不公开参与者ID、群聊详情或认定具体个人/机构违规。

6.1 不应遗漏的五个独立变量

变量 要测量什么 重要边界
Information Diet / 信息饮食 真正接触过多少不同设计范式、历史阶段、媒介、玩法，不只游戏时长与热门游戏数量 输入多不自动高质量，重复同质信息不会同比增加有效参照
Relational Model / 规则关系理解 能解释一款游戏哪些规则/约束产生具体决策与情绪结果 “玩过/通关”不等于理解其机制
Cross-Domain Transfer / 跨类型迁移 能把战略、战术、经济、叙事等不同语法重组，预测冲突并做原型 组合可能产生真正有价值的新品类，但需测试
Problem Ownership / 问题主权 谁选题，能否拒绝题目、修改目标、承担停止决策 有想法与有权实际实施是两回事
Artifact & Feedback / 原型验证 从设计假设到试玩、反馈、修订和第二次尝试的可核过程 外观完成、联网框架、参赛证书并不等于核心玩法成立

更恰当的假说不是“应试生没有创造力”，而是：如果教育/家庭/平台长期奖励读少量指定资料→在指定问题中给高分→减少额外阅读/游玩/制作时间→从几个热点范式中挑选预期安全的项目，那么问题搜索空间和可迁移的游戏语法可能变窄。这条链每一步都须实测，不能把任何成绩优良者认作必定如此。

作者的JA2与R.U.S.E.例子展示不同层级设计知识的潜在互补：前者将个人战术/角色/装备/战略资源联系起来，后者把侦察、欺骗、信息不完整与战场行动联系起来。不同规则集使可想象组合更丰富，但作者个人作品及设计能力的相对优势仍需外部试玩盲评，不因自述玩得多而自动认定“碾压全部学生”。

6.2 PISA 2022创意评估究竟能反驳什么

OECD原始2022创造性思维框架注明：设计给15岁、约60分钟、共同给定题目/情境，原创新颖性参照同一题目其他学生答卷；并未测试从兴趣到原创商业游戏的数年积累。

该测验实属开放回答、有新颖性评价，并非普通机械做题，其分数有效反驳“东亚学生完全不会在给定新问题上产生不同想法”；但不评价游戏类型阅历、玩法语法、非考试自主选题、跨类型设计创新、原型长期存活率。其内部也承认领域知识与准备度影响表现。

2025年OECD进一步分析在完成多个创意任务的样本中发现，跨多个情境同时高分的学生占比有限，进一步支持区分“在一个被给定的题域里表现好”与“可以跨题域长期生成和评估创造性作品”。

Boden概念空间框架：组合式、探索式、变革式创造各自有价值，不可把一切组合式发明视为低级；Boden的原始理论摘要、探索式游戏设计论文均强调知识材料、原型与试玩反馈。真正需要审计的是设计规则能否改变真实玩家决策，而非“元素借鉴得是否够原创”。

6.3 Game Jam 的双重机制：探索入口 vs 可购买履历

先分类三种不同情形： 1. 合法的工程复用：用旧引擎、服务器通用件、合法素材/代码工具加速，现场才提出新玩法、形成可信原型；不应被叫作弊。 2. 赛前练习和导师训练：符合规则、真实参与并能解释自有贡献，可为新人创造学习机会；即使作品能用于求职也并非无效。 3. Credential Substitution / 创作凭证替代创作能力：在求职/升学/作品集目标下，先产出高度模板化的核心游戏或让机构代做，现场仅替换主题、美术、局部功能，却以限时自主原创包装。这会使看似有作品的指标与真实设计/工程能力脱钩；其发生率和中国相较海外的差距UNKNOWN。

国际规则的实际边界：GGJ 2025基督城站FAQ允许预存代码/美术/音效，但明确不允许直接带完成的游戏；GGJ 2026另一站的FAQ要求披露预制资产。各站规则不完全相同，不得把“用了旧素材”直接等同于违规。

国内商业化事实证据： - FSG游戏留学服务官网把Game Jam竞赛、个性化作品集、院校/海外申请与大厂实习纳入同一服务目录；这证明履历化供给存在，不证明作品代做或违规。 - 共创世界2026 Game Jam活动宣传直接把Jam与白名单赛事、升学竞争和赛前14天特训相联；说明创造性活动可以被考试激励吸纳，不代表赛事或参加者都不真实创造。 - 2025未来游戏制作人种子训练营将Jam、证书、推荐信和作品联系为职业路径；提供履历化经济激励的另一事实入口。 - 对照2024年CiGA参赛者技术复盘，有参与者具体记录首次包体、玩家试玩和继续修复BUG的问题，说明中国也存在直接以真实原型反馈为核心的Jam实践。不能把最具争议的聊天截屏当国内整体的随机样本。

6.4 全新的验证口径：不再只数Jam作品和参加人次

首作来源 同届参与者赛前已有的可玩核心/素材清单，版本库时间戳、许可、真实声明 合法复用与假冒现场原作混同

制度设计建议：Jam/学校可把“参赛证明”和“过程能力证据”拆开，允许所有人如实披露复用、外部辅导与团队分工；以主题揭晓后的设计决策日志、玩家首测录像、变化对照、真实贡献和复盘评价培养效果，而不是以48小时完成度、UI外观、证书数量作唯一指标。其效果仍需评估，不把审计再做成重型KPI。

6.5 更新本书的核心研究框架

之前关注：家校是否允许探索 → 有没有第一件作品 → 是否能持续。

现在加上一个从前端到后端都不能省略的结构变量：学生究竟接触过多少种值得研究的世界/产品/系统，是否有足够时间理解这些系统，而不是只学少数得分模板？

《独立游戏英雄传说》因此必须同时研究：KNOWLEDGE DIET / INPUT DIVERSITY、GAME-DESIGN LITERACY、PROBLEM OWNERSHIP、ARTIFACT/FEEDBACK、CREDENTIAL INCENTIVE。只有把这些分别量化，才能比较“高分创造性测验”与“原创游戏产品竞争力”之间真正的落差。

7. 做出第一件作品后，谁能继续控制它？（2026-10-10）

见中国039：原来的Maker Conversion/F3–F6漏斗还需审计探索权、创意否决、预算、IP/续作、收益与退出权。Supercell Spark用16周Jam和组队评估团队而非单张履历；Roblox Jumpstart提供的主要是服务和平台资源而不是工资；Kowloon Nights/Indie Fund有具体、但不同的财务和IP安排。中国有Gamera与大学扶持的真实反例。宣传扶持≠受支持者实际拥有权利≠长期独立续作的因果效果。
