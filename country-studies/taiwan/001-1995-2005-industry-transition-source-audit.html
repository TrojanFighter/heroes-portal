001 — 台湾游戏产业1995—2005转轨：研发、发行、代理与两岸市场（同期来源审计）

  • Status: SOURCE-AUDIT / PRE-CLAIM / FIRST PASS
  • Program: C (Taiwan comparator to mainland industry-history)
  • As of: 2026-10-07
  • Source window covered: 1999-06 to 2004-09, 不是1995—2005完整时序
  • Research question: 游戏生产的利润和决策权怎样在研发、发行、海外代理及跨地区经营之间重新分配？
  • Unit warning: 一家工作室／一款发售作品／市场整体营收／网游产品数属于不同单位；不能静默合并。

0. 初步发现（不得升级为因果定论）

  1. 原创供给衰退早于韩国网游热潮的全面扩张。 1999同期报道已称1998约300款上市游戏中台湾本土制作不足60款，且约1995的40—50家制作公司/工作室高峰后出现团队消失。报道指向 Windows 95技术平台转移、融资、盗版、发行与规模经济等多项解释；目前不能据此识别单一主因。见 E01。
  2. 单机到网游并非「台湾厂商停止开发」的同义词。 2002/03报道说明部分传统厂商裁并单机部门、转投网游与韩国产品代理；同时雷爵《万王之王》、中华网龙、昱泉等亦存在本土研发。不同公司出现代理、自研、合作研发和代工几种生产模式。见 E03—E08。
  3. 发行/代理优势可以先改善现金流，却不一定制造原创产品能力。 2003年MIC经新闻报道给出网游代理产品高达约80%的说法；但是80%究竟是上线产品、销售额、玩家份额或其他口径仍未核原始MIC表，绝不能写成已审计营收占比。见 E05。
  4. 台湾与大陆当时是耦合市场，不是两个独立实验组。 2002年资料列举台湾厂商在大陆投资研发、代理、合资；2003报道又呈现大陆业者逐渐直接获得韩国代理权并扩张本土研发。必须研究台湾生产能力向大陆转移/混合、监管差异和市场规模共同作用。见 E04、E09。
  5. 融资和创作主导权冲突具有早期同期证据。 1999年的融资采访涉及宇峻成立初期难获银行抵押贷款、VC偏好上市路径、开发周期空窗与发行投资对控制权的影响；不是2020年代独立开发才出现的问题。见 E02。
  6. 观察到逆向选择与组织分叉。 昱泉2003年自报单机代理退货与营业损失，同期探索由外部承担100%研发费用、公司保留产品权利的合作开发方案；其他代理商则尝试建立内部研发组。不能把「代理→研发」与「研发→代理」二者抹平成一个单线衰退故事。见 E07、E10。

1. 同期证据登记（报道本身为S1；具名当事人的同期引述可作P0 testimony，但并非独立核算）

E01｜1999-06-29，王佳琪，《製作公司急速萎縮，產業分工不清》，iThome。
URL: https://www.ithome.com.tw/news/3856
文中转述 MIC：1998年台湾游戏最终消费额新台币28亿元；转述《电脑玩家》统计：市场约300款游戏、本土制作少于60款；称1995年左右约40—50家制作公司及工作室。提及 Windows 95转移、盗版、资金和发行；举第三波研发团队独立后与原公司项目投资合作、智冠内部利润中心和版税制度之例。边界：28亿是1998总体终端消费；300/60是款数，不是销售额或发行商数量；40—50为媒体保守估计而非工商登记全数。原始MIC/《电脑玩家》表格尚未回收。

E02｜1999-06-30，王佳琪，《遊戲製作市場風險大，資金來源成問題》，iThome。
URL: https://www.ithome.com.tw/news/3865
报道研发薪资/设备投资少则新台币100万—200万元、开发半年至2—3年；宇峻科技施文进谈早期融资、银行抵押和政府流程；创投协会人士谈开发团队难获VC与出让主导权风险。边界：成本范围为报道当时的粗略估计、非代表性均值；宇峻经验为具名当事人证词，不可推出台湾融资成功率。

E03｜2002-01-27，Lin Chieh-yu, “Gamers find their thrills online”, Taipei Times。
URL: https://www.taipeitimes.com/News/feat/archives/2002/01/27/121697
报道称第三波、华义、智冠、华彩缩减或合并单机业务，资源投向网游；记述台湾网游市场的日本/韩国产品代理及收费模式。边界：描述2002年当时部分公司；“缩减单机部门”≠公司不再研发任何游戏，亦不证明所有企业一致。

E04｜2002-04-16，郭晏铨，《臺灣遊戲軟體廠商在中國大集合》，iThome。
URL: https://www.ithome.com.tw/news/16750
列举昱泉、智冠、第三波、华义等大陆业务；大宇、宇峻、奥汀、弘煜、风云时代合资成立寰宇之星；台湾厂商在北京、上海等设研发中心。边界：可证明当时媒体报道的公司行动；不能推得跨海峡人才迁移净额、研发产值或创新控制权。

E05｜2003-11-25，杨惠芬，《臺灣線上遊戲市場80%依賴代理》，iThome。
URL: https://www.ithome.com.tw/news/22799
报道转述MIC的网游代理约80%、本土自研约20%；2003年预计游戏软件市场新台币74.3亿元，其中在线48.8亿、单机25.5亿。边界：代理比例的原始分母和统计方法未见MIC原表；74.3/48.8/25.5为预测，不能当已实现财报。也不得将其与E01的1998终端消费额直接计算增长率。另2003-02-27 iThome 《本土廝殺有時盡，擴張深耕兩相宜》有「2003网游74.3亿元」不同表述，必须先核对指标/修订版次，暂标 SOURCE FIGURE CONFLICT / UNRESOLVED。

E06｜2003-01-08，陈卓君，《臺製線上遊戲陸續出籠，與韓國業者爭市場》，iThome。
URL: https://www.ithome.com.tw/news/19485
报道游戏橘子、智冠、第三波及其他厂商的自研计划；数码戏胞负责人称按其业务判断，自研网游与代理网游的盈亏平衡CCU可能分别在5000和11000人左右。边界：这是单一业者的口径/预期，非行业工程事实、非财报；报道中的“计划发布”需后续核实到底是否发售。

E07｜2003-08-28，杨惠芬，《昱泉、Sammy攜手研發TV Game》，iThome。
URL: https://www.ithome.com.tw/news/21820
昱泉管理层同期陈述与 Sammy Studios 的合作开发模式：发行与研发费用由对方承担，昱泉提供技术并取得产品权利；财务长称2003上半年亏损约新台币9500万元，涉及自家产品不如预期、30余款代理单机退货。边界：费用负担、权利分配、亏损为新闻中的公司当事人说法；合同与审计报表未见，合作项目最终交付与真实权利后续仍UNKNOWN。

E08｜2003-05-28，陈卓君，《臺灣網竣跨入遊戲代理，今年將代理10款遊戲》，iThome。
URL: https://www.ithome.com.tw/news/20816
一位代理商反向指出：网游运营竞争成本很高、单机代理门槛更低，且自报旧作发行销售约2万套。边界：这一商业判断不代表整个台湾市场利润分布；提供对「凡在线皆更赚钱」的同期反压力。

E09｜2003-03-18，陈卓君，《大陸自製、代理遊戲商出籠，臺灣廠商面臨挑戰》，iThome。
URL: https://www.ithome.com.tw/news/20106
记录韩国厂商从经台湾代理两岸转向与大陆公司直接合作，以及大陆研发厂商崛起。边界：某高管称「从台湾过去的研发团队60多个」未具可核定义/名录，禁止作为迁移人数或团队数统计，仅作可追查的线索。

E10｜2004-09-03，杨惠芬，《數碼戲胞跨足遊戲軟體研發》，iThome。
URL: https://www.ithome.com.tw/news/25929
报道原以代理Nexon为主的数码戏胞建立自研团队；管理层称代理改版受原厂限制，因此追求自己的产品研发主导权。边界：筹备/预计研发小组数不可等于实际成立与成功上线；这是企业战略证词。

E11｜2002-01-04，署名Default，《Online Game遮去市場半邊天》，iThome。
URL: https://www.ithome.com.tw/news/15682
记者转述MIC 2001-12数据：台湾整体游戏市场1999年约新台币34.85亿元、2000年42.83亿元、2001年49.4亿元；在线业务2000年约4.8亿元、2001年17.1亿元；2001年单机32.3亿元。报道记录部分公司转型与ISP/网咖/付费连接。边界：2001的49.4亿元是单机＋网游的整体市场，绝非单机销售额；2001年32.3亿元单机与2000年约38.02亿元对比才符合约15%下降。原报道某句把「1999年38亿元」写作基期，与2001-12 MIC表中2000年38.02亿元矛盾，优先保留表中年份并标记新闻内部疑似笔误，直至回收MIC原表。

E12｜2002-10-16，谢茂青，《線上遊戲產業與廠商動態》，MoneyDJ投资研究档。
URL: https://www.moneydj.com/Z/ZH/ZHD/ZHDZ/ZHDZ.djhtm?a=36DD61D7-2906-4E98-A401-09A70F1AC7ED
该份投资研究而非官方报表收录标注MIC 2001-12的细分序列：1999年单机33.95／在线0.90／总34.85亿元；2000年单机38.02／在线4.81／总42.83；2001年单机32.30／在线17.10／总49.40；2002—2004栏标为预测(F)。另引用MIC/ITIS的研发、发行、通路价值链分析及台湾厂商在大陆市场的竞争变化。边界：投资分析存在股价与个股立场，不能把估算的「价值链比重/毛利率/厂商获利比例」当实际分配凭证；同一资料将2002—2004预测表述成确定结局则属于误用。台湾网游2003规模在不同年月预测存在修订与不一致，须取得原始MIC版本归因。

2. 预备性因果图（HYPOTHESIS，不是结论）

本地付费市场/盗版/支付习惯 ─┬─> 单机回收机会 ─┬─> 开发者存续/资金压力
技术平台迁移(Windows/3D) ───┘               │
渠道/代理/授权收益结构 ────────────────> 研发 vs 代理 vs 自研网游 vs 合作开发
韩国产品与网吧网络 ─────────────────────> 竞争基准与技能需求
大陆市场开放/扩大 + 两岸资金与人员流动 ──> 市场份额/海外设点/技术与团队配置
治理、融资与主创控制权 ────────────────> 可立项项目种类与个人退出路径

四种竞争解释，未来逐个压力测试

  • H-TW01 渠道/代理回报优势：能够更快变现的进口代理挤压高风险原创。反例：E06/E10存在从代理转自研；E08认为某些单机反而比在线代理更便宜。
  • H-TW02 技术/资本门槛上升：Windows/3D/联网维护带来成本提升，弱小工作室退出。反例：需要寻找低成本仍稳定原创的台湾厂商。
  • H-TW03 两岸市场网络转换：台湾企业早期跨海峡扩张，后来大陆市场扩大重塑代理与研发谈判权。反例：没有进入大陆也长期存活的台湾研发团队。
  • H-TW04 发行合作与作者性张力：融资和发行控制权改变可做的产品。反例：智冠利润中心版税制、昱泉出资/版权合作组合可能提供不一样的组织实践；都要核最终执行而非只读公告。

3. 重点未核与下一步取证

两条跨期修正已移交专档： - 007 — 两岸选择效应：2002大陆作为台湾低成本研发腹地、2010s后大陆高薪反向虹吸台湾人才；台湾早期日本/欧美信息先发也单独审计。 - 中国016 — 大陆末代单机能力退出：避免把“大陆后来网游强”误写成“大陆此前单机能力不足”。

  1. 追回MIC 1998—2004的原始统计表/报告目录，定义「网游代理80%」的分母；并审查2003年预测74.3亿元两种冲突口径。此处为P0/原始统计最大缺口。
  2. 追回1995左右制作公司名单与生存轨迹：哪些消失、改名、被并购、转做代理/网游、跨海峡合作？避免把报刊对“消失”的修辞当正式退出统计。
  3. 个体命运：宇峻施文进、昱泉项目负责人、退出业界的原单机开发者的教育/家庭/技能积累/收入/职务权利；避免只有CEO口述。
  4. 产品型反例：2000—2005持续推出单机新作、独立小团队作品、代理失败、自研网游失败等；用同年份同资金规模比较。
  5. 大陆镜像：2000—2004渠道合同、代理韩游与自研团队人员资料，明确是大陆公司净获得能力，还是跨境公司在两地配置同一能力。
  6. 观察口径：团队、项目、发行作品、收入、盈利、玩家数与贡献者的单位及缺失率分开记录。

目前可作的结论：同期报道足以确认台湾产业从1990年代末起出现本土原创项目减少、发行/融资困境、2000年代初大规模在线代理竞争及跨地区业务扩张；尚不足以确定「台湾原创衰退」的单一主因、普通创作者的遭遇比例，或制度与人才创新力之间的因果效应。
