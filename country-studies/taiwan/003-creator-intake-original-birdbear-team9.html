003 — 台湾创作者 Intake：原始鸟熊 × Team9（能力重组、范围变形与市场接口）

  • Status: EVIDENCE INTAKE / PRE-CASE / NO POPULATION INFERENCE
  • Program: A-case candidate linkage + C Taiwan comparator
  • As of: 2026-10-07
  • Subjects: 原始鸟熊 / 《活侠传》；Team9 / 《文字游戏》
  • Method: Creator Life / Decision Audit；Capability–Project Fit
  • Selection warning: 两案都是媒体可见成功者，属于机制样本，不是台湾普通开发者的代表比例。

0. 为什么把两案放在同一轮

两案都经常被叙述成「非科班／小团队做出惊人作品」。现有一手/准一手材料却显示，更准确的问题不是“他们怎么从零学会游戏开发”，而是：

不同职业与兴趣中已经形成的异质能力，如何被重新组合成项目；项目又如何主动适配或反过来压垮这些能力？

两案都不能拿来证明台湾社会更支持独立开发；家庭、住房、生活 burn、储蓄、伴侣收入、完整失败分母均未解决。

A. 原始鸟熊 / 《活侠传》

A1. 当前可确认的前史与创始关系

OBB-E01｜2024-07-16，游戏角落专访（发售后一个月左右，开发者回顾性访谈；P1）
URL: https://game.udn.com/game/story/122090/8098442

  • 两位主创自高中相识，毕业后进入社会仍保持联系。
  • 两人曾长期讨论共同创业，甚至谈过牛肉面店；后因“鸟擅长写程序、熊有写作与绘图兴趣”，决定做游戏并创造自己的IP。
  • 报道写工作室于2020年成立。
  • 主力开发分工：两人共同发想游戏设计；鸟负责程序与项目管理，熊负责剧情文本与美术。
  • 《活侠传》最初是以闪避弹幕为核心的趣味手机游戏；约经历近一年改版后，团队放弃手机方向，转向PC，增加大量系统和剧情。
  • 边界：报道未提供鸟的完整职业前史、家庭资金、工资/储蓄、生活成本或公司资本来源。

OBB-E02｜2025 TGDF讲者页（主办方机构资料 + 开发者公开简介；P1/机构资料）
URL: https://2025.tgdf.tw/en/speakers/8

  • TGDF写“原始鸟熊成立于2021年”，与E01的2020冲突。
  • TGDF写《活侠传》由两人历时约三年打造。
  • 经济部商工登记已解决“法人何时成立”：原始鸟熊股份有限公司（统一编号83238629）登记日期为2020-12-28，当时资本总额/实收资本均为NT$500,000。官方查询：https://findbiz.nat.gov.tw/fts/company/83238629
  • 团队的X自介及2025 TGDF仍写“原始鸟熊成立于2021年”。因此当前最合理的记录不是二选一，而是：法人登记=2020-12-28；团队公开纪年=2021。后者可能指正式运营/品牌起点，尚无同期说明。
  • 当前登记资本已在2025年后变为NT$5,839,161，但这不是《活侠传》开发预算、融资额或可用runway，不得倒推项目资金来源。

A2. “完全外行”叙事需要修正

OBB-E03｜2024-07-25，游戏角落专访（二）（P1）
URL: https://game.udn.com/game/story/122090/8114531

  • 熊明确表示自己曾在在线游戏产业担任美术相关职位。
  • 因此，“两位完全没有游戏行业经验的外行直接做出《活侠传》”至少对熊不成立。
  • 鸟的职业履历仍UNKNOWN；目前只能确认“擅长程序”及项目内负责编程/项目管理。
  • 该文也记录项目的作者输入并非单纯“传统武侠素养”：两人都很喜欢安科作品，并把“骰子分歧—多路径叙事”转化为核心结构。这是 Experience Capital / Demand Discovery 的可检验入口。

A3. 项目形态是能力适配，同时发生明显 scope explosion

同一来源（OBB-E03）支持：

  • 早期“只能逃不能打”的手机弹幕机制被重写为PC武侠RPG。
  • 决斗系统亦从团队称为“超低级格斗”的简单版本继续演化。
  • 多分支随机叙事造成每个选项都要写后续，形成极高文本复杂度；团队自称埋文本耗时三年以上。
  • 背景建筑因开发时间不足主动简化。
  • 原本2D手绘战斗角色因动作量提升后成本过高，最后将3D赵活外包。
  • 22首配乐由外部“幽火的音乐工作室 / TPOP Studio”制作。

因此“两人开发”必须解释为 two-person authorial/core team，不是“两人完成所有资产与音乐/外包”。

暂定 Capability–Project Fit 读法（H）

  • 熊的文本、美术、在线游戏美术经验 → 大量角色、分支与视觉资产；
  • 鸟的程序/项目管理 → 复杂事件与系统整合、发售后高频修补；
  • 两人共同的安科/武侠兴趣 → 内容结构；
  • 外包3D和音乐 → 将核心团队不适合或边际成本过高的工作外部化。

但项目也显示明显 FIT-CAPTURE / scope capture risk：文本分支、系统与未完成内容不断扩大。成功不能反向证明scope是健康的。

A4. 发售危机提供了“现实裁决”证据，但不能被英雄化

OBB-E04｜2024-08-02，游戏角落专访（四）（P1 + 同期Steam轨迹引用）
URL: https://game.udn.com/game/story/122090/8129682

  • 发售首日Steam好评率接近30%；团队连续四天更新，新增普通模式、自动存档、二周目继承和部分事件自选等。
  • 两人明确称这些并非预先藏好的功能，鸟根据论坛反馈快速实现，再与熊沟通。
  • 团队此前主动反对EA：理由包括剧情型游戏反复等待少量内容会疲劳，以及EA并不保证完成。
  • 熊同时承认正式版仍受现实因素影响、未达到原先“做完才收钱”的标准。
  • 2023-11曾出现“熊个人户头不足400元”的公开说法，但访谈明确说明公司账户与个人账户分离，发售并非因为公司没钱。因此不得把个人余额直接写成项目破产/被迫上市。
  • Steam官方页显示开发者为 Obb Studio Inc.，发行商为 Paras Games 与 Obb Studio Inc.：https://store.steampowered.com/app/1859910/Legend_of_Mortal/
  • UNKNOWN：Paras的预付款、收入分成、地区权利、营销/本地化义务及决策权；这些必须在正式Case前补证。

A4.5. 2021独立游戏开发奖励：必须进入Runway账本

政府公开资料确认《活侠传》为2021年度“独立游戏开发奖励计划”8个获奖项目之一。经济部预算表对同一2021-06-01核准事项先记录NT$520,000，后续汇总表列为NT$780,000并标奖励金。

来源： - https://digiblockc.tca.org.tw/news/d645920e395fedad7bbbed0eca3fe2e0 - https://www.ida.gov.tw/ctlr?PRO=filepath.DownloadFile&f=executive&id=17642&t=f - https://www.ida.gov.tw/ctlr?PRO=filepath.DownloadFile&f=executive&id=18784&t=f

当前处理： - 不能再把《活侠传》写成纯私人积蓄/两人自筹； - 也不能写“2021一次拿到78万”，因为52→78万的拨款/累计机制尚未核； - 总开发预算未知，因此奖励金对runway贡献比例UNKNOWN； - 该奖励发生在公司2020-12-28登记之后、2024发售之前，属于早期production资金的一部分。

A5. 原始鸟熊当前还缺什么

正式Case前至少补： 1. 鸟和熊各自创业前的具体职业、收入/离职时间； 2. 2020 vs 2021成立年份的口径； 3. 家庭、住房、生活runway、储蓄/投资/股权； 4. Paras Games合作起点和合同边界； 5. 原型/试玩版公开时间线及首次可付费市场信号； 6. 全credits与3D、音乐、测试、发行、本地化贡献范围； 7. 同期两人武侠RPG/台湾小团队失败或未发售对照。

当前资格判断：HIGH-VALUE CASE CANDIDATE / NOT READY。

B. Team9 / 《文字游戏》

B1. “没做过游戏”并不等于“没有生产能力”

TEAM9-E01｜2021-01-20，映CG团队专访（正式版发售前；P0/P1边界：当事人同期自述）
URL: https://www.incgmedia.com/all-articles/word-game-interview

采访列出的五人及当时能力前史： - 张文韦：总制作人；接案设计师，平面/展览设计； - 黄威恺：营销与游戏企划；贝壳放大共同创办人； - 陈育律 Hank：编剧；文字工作者，做过文学翻译与创作； - 张文瀚：程序；前端工程师，研究所从事科技艺术、做过新媒体作品； - 邱梁钧：动画美术；工业设计背景并从事动态设计/接案。

2019年后美术梁钧与程序文瀚加入。团队自称此前没有游戏制作经验，但这些不是“零经验劳动力”，而是跨行业成熟能力组合。

TEAM9-E02｜2022 TGDF讲者页（机构+开发者讲者简介；P1）
URL: https://2022.tgdf.tw/en/speakers/wenhan_chang_team9

  • Team9被写为成立于2018年。
  • 张文瀚明确被描述为此前“完全没做过游戏的网站前端工程师”。
  • 团队使用Godot；讲者回顾约两年实际开发流程。
  • 边界：“成立2018”“两年开发”需要与2019成员加入、早期概念阶段区分，不能机械相减为完整生产周期。

B2. 项目从一开始就是 Problem Redefinition

E01显示团队没有把《文字游戏》做成普通“文字谜题关卡集”，而是从一开始决定做成类似JRPG的长篇体验，并把：

  • 文字 = 场景图像；
  • 文字 = 可移动物件；
  • 文字 = 谜题规则；
  • 文字 = 叙事内容；

压到同一表现媒介。

这形成极强的 Capability Leverage：平面/展览、文学、前端、新媒体、工业设计都能直接进入核心玩法，而无需先复制传统3D RPG完整资产管线。

但这并非纯粹“降成本”。采访也明确记录： - 企划不断提出超出现有系统架构的谜题，导致程序特例增加； - 文字动画最初近似逐格，后来由美术开发AE文字遮罩流程，并用3D软件先制作动画后再转成文字画面； - 配乐仍请外部专业音乐人黄镇洋制作。

因此更准确的机制是：

Problem Redefinition把某些传统资产成本删除，但把复杂度转移到文字系统、特例程序和自定义动画工具链。

B3. 市场接口不是“游戏做好以后才营销”

E01还记录： - 团队在独立开发者聚会“增肥聚”和线上社团展示Demo； - Demo吸引到贝壳放大共同创办人/执行长林大涵，促成集资合作； - 团队把众筹视为较早接触玩家和改进体验的工具； - 黄威恺本身横跨Team9和专业集资团队，意味着market capability从早期就是团队能力的一部分，而不是发售末期临时外包。

这与本仓库“Market Interface Is Production”命题高度相关。

B3.5. 众筹之前已经有项目投资，而且它改变了全职状态

2020-05-18 TAICCA官方资料确认：文策院与贝壳放大共同投资“天使放大”IP项目投资公司；天使放大首波合作标的包含Team9《文字游戏》。

https://www.taicca.tw/latest_news/news/detail/318

同期中央社进一步说明天使放大的机制是“单项专案收益分成/作品发行后权利金抽成”，因此这不是普通补助。具体《文字游戏》投资额、分润比例、期限、是否持股仍UNKNOWN。

https://www.cna.com.tw/news/acul/202005180205.aspx

更关键的是，2020同期报道引述负责人张文韦表示，这笔投资让原本业余投入的成员能够转为全职。
https://www.businesstoday.com.tw/article/category/183015/post/202005180036/

因此Team9的runway顺序至少应记录为：

跨行业/接案劳动 → 2020-03-02公司登记 → 2020天使放大项目投资，出现从业余转全职的直接证词 → 2020-11至2021-02众筹 → 2022正式发售

这直接修正“5个接案者靠众筹把游戏做出来”的过度简化版本。

B4. 众筹数字必须拆开，不得把“324倍达标”写成神话

TEAM9-E03｜嘖嘖项目页（P0）
URL: https://www.zeczec.com/projects/wordgame

  • 募资期：2020-11-18—2021-02-09；
  • 名义目标：NT$9,999；
  • 最终累计：NT$3,240,193；
  • 3578次赞助、3263名不重复赞助者；
  • 2022-01-21正式Steam发售（项目更新可核）。

由于名义目标只有9,999元，3,240,193 / 9,999 约为324倍，不能解释为获得了“预算需求的324倍”。目标额明显不是开发总预算估计。正式Case必须区分： - 宣传性/象征性目标额； - 实际众筹毛额； - 平台/履约/周边成本； - 开发者可用净额； - 项目在众筹前已投入的时间和接案收入； - 众筹是否让成员转为全职、持续多久。

2021映CG采访的“超过目标20倍”只是采访当时的阶段性进度或不同时间截面，不能与最终约324倍混作冲突结论。

B4.5. 同一团队后来的制度资金说明“支持”并不等于无条件补助

2025 TAICCA“VR游戏开发/国际平台商业验证”计划从11件合格提案中选3件，每案支持NT$1.2m；Team9《A Black Climbing Dog LITE》入选。

https://taicca.tw/latest_news/plan_bulletin/detail/362?industrys%5B0%5D=5

规则同时要求至少NT$600k自备资金，并绑定Astrea/Meta商业验证与分润。它是Team9成功后的后续资本工具，不得反推为《文字游戏》早期成功原因。

B5. 当前人生审计最关键的UNKNOWN

采访说“大家原先都是接案工作者”，但不能自动推导： - 五人都以接案作为唯一收入； - 众筹前后所有人全职； - 没有家庭支持； - NT$3.24m足以覆盖全部开发成本。

正式Case前至少要补： 1. 2018起点究竟是概念、团队还是公司； 2. 五人在2018—2022各阶段的full-time/part-time状态； 3. 接案与开发的时间/现金关系； 4. 黄威恺/贝壳放大的商业合作条款、是否收服务费或其他权益； 5. 团队所有权、IP和发行权； 6. 外部配乐、QA、移植、本地化等完整perimeter； 7. 商业发售结果及下一作/团队存续； 8. 同期其他“跨行业非科班”台湾团队失败对照。

当前资格判断：HIGH-VALUE CASE CANDIDATE / NOT READY。

C. 两案对照后新增的研究判断（H）

机制 原始鸟熊 Team9
核心组合 程序/项目管理 + 文本/美术 设计+营销+文学+前端+动态视觉
游戏行业前史 熊有网游美术经历；鸟未知 自称此前没做过游戏
项目塑形 手机弹幕 → PC武侠RPG 文字媒介 → JRPG结构
复杂度代价 分支文本/系统规模膨胀 谜题特例/文字动画工具复杂度
外围能力 3D外包、音乐工作室、发行商 专业配乐、众筹专业网络
市场接口 试玩/Steam/发行商，完整时间线待核 Demo聚会+社群→众筹→Steam
人生runway 大量UNKNOWN 接案存在，但现金结构UNKNOWN

暂定命题：TW-CN-H04A

“非科班”最值得研究的不是学历标签，而是传统游戏工业以外的能力是否能够被一个足够特殊的项目重新定价。

反证要求： - 同类跨行业背景但做普通游戏/失败的台湾团队； - 传统游戏从业者同样能有效进行Problem Redefinition的案例； - 跨行业能力实际没有进入核心产品、只是履历装饰的案例。

只有完成这些反证后，才有资格把两案提升为更广泛判断。
