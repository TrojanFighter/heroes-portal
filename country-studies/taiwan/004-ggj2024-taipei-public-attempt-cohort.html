0. 为什么这个队列比“台湾优秀独游”有用

它的入选条件是固定时间 + 固定场地 + 实际参加jam并提交作品，不是销量、媒体采访或奖项。

因此可以观察： - 普通公开尝试者是否继续制作； - 哪些项目留下GitHub/itch痕迹； - 多少人两年后还参加jam或做游戏； - 哪些完全没有可观察后续。

但它仍不是台湾人口/游戏从业者概率样本：参加GGJ本身已经经过兴趣、时间、城市和社群自选。

4. 已确认的“生产痕迹”例子，但暂不计成功

若干项目页已公开： - The Slap 有GitHub repository和明确6名左右分工（程序、美术、设计/声音）； - 神說，讓我笑 有GitHub、itch playable； - Win87 有GitHub、itch playable； - 笑到終點 有GitHub； - LetMeLaugh 有GitHub和可在线游玩版本。

这些只能证明jam期公开artifact和团队协作，不等于后续开发、商业发行或职业转化。

第一轮个体追踪已经证明这个队列内部能力差异很大，因此它不能被叫作“新人队列”：

  • GGJ用户“鄒佳宏”页面显示其2024参与《神說，讓我笑》，2026又参加MIT Game Jam #14并有新作《HELL-o-WORD》。这是“持续公开创作”的可追踪实例，但不等于职业化或创业。来源：https://globalgamejam.org/users/zoujiahong
  • F组《Make Me Laugh》成员古明弘的GGJ个人页在“Past Games”中列出Steam作品，并显示2025《星塵入海 reStar》、2026《情緒按摩師》等后续jam作品。来源：https://globalgamejam.org/users/guminghong
  • 其中Steam App 2251430《Original》在2023-07-05已正式发售，即早于本队列的2024 GGJ。因此至少一位参与者在入组时已经有商业Steam发行经历。Steam记录入口：https://store.steampowered.com/app/2251430/Original/
  • 古明弘2025又参加同系列MIT Game Jam #13《星塵入海 reStar》：https://globalgamejam.org/games/2025/xingchenruhai-restar-4

这几项只支持一个方法论修正：本队列是public creative-attempt cohort / 社群创作队列，不是beginner cohort。后续coding必须新增： - pre_2024_commercial_release - pre_2024_game_jam_history - pre_2024_professional_or_public_portfolio

否则会把“已有开发者继续参加jam”误算成“jam把新人转化成开发者”。

5. 与深圳南山试点怎么比

跨海峡公共平台栈审计见：015 — 台北 × 深圳GGJ公共作品栈。015已核本会场至少7/10实际组有GGJ页直接暴露的公开源码/仓库链路，同时保留GitHub diversifier、参与者前史和深圳可观察性不对称等竞争解释；不得直接计算“台湾公开率高于深圳”。

当前不能直接比较“台湾10 vs 深圳16”，原因： - 深圳当前统计单位是16条官方目录listing、15个不同题名，尚未完全重建实际团队数； - 台北第一会场已经借主办方纪录校正为10个实际组； - 台北报名规则要求一定制作熟悉度，深圳站规则不同； - 城市、主办网络、场地容量、参与者职业构成均不同。

下一步应该先把双方都统一成：

actual event teams → GGJ project artifact → public contributor perimeter → 24/36-month public follow-up → commercial release / continued creation / no observable trace / unknown

再比较可观察转化，并始终保留self-selection和missingness。

6. 下一轮 follow-up coding

每个项目逐项填： - repository_alive_2026 - itch_or_store_release - same_team_continued - individual_creator_continued - next_jam - commercial_project - employment_provenance_observable - media_featured - no_public_trace_observed - unknown_due_to_identity_or_alias

禁止把： - NO PUBLIC TRACE OBSERVED 写成“退出游戏行业”； - GitHub更新写成“职业开发者”； - 参加下一届jam写成“创业”； - Steam发售写成“商业成功”。

完成十组follow-up后，本队列才有资格成为台湾“普通公开尝试者”的第一份纵向资料。
