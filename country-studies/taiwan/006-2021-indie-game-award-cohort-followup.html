006 — 2021台湾独立游戏开发奖励：8个获奖项目的纵向追踪

  • Status: COHORT FOLLOW-UP / SELECTED-WINNER FRAME / NO TREATMENT EFFECT INFERENCE
  • Program: C Taiwan comparator
  • As of: 2026-10-07
  • Sampling frame: 2021年度“独立游戏开发奖励计划”官方8个获奖项目
  • Unit: awarded project, not individual developer
  • Core question: 被该计划筛选出来的项目，之后是否公开发售、转平台、延迟、继续开发或消失？
  • Critical restriction: 这是“获奖者队列”，不是所有申请者，更不是随机处理组。不能用发售比例证明奖励计划造成发售。

0. 为什么研究完整8案，而不是只看《活侠传》

单看《活侠传》《廖添丁》《Alina》会产生严重的成功者偏差。2021官方名单恰好提供一个固定、完整且较小的获奖队列，可以先回答：

评审筛选出来的8个项目，到2026年分别发生了什么？

这仍回答不了： - 未获奖申请者的命运； - 奖励本身提高了多少发售概率； - 如果没有奖励，项目是否仍会完成； - 获奖团队的利润、创作者收入和长期存续。

但它至少比“挑几个成功者讲故事”前进了一层。

TW21-AWARD-E02｜2021申请资格本身已经选择了“公司化团队”
https://digiblockc.tca.org.tw/news/3416a75f4cea9109507cacd8e2f2aefc

Q&A明确要求申请人： - 必须是依台湾公司法设立； - 公司成立未满5年； - 不能以个人身份先申请、获奖后再成立公司。

官方理由明确提到公司资金运用、组织机能及奖金发放可确认性。

因此本队列的分母从一开始就排除了： - 尚未公司化的个人开发者； - 仅有私人原型的人； - 不愿/不能先承担公司设立成本的团队。

这不是台湾“所有独立创作者”的起点。

3. 为什么7/8看起来很漂亮，但因果上非常危险

3.1 Selection on maturity

至少《廖添丁》在2021-11-01发售，仅距5月获奖约半年；《夜之岛》也在2021年公开发行。它们在评审时显然已经不是只有概念的早期项目。

因此评审可能本来就偏好： - 已经公司化； - 有可玩版本； - 能在近期交付； - 有既往开发能力； - 有较明确商业路线的项目。

高发售率可能主要来自选择机制，而不是奖励造成的提升。

3.2 Missing rejected comparator

当前不知道： - 2021共多少申请件； - 未获奖项目名单； - 未获奖项目2021—2026发售率； - 评审时各项目成熟度。

没有这些分母，无法估计 treatment effect。

3.3 Award amount is not total budget

同一批2021项目在政府公开表中出现两组金额： - 较早表：约NT$400k / 520k / 640k档； - 后续汇总：约NT$600k / 780k / 960k档。

金额呈1.5倍模式，强烈提示可能存在阶段拨付/累计口径，但历史规则尚未核定。

因此： - 不用较大数字当一次性现金； - 不把奖励额当开发预算； - 不计算“政府出了项目X%成本”，除非拿到总预算和实际到账口径。

4. 八案里最值得继续研究的四种机制

A. 《机辩意识》：获奖但长期未发售

Steam:
https://store.steampowered.com/app/1869030/Project_Court_2050/

截至本次核验仍显示 Coming soon。

它是这个队列最重要的反压力样本。下一步应核： - 2021评审时完成度； - 之后公开开发日志； - 团队/公司是否仍存续； - scope是否扩大或技术更换； - 是否有其他收入维持； - 项目暂停、重启或持续开发的证据。

在没有开发者/公司明确声明前，只能标为：NOT RELEASED / PUBLICLY LISTED / CURRENT STATUS UNKNOWN BEYOND STORE PAGE。

B. 《风暴驭使》：个人原型→为融资公司化→最终PC发行

2023 GNN采访：
https://gnn.gamer.com.tw/detail.php?sn=260479

创作者“老游”自述： - 起初个人独立开发； - 后来遇到资金问题； - 带原型找资源； - 发现政府奖励或民间投资以个人身份接洽限制很多，因此成立碎盾游戏； - 2023团队为3名全职员工。

2024商业版：
https://store.steampowered.com/app/2321350/StormEdge/

Steam记录2024-09-13发布，开发商Shieldbreaking Games，发行商HypeTrain Digital、Edigger。

这个案例直接说明公司化门槛可以反过来塑造组织：不是“先想开公司再找补助”，而可能是“要进入资金系统，所以从个人原型转成公司”。

但还有重要未解： - 2021获奖项目名为“手机游戏开发专案”，最终Steam产品为PC； - 是否是同一代码/产品连续演化； - 奖励契约是否允许平台变化； - 手机版是否曾单独完成/结案； - 后续发行商资金与政府奖励的相对作用。

C. 《夜之岛》：众筹不一定是生存融资

当前Google Play：
https://play.google.com/store/apps/details?id=com.Yutuo.NightMarket

页面仍可见，显示鱼拓有限公司、1万+下载。

这个项目后续还需结合其众筹FAQ核验团队自己的说法：如果团队明确表示游戏即使未达众筹也会完成，那么众筹更接近社区/传播/周边接口，而不是“没有这笔钱就做不下去”。

这可防止把所有crowdfunding机械编码成runway。

D. 《摇摇星球》：奖励项目可长成“自研+委托开发”的混合公司

大顽游戏官网： https://www.daonegames.com/about/ https://www.daonegames.com/works/

公司将《摇摇星球 / Boba Cafe Fever》列为自研、iOS/Android已上架，并称获得Google Play Best of 2023；同时公开“20+委托开发项目”。

因此后续应研究： - 委托开发是否为自研提供现金流； - 奖励发生前后收入结构； - 自研与B2B项目如何分配人力； - 当前App发行主体/版本变化。

这与本仓库“work-for-hire养原创”的既有案例可以形成台湾对照。

5. 目前已经能得出的更强结论

结论1：台湾的独立游戏奖励不是面向“卧室里的个人开发者”

2021规则明确要求“公司成立未满5年”。因此它更准确的定位是：

给已经跨过公司化门槛的年轻游戏企业购买额外研发时间与组织稳定性。

这会产生明显的 access selection。

结论2：公司化本身可能是资金系统诱导出来的

《风暴驭使》创作者的回顾证词直接说明，他因为个人身份难以取得政府奖励和民间投资，才成立公司。

这提供了“政策工具→组织形态”的机制证据，而不只是“公司→申请补助”。

结论3：项目发售率高，不等于政策有效性已经证明

7/8公开发售/1待发的描述性结果值得保留，但更像是在告诉我们：

评审筛出的项目成熟度可能很高。

真正要判断奖励是否产生additionality，至少需要： 1. 全部申请者/落选者； 2. 申请时项目成熟度； 3. 资金到账时间； 4. 没有奖励时的团队计划； 5. 实际改变的工作时间/headcount/scope； 6. 项目长期商业存续。

6. 下一步研究设计

大陆平台型对照：中国014 — China Hero Project第一/二期固定入选队列。两者只能比较selection、capital/services timing与failure modes，不能比较“扶持成功率”。

P0：追回2021全部申请分母

优先找： - 总申请件数； - 初审/复审件数； - 完整落选项目名单（若依法公开）； - 评审标准及项目成熟度要求。

若无名单，不应通过搜索引擎自行拼出“落选者”，避免严重遗漏。

P1：把8个项目编码到统一时间轴

每案记录： - company_date - prototype_before_award - demo_before_award - publisher_before_award - crowdfunding_before_or_after_award - award_payment_timing - full_time_headcount_before_after - platform_at_award - platform_at_release - launch_date - post_launch_survival - next_project - company_survival - explicit_counterfactual_statement

P2：扩到2020—2024历年获奖队列

如果每年固定约8案，可以建立多届获奖panel，研究： - selected-project shipping conversion； - 平均award→launch latency； - 平台/发行商变化； - 公司存续； - 下一作； - 与国发基金/文策院投资衔接。

仍然必须称“获奖队列”，不是政策因果评估。

P3：寻找真正的对照组

优先级： 1. 同计划未获奖申请者； 2. 同年同展会/同成熟度、未获奖励的公司化项目； 3. 历年规则变化前后的准实验机会。

只有走到这里，才可能回答“这笔钱到底有没有提高发售/存活概率”。
