009 — 台湾成人独游2025可见发行队列：收益偏斜、发行商重叠与作者第二作存活

  • Status: VISIBLE-CATALOG SNAPSHOT / AUTHOR-PERSISTENCE PILOT / NOT COMPLETE MARKET CENSUS
  • Program: C Taiwan comparator
  • As of: 2026-10-08
  • Source base: SteamDB当前发行商/开发商目录快照 + 官方发行商页面
  • Publishers: Mango Party / PlayMeow / LewdLoco
  • Unit: released base game（排除Demo、DLC、Soundtrack、Artbook）
  • Core restriction:
  • SteamDB发行商页对Mango Party / PlayMeow存在100条显示上限，因此本文件只称“可见目录样本”，不是全年完整发行总数；
  • Steam合作伙伴可自行填写publisher/developer字段，SteamDB也明确提示可能存在误归属；
  • 同一作品可能同时出现在多个发行商目录，绝对不能把三家产品数相加当市场规模；
  • followers / peak CCU / rating用于可见度与相对表现，不换算销量或收入。

0. 为什么要做这一层

只看《Summer Clover》《V-LOVER!》《Take Me To The Dungeon!!》会把市场误读成高收益赛道。

本轮改用： - 三家专业发行商的当前SteamDB目录； - 只抽2025正式发售的base games； - 保留头部、中腰部和低尾； - 再抽若干开发者追踪其Steam目录，观察首作/后续作是否持续。

目标不是估算整个台湾R18市场收入，而是回答：

在专业发行商已经形成规模以后，普通作品的“典型可见表现”是什么？创作者做完一作之后会不会继续？

1. 发行商规模不能简单相加

当前SteamDB目录： - Mango Party News：页面显示100 products，且明确提示结果因过多被限制； - PlayMeow：页面显示100 products，同样提示结果被限制； - LewdLoco：67 products。

Sources: https://steamdb.info/publisher/Mango%20Party%20News/ https://steamdb.info/publisher/Playmeow/ https://steamdb.info/publisher/LewdLoco/

官方Steam关注： - Mango Party约32万+关注； - PlayMeow约17万+关注。

Sources: https://store.steampowered.com/publisher/mangoparty/about/ https://store.steampowered.com/publisher/playmeow/about/

但目录有明显重叠

例如： - 《Homebody Hostess》SteamDB同时列Mango Party、LewdLoco； - 《Taiwan Love Story⁵》同时出现在Mango Party与LewdLoco目录； - 《Lewd Gym》等也存在多发行商/历史合作字段。

所以：

Mango 100+ + PlayMeow 100+ + LewdLoco 67 ≠ 267款独立作品 ≠ 267个台湾开发项目。

正确单位应拆成： - unique app； - unique developer； - publisher relationship； - Taiwan legal entity； - developer location。

这再次支持“台湾是发行枢纽”而不等于“全部作品都是台湾自产”。

这就是portfolio publishing存在的经济理由之一。

3. 这不是三家“发行能力排名”

以上统计不能直接解释成：

Mango > PlayMeow > LewdLoco。

原因： 1. Mango / PlayMeow页面被SteamDB限制到100条，可见样本可能漏掉更低rating产品； 2. 各家2025发行数量不同； 3. 发行商选择的项目成熟度不同； 4. 品类、价格、发行月份不同； 5. 有联合发行和重复条目； 6. developer品牌资产不同； 7. 2025作品观察窗口不完全一致。

当前只能说：

三家目录共同证明专业发行并没有消除极端收益偏斜；而不同发行商可能分别选择了更成熟的项目、较宽的creator funnel或不同风险组合。

5. 初步作者存活模型：R18更像“连续小赌注”而不是“一作定终身”

从这一小组样本能看到三类路径：

Serial studio

樹懶叫工作室： 多年连续生产、多个项目、多个发行关系。

Hit acceleration

Tiramisu / Hentopia： 前作/初作 → 强市场反馈 → 快速下一作与更大scope。

Long-tail persistence

NAGATOUI / SiGMAGURO： 低峰值项目后仍继续制作。

因此成人独游相对传统premium indie的一个重要结构优势可能是：

smaller scope + reusable art/system pipeline + explicit niche demand + publisher infrastructure → lower cost of another attempt.

也就是说，单个作品失败的职业终局风险可能更低，因为作者可以更快再试一款。

Status: PROMISING HYPOTHESIS.

还缺： - 开发成本； - 实际净收入； - 作者是否full-time； - 第二作之间是否靠接案/本职工作维持； - 被发行商拒绝的作者； - 完全停止更新的开发者分母。

6. 发行商越来越像risk-pooling机构

LewdLoco官方业务说明： - 从开发到销售的技术支持； - 本地化翻译/配音； - 游戏测试、优化； - Steam / DLsite上架； - 数据分析、target marketing、promotion； - VTuber / media / event exposure； - team matching。

Source: https://www.lewdloco.com/ https://www.lewdloco.com/%E5%90%88%E4%BD%9C%E6%9F%A5%E8%A9%A2

Mango Party公司自述也包含： - 投资； - 产品顾问； - 翻译； - 技术/开发支持； - 移植； - 社群/媒体营销。

Source: https://www.cake.me/companies/store-steampowered-franchise-mangoparty

PlayMeow则进一步加入： - low-code creator tool； - creator education； - own platform； - funding / publishing pipeline。

这三家并不是“传统发行商复制品”，更像成人indie专门的： portfolio selector + shared services + audience aggregator + risk pool。

7. 但最重要的商业条款仍是黑箱

本轮没有找到三家公开标准化的： - publisher advance； - minimum guarantee； - revenue split； - recoup waterfall； - marketing recoup； - IP ownership； - sequel option； - exclusivity； - localization cost allocation。

LewdLoco合作页公开的是服务范围，不公开term sheet。 Mango / PlayMeow公开页面同样以合作联络为主。

因此不能从“发行商提供很多服务”推导：

开发者拿到的钱很多 / 条款友好 / IP一定归作者。

这恰恰是下一阶段最需要访谈、开发者公开复盘或合同泄露/范本才能补的证据。

8. 对市场空间的新判断

市场不是饱和到“不能做”，而是分层成熟

顶部

仍有可观爆款空间。 2025可见样本里仍出现2,000—3,000 peak级产品。

中间

200—900 peak产品很多，这可能才是专业发行商真正稳定的“中腰部”。

底部

13—100 peak同样大量存在，且有些开发者仍继续下一作。

所以“市场空间”不能只问：

还能不能出爆款？

更应该问：

在什么开发成本下，50 / 200 / 500 peak的产品是否还能支撑下一次尝试？

真正决定产业可持续性的不是头部销量，而是： median project economics + second-attempt survival。

当前缺成本与净收入，不能回答盈亏平衡。

9. 下一步：从作品分母转向“开发者经济学”

下一轮优先：

  1. 对2024/2025发行目录做unique developer去重；
  2. 追每个developer首作年份、作品数、最大/最小表现、是否有2026/2027新作；
  3. 抽低尾作者寻找： - Patreon/FANBOX； - DLsite； - freelance job； - full-time employment； - publisher funding；
  4. 搜发行商与开发者公开合同/分成复盘；
  5. 建“second-title survival”： - 2024首发作者在2026是否有第二款； - 高/中/低表现分别比较；
  6. 只有拿到成本/分成后，才估算成人indie的真实median career viability。

当前最重要的方法论结论

成人游戏的优势未必是“单作更容易爆”，而可能是“scope小、需求明确、发行服务成熟，使创作者更容易获得第二次和第三次尝试”。

这比只看爆款更接近行业长期竞争力。
