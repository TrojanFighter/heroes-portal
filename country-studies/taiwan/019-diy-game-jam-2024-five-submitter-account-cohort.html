019 — 台湾DIY Game Jam 2024「火锅」：五个普通投稿账号的前史与两年后创作痕迹

  • Program: C Taiwan / fixed-entry public amateur production, linked to OQ-001/002/003
  • As of: 2026-10-08
  • Status: FULL 5/5 SUBMITTING-ACCOUNT FRAME RECONCILED / PUBLIC AFTER-TRACE LOWER BOUND / NO EMPLOYMENT OR CAUSAL INFERENCE
  • Unit: primary submitting itch account linked to one 2024 DIY jam work; not verified natural person, not stable team, not employer.
  • Cohort T0: 2024-03-03 第八届 DIY Game Jam「火锅」提交截止; event preceded by about one month of concept/development, itch submission window itself was 2024-02-29 to 03-03.
  • Parent: 台湾004 GGJ台北 / 016作者路网 / 017生产中段 / 018东亚入口比较

0. 为什么要追这个无明星小样本

这不是选5名媒体故事丰富的创作者，而是把已公开的2024 DIY Game Jam第八届全部5条提交逐条锁定，追到2026。活动主办方明确称免费、不限团队人数和产业类型、线上Discord合作、以兴趣交流为主而非正式比赛，主题「火锅」，有企划分享、成果提交和开发感想投稿节点。

  • 主办方原始活动页（P0）：https://itch.io/jam/20240303
  • 完整提交名册（P0）：https://itch.io/jam/20240303/entries
  • 2024-02-29至03-03是itch收件窗口，而活动规划自1月29日开始；不能把实际开发周期误写为「只做了四天」。

5个提交账号： Suncacao, fakaty, PooGamer, rabbit99, gounson.

该公开帖是同期第三方证词（S2/证据指针），非作者开发日志；与同一作者公开itch游戏页交叉支持作品及本人关联，但2025具体日期仍由第三方帖子锚定。合理编码是 SECONDARY_DATED；不得升级成PRIMARY_DATED或未经核实的发行意图。在未取得作者原始发布日期前，提供宽口径下限2/5、严格P0本人明确日期下限1/5。

更重要的机制反例：没有Steam并非无能力、无平台意识、或没有继续创作；同人/非盈利项目可以有独立的发行选择。以上动机是第三方转述，不外推至全体。

3. 两个重要方法论纠错

3.1 Game Jam的“回头客”与“新作者形成”必须拆分

若5名公开投稿者中至少3名在T0之前已有作品，则即使其中一位再次于2026投稿，也不能说是2024年活动创造了这名开发者。本cohort最大价值不是续作成功率，而是公开地证明这里同时存在旧参与者、潜在新人和未知职业路径。

若要真正估计 CREATOR_FORMATION，分母必须从活动前尚未有游戏创作的人/课程/社团/普通玩家处建立，并识别报名未提交及只做私有原型者。完整SUBMISSION COHORT只能告诉我们较后的作者轨迹。

3.2 在全球公共平台上持续做非商业游戏，也是一种作者再生产

AUTHORIAL_PERSISTENCE 与 FULL_TIME_EMPLOYMENT、STEAM_COMMERCIAL_RELEASE、PROFITABLE_STUDIO应永不合并为单一结果。普通作者可以持续发表小作，根本不以Steam交易为目标。在作品平台寻找“未来的市场化作者”会让这类人与其他自愿非商业作者消失；直接判定“未商业化=淘汰”属于错题。

同样，对兔子账号而言主页第二款是明确早于2024基线的作品，不能用“首页游戏数>1”算次作。

4. 对照欧洲/日本/大陆时的正确口径

日本2025 Koshien：873 submissions不是873 playable games

官方2025规则允许游戏、未完成Alpha、企划PDF、角色设计、概念艺术、音乐等单项投稿；不限一人/团队多次投稿、允许同一作者多个团队。2026-01公布2,751 student entrants, 873 submitted works均是真实活动数字，但不能把873换成“873款游戏成品”，更不能直接除人口比较台湾PC游戏189或大陆CUSGA528。

P0: - https://game.creators-guild.com/gck2025-terms/ - https://prtimes.jp/main/html/rd/p/000000072.000126454.html - Game Parade公开作品栈：https://gameparade.creators-guild.com/works

日本优势候选是INCOMPLETE_WORK ACCEPTANCE + MULTI_DISCIPLINE AUTHOR ENTRY，而非基于混合类别数量宣称的「人均独游高产」。

台湾与大陆一样存在面向新人的入口，不可把日本独有化

  • 台北GGJ2024第一会场要求一定制作熟悉度，并采用日间开放、在活动中间提交企划/Alpha；深圳南山GGJ2024开放48小时使用，有技术环境和场地支持。两站点 eligibility/有效工时/组队规则有差异，原型数量不等于作者能力差异。
  • 台湾2025 Garena Game Jam明确欢迎开发新手、学生、专业者： https://gamejam.garena.sg/tw/web_event/GarenaGamejam/news/news_20250423.html
  • 中国2025 CiGA Game Jam宣传强调新人与老司机共同参加、有线上+线下入口及公开GmHub作品：https://www.gmhub.com/jams/cgj2025
  • 2025沈阳GGJ站直接写“不必会写代码或画画，也欢迎任何知识背景参与，提供想法/测试/团队支持”：https://globalgamejam.org/fa/group/11991
  • ENTRY ELIGIBILITY 是一个活动层变量，不能给任何地区永久贴上“零门槛/高门槛”的国家标签。

5. 后续真正要完成的不是第三个更漂亮的故事

此样本已经具备5/5完整起点与下限，然而 分母尚不到“注册过/考虑过创作的人”。下一阶段最有价值的事： 1. 把台湾2023/2024不同DIY届的完整投稿账号连成跨届公开身份图，统计曾投稿账号中至少几成是repeat author（同时去重更早基线）； 2. 取大陆GmHub一个完整同期站点/线上jam固定目录，按同样账号级别做pre/post窗；注意GmHub实名程度、二次发布平台和永久URL都可能降低可观察性，不得用搜索不到=没继续； 3. 取日本Game Parade内确定 game 类别且作品首发于2023/2024的固定入口小样本，区分游戏、企划、音频、美术与同作者重复投递； 4. 之后才做CREATOR ENTRY的项目外来源：普通游戏玩家/非专业学生样本的自愿问卷、制作工具首次使用、第一次实际完整原型时间； 5. 收集2024 DIY活动报名（非只投稿）及非投稿者在允许/自愿条件下的聚合信息；不可从公开姓名推测家属、雇主或个人经济。

关闭条件：有统一单位、相同T0、pre-entry经验明确、T+24个月公共作品状态、社群自选程度记录与海外公共平台可观察性偏差说明。即使达到这些，仍是参加者研究，不是自然人口创新率。

6. Time & privacy boundary

  • 2024年基线；2025年第三方同期展示证据；2026-09-27原作者公开作品时间。
  • 不追私人住址、学校、雇主、家庭/薪酬、身份拼图；保留创作者自愿公开的itch handle即可。
  • 本档仅公开行业研究，不记录未公开的私人游戏项目、个人商业事项或营销方案。
