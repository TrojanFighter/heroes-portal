为什么研究台湾

台湾与中国大陆有相近的语言市场及部分文化和游戏题材传统，但产业历史、市场规模、游戏准入、国际商务、教育与家庭制度并不相同，且长期存在两岸公司、人才、市场互相流动。它是重要的比较对象，不是被假定为「自由就更有创造力」的制度实验或随机对照。

核心问题： 1. 1990s 台湾原创 PC 开发与流通结构如何演化；为何在国产作品之外出现代理、进口与网游转型？ 2. 2000s 台湾公司究竟在代理、自研、代工/合作开发之间如何分化，而不是把全部混作「放弃原创」？ 3. 台湾厂商及人才进入大陆市场时，能力、收入、渠道控制与 IP 权利发生什么变化？ 4. Steam/全球平台时代，哪些开发者能力与人生条件使小团队原创项目成为可选项？ 5. 被媒体报道的人是否只是极少数；未发售、未获资助、回归就业或保持在职的普通创作者在哪里？
