发达国家创新者与跨行业研究

返回研究计划总图

本区研究两件互相关联但层级不同的事：

  1. Innovation Formation：一个创新者怎样形成，他如何获得技能、判断、资本、决策权与错误窗口。
  2. Industrial Revolutions Comparative Lab：技术机会本身怎样出现、跨过成本线、扩散，并最终被新的组织或产品形态吸收。

这两条线不能混成“伟人创造技术”或“技术自动创造伟人”。

2026-10-11：价值网络理论扩展（研究方法，不预设国别结论）

  • Value Network beyond Disruption — 三网络、切换成本、创新收益占有与再生产：基于Christensen/Rosenbloom及Christensen Institute教育场景的理论扩展，关联新西兰与中国040时代窗口。保留原始理论边界、竞争性解释、反例与分母未知。

  • 健身房创业者自述 × 威尔仕停业 × 新式月付健身：进入拥挤、信息不对称和现金流义务：2025年答主个人证言与2026年行业报告、上海预付款监管、乐刻模式交叉审计；辨别「存量净减少≠关店率」「个案≠全国」并检验新旧价值网络，而不把单个失败案例奉为强因果。

1. 从游戏业进入跨行业：PUBG 是桥梁

根目录 CASE-032 已经给出一个关键中间态：

mod / community 中的个人规则发明 → 可玩的公共 artifact → 商业组织合作 → 大型公司资源放大。

它避免两个极端：

  • 伟大创新都是一个天才凭空想到；
  • 大型公司只要投入更多资源就能买到创新。

PUBG / Brendan Greene 因此连接了 indie production 与 industrial-scale innovation。

2. Innovation Formation / 创新者形成

Builder / 创业者

首批：Steve Jobs、Elon Musk、Jensen Huang、Jeff Bezos、Edwin Land、James Dyson。

观察： - formative hobbies / early work； - first artifact； - non-consensus decision； - capital allocation； - hiring / decision rights； - vertical integration； - customer feedback； - failure portfolio； - founder control 的正负效应。

Organizational innovator / 工程组织者

候选：Kelly Johnson / Skunk Works、John Carmack 等。

重点不是个人魅力，而是组织怎样让小团队获得 clear owner、short feedback loop、protected autonomy、direct user / test data、low coordination tax 和 escalation discipline。

Theorist / 理论工具

首批：Clayton Christensen。

理论家不等于成功 builder。disruption、value network、incumbent incentive、overserving、resource dependence 应作为可被案例支持或反驳的解释工具，而不是先验定律。

当前上层理论节点

  • Self-Obsolescence / Second-Answer Test：成功公式处决、自我过时与第二答案测试 — 用 DOOM Eternal→The Dark Ages、Intel/Grove、Christensen、Apple、Nintendo 与 Pocketpair 边界样本检验：真正长期创新是否取决于让自己的成功答案重新接受现实审判；提出 SELF-OBSOLESCENCE、ORTHODOXY HALF-LIFE、SECOND-ANSWER TEST、LAGGED-EVIDENCE TRAP，并明确要求失败型自我蚕食与数量级对照。

  • Complementary Taste / Founder Pair Lifecycle：互补鉴别力、创始组合与生命周期 — 用 Carmack×Romero 与 Jobs×Woz 两组不同终局的创始组合，区分 skill complementarity 与 ERROR COMPLEMENTARITY；提出 TRANSLATION BANDWIDTH、FEEDBACK-TIMING COMPATIBILITY、IDENTITY TERRITORY OVERLAP、TASK-BOUNDED COMPLEMENTARITY，并把组合终局拆为 CONFLICT FAILURE / TASK COMPLETION / CAPABILITY SUCCESSION。下一步用 Nintendo 多代师承与制度传递压力测试第三型。

  • Reversible Bets / Irreversibility Gradient：可逆下注、创新期权与承诺升级 — 把 Bezos 的 one-way/two-way door、McGrath/MacMillan 的 discovery-driven planning、Christensen 的 emergent→deliberate strategy 与 Grove 的 inflection-point experimentation 放入同一可证伪框架；提出 IRREVERSIBILITY GRADIENT、QUESTION-MADE-EXECUTABLE、INFORMATION-FIRST MILESTONE、PERPETUAL OPTIONALITY 与 OPTION EXPIRY，并显式保留 prototype false-negative problem 作为下一轮反例压力测试。

  • Innovation Constitutionalism：Exit / Voice / Loyalty 与创新中的判断主权 — 用 Hirschman 的 Exit / Voice / Loyalty 把 Grove 的内部异议、Christensen 的替代选择系统、early id 的退出与无许可验证、Nintendo 的内部原型权放进同一纠错框架；提出 CREDIBLE EXIT + EFFECTIVE VOICE + REVOCABLE LOYALTY、PERMISSIONED INDIVIDUALISM、PERMISSIONLESS VALIDATION 与 Innovation Rights Stack 2.0，并明确美国同样存在层级、竞业、阶级与沉默边界。

  • Judgment Under Uncertainty：March / Simon / Knight / Hayek / Buxton 理论栈 — 把 exploration/exploitation、bounded rationality、Knightian uncertainty、dispersed local knowledge 与多方案prototype放入同一前范式决策链；回答为什么旧答案会获得资源优势、为什么数据不能消灭真正未知、为什么中央指标不能替代局部知识，以及为什么 Compare Before Commit 比过早精炼唯一方案更可靠。

  • Tacit Judgment / Selection Apprenticeship：Polanyi、Taste传承与AI时代的隐性知识 — 用 Polanyi 的 tacit knowing / connoisseurship 与 Schön 的 reflection-in-action解释为什么规则、文档和design bible不能完整复制高手Taste；提出 DOCUMENTATION COMPLETENESS FALLACY、ATTENTIONAL APPRENTICESHIP、APPRENTICESHIP–SOVEREIGNTY TRANSITION、JUDGMENT TRACE 与 AI-AUGMENTED SELECTION APPRENTICESHIP，并讨论AI既可能提高隐性模式可观察性，也可能制造 apprenticeship void。

  • Representation / Orientation / Paradigm：Alan Kay、Boyd、Kuhn、Lakatos 与前范式搜索 — 把 point-of-view leverage、new-medium masquerade、Kuhnian exemplar/normal science/anomaly、Boyd 的 Orientation / destruction-and-creation 与 Lakatos 的 progressive / degenerating research programme 接成一套表征更新框架；提出 REPRESENTATION SOVEREIGNTY、MEDIUM MASQUERADE、EXEMPLAR CAPTURE、ANOMALY PROMOTION THRESHOLD、PARADIGM PATCH BURDEN、ORIENTATION DEBT、PREDICTION-BEFORE-OUTCOME TEST 与 REPRESENTATION PROTOTYPING，并区分 output diversity 与 representation diversity。

  • Double-Loop Learning / Defensive Routines：Argyris 与组织为什么明知有问题却学不会 — 区分 single-loop 行动纠错与 double-loop governing-variable 重审；提出 LOOP-DEPTH MISMATCH、GOVERNING-VARIABLE LOCK、FEEDBACK THEATER、ESPOUSED–ENACTED GAP、SUCCESS-SHELTERED LEARNING、TESTABLE ADVOCACY 与 STRUCTURAL DOUBLE LOOP，并用 defensive routines / skilled incompetence 解释为什么聪明、成功、开放沟通的组织仍可能系统性逃避真正学习。

  • Sensemaking / Ambiguity Competence：Weick、模糊决策与行动中的理解 — 把 identity / retrospect / enactment / social / cues / plausibility 等sensemaking机制与 Small Wins、Mann Gulch、Drop Your Tools 接入前范式决策框架；提出 PROVISIONAL COHERENCE、ACTION-GENERATED EVIDENCE、CUE REGIME、IDENTITY–CUE LOOP、SOCIAL SENSEMAKING BANDWIDTH、PROBLEM-SCALE FIT 与 BEST UPDATABLE STORY，用于区分模糊决策能力与单纯信息不足。

  • Intuitive Expertise / Taste Validity：Klein × Kahneman × Hogarth — 用2009年Kahneman–Klein共同结论与Hogarth kind/wicked learning环境，为Taste Capital加上环境有效性、反馈完整性和领域迁移边界；核实消防指挥研究的26名专家/156决策点，提出 TASTE DOMAIN MAP、EXPERTISE SCOPE DISCIPLINE、LEARNING-ENVIRONMENT TRANSFER GAP，连接CDM与Premortem，并区分快速模式识别、预测校准和创造性问题形成；追加“判断主权属于个人，判断信用来自现实”原则及 Jobs / Miyamoto / Carmack 人物判断审计协议（待执行）。

统一分析模板

每个跨行业人物 / 组织至少回答：

  1. Formation：童年、家庭、教育、兴趣、早期工作形成了什么能力与世界模型？
  2. First artifact：第一次无需职位授权就能证明能力的作品是什么？
  3. Non-consensus bet：真正逆共识的判断是什么，当时为什么不是常识？
  4. Runway / capital：谁为试错付钱？失败一次会怎样？
  5. Decision rights：谁有 kill / pivot / ship 权？
  6. Feedback architecture：多久能获得外部真相？
  7. Escalation：什么时候从小下注升级为大规模投入？
  8. Residual value：失败留下了什么人才、技术、渠道、品牌或认知？
  9. Institutional amplifier：公司、资本市场、大学、政府、供应链承担了什么放大作用？
  10. Dark side / boundary：这种模式制造了什么组织代价、错误和不可复制条件？
  11. Technical opportunity：当时刚刚成熟 / 扩散到可用的技术是什么？本人是否明确意识到这一窗口？

3. Industrial Revolutions Comparative Lab / 工业革命比较实验室

正式入口：industrial-revolutions/

这里研究的不是“最新技术新闻”，而是：

一项技术怎样从“已经存在”变成“值得采用”，再变成“产业基础设施”。

强制区分：

invention → engineering maturity → economic viability → diffusion → complementary fit / killer application

以及：

frontier availability → professional diffusion → small-team / indie diffusion → mass availability

研究案例包括：

  • Newcomen → Watt / Boulton：效率、通用化、商业组织与蒸汽动力扩散；
  • 电气化：发电 / 电网 / 电机已经存在后，工厂为什么还需要组织重构才能吃到生产率收益；
  • Diesel：从早期固定 / 船舶 / 潜艇应用，到不同运输和军用场景找到优势组合；二战苏联装甲应用只作为其中一个高价值候选，不写成“战争才第一次证明柴油机有用”；
  • 计算机 / 微处理器 / PC / 网络：frontier capability 与普通开发者可调用能力之间的扩散时滞；
  • 通用引擎、数字发行、众筹、Early Access、UGC 平台：它们怎样改变最低有效团队规模和反馈路径；
  • 生成式 AI / agent：哪些成本项真实下降，哪些互补组织、数据、判断、验证和专业能力仍构成瓶颈。

技术决定论禁令

禁止：

技术没到位，所以以前的人什么都做不了。

也禁止：

技术到位，所以现在一个人什么都能做。

正确研究对象是：

在一个时代真实可获得的技术集合里，当事人看到了什么新可行解；同代其他人为什么没有采用、不能采用或不愿采用。

4. “技术→体验转换”的研究归属

技术→体验转换不进入“游戏设计方法论”专区。

在本项目里它只作为历史与产业问题处理：

  • 某项尖端技术哪年出现；
  • 哪年工程成熟；
  • 哪年成本降到商业可接受；
  • 哪年扩散到大厂；
  • 哪年扩散到普通专业团队；
  • 哪年小团队也能负担；
  • 哪一批产品最早证明它能创造玩家真正重视的体验 / 市场价值；
  • 哪些技术曾经长期存在，却因为缺少 complementary system 而低利用；
  • 哪些“先进技术”没有形成有竞争力产品，为什么。

对应框架见 Technology Absorption Framework。

5. “中国从美国学到了什么 / 没学到什么”必须拆开

已大量学习、需要具体量化的部分： - 大规模工程管理； - 软件与互联网组织； - 风险资本形式； - 全球供应链； - 平台商业； - 用户增长与广告； - 标准化职业体系； - 大规模制造与成本控制。

待检验是否仍存在差距的部分： - problem selection / product thesis； - 对非共识个人的早期容忍； - artifact-first credential； - 创始人 / 小团队的真实 decision rights； - 在证据出现前保持小下注、证据出现后快速加码； - 对失败项目的 residual-value accounting； - 跨组织的人才流动和创业再组合； - 长周期资本； - 从本土 benchmark 跳向全球前沿问题的能力； - 把“怪人”留下来而不是只筛掉。

这些都必须用中美公司史、创业者人生史、招聘 / 资本 / 组织制度和失败案例验证，不能用文化印象完成。

6. 当前边界

本区现在建立研究框架、来源池和桥梁案例，不批量生成英雄传记。

跨行业材料尤其容易受创始人自传、授权传记、公司公关、投资者成功学和事后“伟人早知道一切”污染。正式结论必须同时有同期材料、反方材料、失败节点和制度背景。

同样禁止把本区研究转写成私人项目的具体游戏设计、数值、系统、关卡或竞争方案。这里研究历史发生了什么；私人商业应用留在仓库外。
