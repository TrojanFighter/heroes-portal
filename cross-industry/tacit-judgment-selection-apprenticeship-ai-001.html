Tacit Judgment / Selection Apprenticeship：Polanyi、Taste 传承与 AI 时代的隐性知识

  • Related:

0. 核心问题

如果一个强设计师 / 工程师 / 制片人真的拥有高水平 Taste，为什么： - 他写一份完整规则手册，别人仍然不能复制他的判断？ - 新人和高手看同一个 prototype，却会注意到不同问题？ - 高手有时“知道这里不对”，却一时说不出完整原因？ - Nintendo 等组织需要长期师承、共同做项目与逐级 Decision Right，而不是只靠 design bible？ - AI 即使读完组织全部文档，也不自动等于拥有这个组织最珍贵的判断能力？

Michael Polanyi 提供的核心入口是：

We can know more than we can tell.

这里的 tacit 不能简单理解为“还没写进文档的知识”。

更强的命题是：

有些熟练判断的运作条件并不能被穷尽地写成规则；规则可以帮助实践，却不能替代实践中已经内化的综合判断。

这使 Taste 从“神秘天赋”变成一个可研究对象： - 哪些部分可以 articulation； - 哪些部分必须通过 demonstration / participation / calibration 形成； - 哪些组织结构能让隐性判断跨代延续； - 哪些 AI 工作流可以部分捕获行为模式； - 哪些“知识管理”会把规则文档误当成能力本身。

Primary: - Michael Polanyi, Personal Knowledge (1958): https://press.uchicago.edu/ucp/books/book/chicago/P/bo19722848.html - Michael Polanyi, The Tacit Dimension (1966): https://press.uchicago.edu/ucp/books/book/chicago/T/bo6035368.html

1. Tacit Knowledge 不是“秘密知识”，而是 Knowing 的结构

Polanyi的重要区分不是简单二分： - explicit = 写出来； - tacit = 没写出来。

他研究的是一种 from–to structure：

我们会从大量处于背景中的 subsidiary particulars， 整合到一个前景中的 focal whole。

例如： - 读文章时，焦点是句意；语法和字形大多退到背景； - 锤钉子时，焦点是钉子和工作结果；手掌压力成为工具性的背景感觉； - 识别人脸时，焦点是“这个人是谁”；鼻形、眉骨、比例等线索并不是逐条显式计算； - 判断一个prototype“哪里不对”时，焦点是整体体验；节奏、反馈、空间、动画、输入、预期、类型经验等大量线索在背景中被综合。

Polanyi把这种背景线索到整体意义的整合称为 tacit knowing 的核心。

因此：

TACIT != UNDOCUMENTED

更接近：

TACIT = KNOWING THROUGH INTEGRATED SUBSIDIARY CLUES

辅助材料： - Polanyi Society glossary / focal vs subsidiary awareness: https://polanyisociety.org/glossary-of-polanyis-terminology/ - 2024 organizational embodiment discussion: https://journals.sagepub.com/doi/10.1177/01708406241228374

2. 为什么“规则写得更详细”仍不能复制高手

Polanyi在 Personal Knowledge 讨论技能时明确指出：

rules of an art can be useful, but they do not determine the practice of an art.

规则可以： - 提醒； - 定位常见错误； - 建立共同词汇； - 帮助新手注意某些变量。

但规则本身仍然需要： - 情境判断； - 时机； - 权重； - 例外处理； - 整体整合。

因此：

Explicit Rule
+ Novice
≠
Expert Performance

更接近：

Rule
+ Situated Cases
+ Demonstration
+ Guided Attention
+ Repetition
+ Error Correction
→ Internalized Judgment

Documentation Completeness Fallacy

新增概念：

DOCUMENTATION COMPLETENESS FALLACY / 文档完备错觉

认为只要把“知道的东西”全部写下来，组织能力就已经被完整保存。

文档可以保存： - vocabulary； - declared principles； - known failure modes； - process sequence； - historical rationale。

但它不自动保存： - 具体情境下哪些原则该优先； - 什么时候违反规则； - 哪个弱信号值得当真； - 怎样从多个不完整线索形成整体判断； - 如何区分“看起来像问题”和“真正会杀死产品的问题”。

所以：

DOCUMENT RETENTION != CAPABILITY RETENTION

3. Connoisseurship：Taste 本来就是 Polanyi 的核心研究对象之一

Polanyi并不只讨论“会不会做”。

他还专门讨论 connoisseurship： - 识别； - 区分； - 诊断； - 对综合对象作质量判断。

这与我们此前定义的 Taste 非常接近。

一个 connoisseur 并不只是记住很多规则， 而是能把大量具体线索整合成：

“这个整体值不值得继续？”

因此此前的：

Taste Capital

可以更严谨地改写成：

由大量 situated comparison、prediction→outcome、guided attention 和 correction 所形成的、部分隐性的 selection model。

也就是说：

Taste Capital
≠
Opinion Count
≠
Reference Count alone

而更接近：

Reference Breadth
× Situated Judgment Repetitions
× Consequence Feedback
× Error Updating
× Tacit Integration

4. Selection Apprenticeship：高手真正传授的是“注意什么”

如果隐性判断不能完全通过规则复制，组织怎样传递？

Polanyi给出的经典答案之一是：

example from master to apprentice.

这里最值得吸收的，不是旧式师徒等级制， 而是：

新手在真实实践中观察高手如何选择、如何注意、如何放弃、如何修改，并在高手的纠正下逐渐学会看到过去看不见的线索。

所以我们此前提出的：

SELECTION APPRENTICESHIP

现在可以更具体地定义为：

Novice predicts
→ Master judges
→ Both inspect same artifact
→ Master redirects attention
→ Reality produces outcome
→ Compare prediction vs outcome
→ Repeat

真正传递的不是：

“这个项目应该做。”

而是：

你为什么应该在这个时点注意这个变量，而不是另外十个变量。

这叫：

ATTENTIONAL APPRENTICESHIP / 注意力师承

5. 师承不是反个人主义：创新者需要“先住进传统，再获得主权”

Polanyi的一个重要修正是：

学习无法穷尽说明的技艺，初期往往需要对熟练者进行一定程度的 epistemic trust。

这对我们此前的美国个人主义 / Permissionless Validation框架是必要压力测试。

错误版本：

independent thinker
= never submits to authority

更好的版本：

Tradition
→ Apprenticeship
→ Internalization
→ Independent Judgment
→ Reality Correction
→ Generative Mutation

创新者很多时候并不是：

没学会传统就反传统。

而是：

先获得足够深的传统内化，才知道哪些东西是表面形式、哪些是生成原则、哪些地方可以真正突破。

这与此前的： - Generative Succession； - Solution Knowledge vs Generative Knowledge； - Nintendo Yokoi / Miyamoto / Aonuma / Fujibayashi； - Carmack对技术约束的深度内化； 完全兼容。

Apprenticeship → Sovereignty Transition

组织真正困难的是：

什么时候停止要求新人“先照做”，开始把真实判断权交给他？

因此新增：

APPRENTICESHIP–SOVEREIGNTY TRANSITION

失败模式A：

Premature Sovereignty

  • 技能未内化；
  • 缺乏案例；
  • 把无知当原创。

失败模式B：

Permanent Apprenticeship

  • 永远执行前辈答案；
  • 可以模仿，却不能形成新selection function；
  • capability succession停在L1–L3，无法进入真实L4–L6。

优秀制度应实现：

imitate
→ explain
→ predict
→ decide under supervision
→ own bounded decisions
→ own full decisions
→ create new method

6. 为什么 Nintendo 式 Capability Succession 必须观察共同实践，而不只看文档

此前Capability Succession分层： - vocabulary inheritance； - method inheritance； - calibration inheritance； - authority inheritance； - generative mutation； - institutional inheritance。

Polanyi让其中最关键的一层更清楚：

Calibration inheritance 不可能仅靠“设计原则被保留”证明。

真正证据应包括： - senior与junior长期共同看artifact； - junior先提出判断； - senior不是只给答案，而是纠正注意力； - junior得到反复独立下注； - senior逐渐退后； - junior后来能创造不同于老师的成功形式。

因此：

SHARED ARTIFACT JUDGMENT

比：

SHARED VOCABULARY

更接近真正Taste传承。

7. Donald Schön：从 Tacit Knowing 到 Reflection-in-Action

Schön把Polanyi式隐性知识推进到专业实践。

他的核心概念： - knowing-in-action：熟练者在行动中表现出的、未必能完整陈述的知道； - surprise：现实出现不符合预期； - reflection-in-action：行动过程中重新审视自己的理解； - on-the-spot experiment：即时修改并观察结果。

这几乎就是我们此前定义的Experimental Taste的专业实践版。

Tacit Model
→ Action
→ Surprise
→ Reflection
→ Local Experiment
→ Updated Practice

所以高手不是：

只靠无法言说的直觉。

而是：

拥有大量隐性判断，同时能在现实打断自己时，把部分隐性模型拉到前景重新检查。

这非常重要，因为否则Tacit Knowledge容易被神秘化成：

“大师说不清，但他就是对。”

不。

真正强的实践者还必须具有：

REFLECTIVE ACCESS

即：

在关键失败时，能把原本背景化的判断部分重新显性化、试验、修改。

Source: - Donald Schön, The Reflective Practitioner: https://is.muni.cz/el/1451/podzim2013/np2270/um/D.Schon_Reflection_in_action0001.pdf

8. Nonaka边界：不要把“隐性知识”简单理解成等待转成文档的原料

管理学中常见的SECI模型把 tacit / explicit knowledge 看成可相互转化。

这套模型很有生产力，但围绕它已有长期争论。

关键批评是：

Polanyi的tacit knowing并不只是“还没有externalize的知识”。

有些能力可以： - 通过访谈部分外化； - 通过案例形成heuristic； - 通过AI总结形成semi-explicit artifacts。

但不能由此推出：

最终可以把完整expert judgment全部变成文本。

相关批评： - Gourlay 2006: https://doi.org/10.1111/j.1467-6486.2006.00637.x - Tsoukas, “Do We Really Understand Tacit Knowledge?”: https://www.researchgate.net/publication/2528222_Do_We_Really_Understand_Tacit_Knowledge - Organization Science 2009 tacit/explicit controversy review: https://doi.org/10.1287/orsc.1080.0412

因此未来仓库禁止写：

“把隐性知识全部显性化。”

更严谨：

通过语言、案例、示范和行为记录，提高隐性判断的可观察性、可讨论性与可训练性。

9. AI：读完全部文档，不等于读完组织的Taste

AI时代最危险的知识管理错觉之一：

All docs indexed
→ organizational knowledge captured

不成立。

因为文档主要包含： - 结果； - 规则； - 总结； - 被认为值得记录的显性原因。

但Taste往往还存在于： - 当时有哪些替代方案被放弃； - 某人为什么在5秒内觉得“这里有问题”； - 什么弱信号触发了进一步调查； - senior如何根据context改变原则权重； - 失败前曾经有哪些不确定感； - 最终结果怎样反证最初判断。

因此AI真正需要的不只是：

KNOWLEDGE BASE

而是：

JUDGMENT TRACE

新增定义：

Judgment Trace = context → alternatives → prediction → choice → rationale-if-articulable → observed consequence → retrospective update

这比保存最终决策文档更接近保存selection function。

10. AI并不意味着Tacit Knowledge永远无法扩散：新的证据要求更细

不能从Polanyi简单推出：

AI永远学不会隐性知识。

2026年的一项Academy of Management Proceedings研究访谈了52个实施生成式AI的组织、66名受访者，提出一种值得继续验证的机制：

pattern-based mediation：AI不要求专家先把所有知识写成规则，而可以通过观察expert work中的context–action patterns，帮助组织扩散一部分原本难以文档化的实践模式。

Source: - Xu et al., “Beyond Codification: Generative AI and the Integration of Tacit Knowledge in Organizations,” 2026: https://journals.aom.org/doi/10.5465/AMPROC.2026.286bp

这给出一个更好的区分：

Document-only AI

输入： - manuals； - design docs； - postmortems。

擅长： - explicit retrieval； - vocabulary； - known cases。

Behavior-observing AI

输入： - expert actions； - revisions； - tool traces； - before/after artifacts； - decision history； - context/outcome pairs。

理论上更可能学习： - context-action patterns； - exception handling； - recurring selection signatures。

所以AI时代组织真正应投资的是：

WORK OBSERVABILITY

而不只是：

DOCUMENT VOLUME

11. 但AI又可能制造一个反向问题：Apprenticeship Void

2026年一篇概念论文提出 apprenticeship void：

如果AI首先自动化掉： - 初级分析； - first draft； - manual checking； - repetitive case handling；

这些工作虽然低级，却过去承担了一个隐藏功能：

让新人通过大量真实案例形成 tacit pattern recognition。

如果新人直接获得AI成品：

Output quality ↑
while
Personal calibration repetitions ↓

就可能出现： - synthetic readiness：看起来能干，实际上缺独立经验； - promotion fragility：职位增长快于真实能力； - pipeline thinning：未来能独立判断的高手变少。

Source: - Sarala, “The apprenticeship void: AI augmentation and entry-level displacement in knowledge work,” 2026: https://www.emerald.com/xjm/article/23/2/174/1389190/The-apprenticeship-void-AI-augmentation-and-entry

该文为理论框架，尚需更多实证，不能当成已证明的普遍效应。

对游戏/设计尤其重要

如果AI替新人直接： - 生成关卡； - 给出balance修改； - 写完整文案； - 产出美术variation； - 完成竞品分析；

而新人没有经历：

自己预测 → 自己做错 → 看玩家反应 → 重做

那么短期生产率可能上升， 长期却可能：

CALIBRATION REPS DOWN

这与我们已有Authorial Calibration Density直接连接。

12. AI时代真正需要的是 AI-Augmented Apprenticeship，而不是取消师承

更好的方向：

Human novice makes prediction
→ AI / mentor asks for rationale
→ novice acts / produces artifact
→ player / system gives outcome
→ AI compares prediction with result
→ mentor highlights missed cues
→ novice retries

AI最有价值的角色不一定是：

替新人做。

而可以是： - 保存大量judgment traces； - 找到相似历史案例； - 反问“你漏看了什么变量？”； - 强制pre-register prediction； - 对比mentor和novice关注点； - 追踪个人反复犯的selection error； - 提升真实师徒反馈密度。

这叫：

AI-AUGMENTED SELECTION APPRENTICESHIP

其目标不是：

ANSWER DELIVERY

而是：

CALIBRATION ACCELERATION

13. Taste Transmission Stack

新增一个组织审计栈：

L0 — Principle Exposure

读规则、书、设计文档。

L1 — Case Exposure

看真实成功/失败案例。

L2 — Demonstration

观察高手实际做判断。

L3 — Contrastive Judgment

新人先下注，再与高手判断对照。

L4 — Consequence Feedback

等待真实玩家/市场/工程结果。

L5 — Guided Reflection

解释为什么预测错、遗漏了什么。

L6 — Independent Decision Right

新人独立承担bounded决策。

L7 — Generative Mutation

形成不同于老师的新selection function。

所以：

真正Capability Succession至少需要L3–L7；只做到L0–L2更接近知识传播，而不是判断能力继承。

14. Tacit Knowledge Loss：为什么某些组织“文档都在，人走了能力仍没了”

传统知识流失审计常问： - 文档在不在； - source code在不在； -流程有没有SOP。

Polanyi框架要求新增：

  • 谁还能识别什么算异常？
  • 谁知道何时无视SOP？
  • 谁见过足够多失败样本？
  • 谁能判断两个看似等价方案的长期风险？
  • 谁拥有玩家/客户/工程材料的身体化熟悉程度？
  • 谁能训练下一代？

所以新增：

TACIT CAPABILITY AT-RISK MAP

离职风险不能只按：

“这个人掌握多少秘密信息”

而应按：

这个人的judgment function是否已有可替代继承者。

15. Master-Apprentice模型的危险边界

Polanyi不是给等级制度开免检证明。

师承有三个重大风险：

15.1 Authority Lock-in

新手把“暂时信任高手”变成永久服从。

15.2 Blind-Spot Replication

师傅自己的selection bias被整代复制。

15.3 Tradition Freeze

隐性方法被当成神秘传统，拒绝现实检验。

因此优秀师承必须包含：

REALITY SUPERSEDES MASTER

导师的功能是： - 帮你学会看； - 帮你形成模型； - 给你高密度纠错；

不是：

永久成为真理来源。

所以完整链条：

Trust Master
→ Learn to See
→ Predict Independently
→ Test Against Reality
→ Disagree with Master when evidence warrants
→ Create New Tradition

这正好与Innovation Constitutionalism兼容。

16. 对“中国个人主义 / 企业师徒制”研究的修正

这条理论会阻止两个相反错误：

错误A：

中国等级意识强，所以一切师承都阻碍创新。

不成立。 高级技能本来就经常需要： - exemplar； -共同实践； -高质量反馈； -传统。

错误B：

有名师、大厂mentor、老兵带新人，所以创新能力自然传下来了。

也不成立。

真正要问： - 新人有没有先预测的机会？ - mentor是否解释注意力而不只发答案？ - 新人有没有真实Artifact Right？ - 是否接触玩家/现实结果？ - decision right是否逐步转移？ - 最终能否合法否定师傅？

所以：

APPRENTICESHIP QUALITY != HIERARCHY STRENGTH

17. 与前面“现代个人主义”的真正结合

此前定义：

Judgment Sovereignty
+ Chosen Commitment
+ Reality Correction

Polanyi现在补上形成阶段：

Tradition / Apprenticeship
→ Tacit Integration
→ Judgment Sovereignty
→ Reality Correction
→ Generative Mutation

所以成熟个人主义不是：

没有传统。

而是：

传统不能永久拥有你的判断权。

成熟创新传统也不是：

每代复制大师。

而是：

每代都能从大师那里学到“怎样判断”，最后产生大师没有给出的新答案。

18. Reader-facing Debugger

遇到“我们已经把知识都沉淀到文档里”：

问： 1. 这个领域里哪些判断只能在真实case里学？ 2. 我们保存的是答案，还是context→choice→outcome？ 3. junior是否有机会在看到senior答案前先下注？ 4. 哪些技能被AI自动化后，顺便删掉了新人的calibration reps？ 5. 谁能在专家离职后继续判断“什么时候规则应该被违反”？ 6. 这个组织能否让徒弟最终合法反对师傅？

遇到“AI已经读完公司所有资料”：

问：

它读到了我们的规则，还是观察过我们在规则冲突时到底如何选择？

这两者不能混为一谈。

19. 当前最值得继续验证的问题

  1. Nintendo公开访谈里能否找到更多“junior先判断、senior后纠正”的具体episode；
  2. 强游戏团队的postmortem是否记录被放弃的alternatives，而不只是最终答案；
  3. AI读取完整行为trace后，对expert decision imitation是否显著优于只读文档；
  4. 游戏公司AI自动化初级任务后，junior的独立判断质量三年后如何变化；
  5. 如何构造JUDGMENT TRACE而不过度增加团队记录负担；
  6. 高Taste专家之间的分歧是否主要来自不同tacit representation，怎样通过shared artifact暴露差异；
  7. Apprenticeship–Sovereignty Transition在不同国家/公司文化中什么时候发生、谁拥有授予Decision Right的权力。

20. Dreyfus：Expert 不是“更多规则的新手”，而是情境感知发生变化

Hubert 与 Stuart Dreyfus 的技能获得模型把 novice→expert 理解为一种质变过程，而不是规则数量线性增加。

在其成熟表述中，expertise的典型特征是： - 不再逐条匹配抽象规则； - 更直接地感知“这个具体情境要求什么”； - 经验已经改变什么线索会自动凸显； - 直觉判断不是无理由拍脑袋，而是长期situated experience压缩后的快速情境响应。

他们同时强调：

专家仍会在有时间时反思和推理，但反思的目标往往是改进直觉，而不是用规则永久替代直觉。

Source: - Dreyfus & Dreyfus, “Peripheral Vision: Expertise in Real World Contexts,” Organization Studies 26(5), 2005: https://journals.sagepub.com/doi/10.1177/0170840605053102

20.1 Rule Ceiling

这给我们一个新概念：

RULE CEILING / 规则上限

规则对： - novice onboarding； - common failure prevention； - vocabulary； - safety boundary； 非常重要。

但一个系统如果只训练：

“在什么条件下套什么规则”

可能把人长期锁在：

ADVANCED BEGINNER / COMPETENT RULE USER

而没有形成：

SITUATIONAL SALIENCE

即：

哪些线索在这个具体局面里应该自动变得重要。

20.2 Taste Training = Salience Training

因此游戏设计Taste培训，不只是：

多讲设计原则。

而是：

反复让新人面对真实artifact，并追问：你第一眼注意到什么？为什么？高手第一眼注意到什么？结果证明谁漏掉了关键线索？

这使：

ATTENTIONAL APPRENTICESHIP

进一步变成：

SALIENCE CALIBRATION

21. Lave & Wenger：学习不是“获得知识”，而是逐步获得真实参与资格

Lave与Wenger 1991提出：

LEGITIMATE PERIPHERAL PARTICIPATION / 合法边缘参与

学习者不是先在课堂里“完整学会”，再进入实践。

更常见的机制是： - 先以低风险、边缘但真实的角色参与； - 接触真实artifact、语言、人际关系、工具和标准； - 逐渐理解共同体“实际上在乎什么”； - 责任与访问范围不断扩大； - 最终移动到full participation。

Primary: - Jean Lave & Etienne Wenger, Situated Learning: Legitimate Peripheral Participation: https://www.cambridge.org/highereducation/books/situated-learning/6915ABD21C8E4619F750A4D4ACA616CD

这与一般“培训新人”最大的区别是：

Peripheral不等于Fake。

新人可以做简单任务， 但这些任务必须真正处在生产/创作共同体里， 并让他看见： - 完整产品怎样被讨论； - 老手怎样判断； - 自己的工作怎样影响最终结果。

22. 新概念：Legitimate Low-Stakes Reality

结合Reversible Bets与Lave/Wenger，新增：

LEGITIMATE LOW-STAKES REALITY / 合法低风险现实

新人最好的训练任务同时满足：

  1. Low Stakes
    错了不会毁掉大项目。

  2. Real Consequence
    结果不是课堂假题，真的有人使用/试玩/依赖。

  3. Visible Whole
    新人知道自己的局部怎样进入完整产品。

  4. Expert Proximity
    可以观察更强者怎样处理同类问题。

  5. Increasing Agency
    做对以后得到更大的问题权与决策权。

这比：

sandbox exercise

更强，

也比：

把新人直接扔进高风险核心任务

安全。

对游戏行业

高价值入口可能包括： - 小型真实关卡； - 小活动； - mod； - jam； - bounded prototype； - 支线系统； - 内部可玩实验； - 小规模live feature。

前提是：

新人不是只做“资产加工”，而是能看到判断→结果链。

23. 这给“大厂有没有培养原创人才”一个新的审计方法

过去容易按： - 公司名； - 项目规模； - 年资； - 职级；

推断人才质量。

Polanyi + Dreyfus + Lave/Wenger要求改问：

Practice Access

新人是否看得见真正的设计/产品判断过程？

Judgment Exposure

是否知道为什么A被选、B被杀，而不是只收到Jira任务？

Salience Calibration

有没有人指出他漏看了什么？

Consequence Contact

能否看到真实玩家、市场或工程结果？

Agency Escalation

是否从：

execute
→ choose between options
→ frame bounded problem
→ own prototype
→ own product decision

逐步升级？

所以：

YEARS IN INDUSTRY != YEARS OF JUDGMENT PRACTICE

一个人在大厂待8年， 如果8年主要是：

接feature需求 → 高质量执行

他的Production Capital可以极强， 但Selection Apprenticeship未必同样深。

24. AI Apprenticeship Paradox：AI可能同时扩大“边缘参与”和删除“边缘参与”

AI有两种完全相反的可能。

Path A — Access Expansion

过去新人无法独立碰的东西： - coding； - art； - research； - prototype；

现在借AI可以更早做出真实artifact。

这会提高：

LEGITIMATE PARTICIPATION ACCESS

即：

新人更早进入真实生产循环。

Path B — Experience Removal

但如果团队流程变成：

prompt
→ AI produces
→ senior approves

新人可能不再经历： - 分解问题； - 手动处理大量边界案例； - 观察局部错误； - 慢慢形成salience。

于是：

OUTPUT ACCESS ↑

同时：

EXPERIENTIAL DEPTH ↓

这就是AI时代真正需要测的矛盾：

AI究竟让新人更早进入实践，还是只让新人更早得到实践的输出？

两者完全不同。

25. Harry Collins：并非所有“Tacit”都是同一种东西

后续研究者Harry Collins尝试进一步区分 tacit knowledge。

其中至少有两个对AI讨论很有用的维度：

Somatic / embodied limits

某些能力和身体、感觉运动系统相关。

Collective tacit knowledge

某些“知道怎么做”并不只存在个人头脑，而嵌在一个社会共同体的规范、语言使用、默契与互动里。

Source: - Harry Collins, “Bicycling on the Moon: Collective Tacit Knowledge and Somatic-limit Tacit Knowledge,” Organization Studies 28(2), 2007: https://journals.sagepub.com/doi/10.1177/0170840606073759

这提醒我们：

AI是否能学会某项“隐性知识”，要先问它究竟是哪一种隐性。

有些只是： - 未被写下； - 写下成本太高；

AI通过大量行为trace可能学到相当多。

有些依赖： - 身体； - 长期社会参与； - 共同体内部不断变化的规范；

则不能因为LLM语言表现很好，就直接宣布问题已经解决。

26. “Expertise Capture”应该从文档工程升级成 Practice Observatory

如果目标是保存高级团队Taste， 组织真正应该建设的可能不是：

KNOWLEDGE REPOSITORY

而是：

PRACTICE OBSERVATORY / 实践观测层

最低记录： - artifact版本； - alternatives； -谁提出什么判断； - 哪些变量触发关注； - 哪些方向被杀； - 当时预测； - 实际结果； - 复盘时模型如何更新。

AI可以进一步： - 聚类反复出现的judgment pattern； - 找senior常见exception； - 把同类case调给junior； - 比较不同高手的salience差异； - 发现“团队嘴上原则”和实际选择不一致。

这比让模型读取1000页Design Bible更接近：

SELECTION FUNCTION OBSERVABILITY

27. 最终合并：创新能力的形成不是“自由”与“服从”二选一

现在可以把个人主义主线修正为完整生命周期：

LEGITIMATE PARTICIPATION
→ APPRENTICESHIP
→ TACIT INTEGRATION
→ SALIENCE CALIBRATION
→ BOUNDED DECISION RIGHT
→ JUDGMENT SOVEREIGNTY
→ REALITY CORRECTION
→ GENERATIVE MUTATION

因此：

没有前半段

容易产生：

没学会任何东西就宣称自己独立思考。

没有后半段

容易产生：

技艺很高，但永远只能复制师傅和旧组织。

真正创新体系需要：

TRADITION WITHOUT PERMANENT SUBMISSION

以及：

INDIVIDUALISM WITHOUT IGNORANT ANTI-EXPERTISM

这两个边界应当长期保留。
