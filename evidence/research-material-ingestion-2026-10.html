2. 截图摄取：按主题而非私人身份归档

58 张截图不作为 public evidence，全部只生成 A0-CHAT hypotheses。已分为以下主题簇：

S-A 商业游戏训练 vs indie objective function

Claims generated: - 商业训练可能更适合 exploitation； - premium small-team 需要 problem selection； - 作者性与完整 ownership 可能在专业分工中被压低。

Status: partially promoted through Sea/NExT/role-origin public cases.

S-B “执行主策化”

Generated: - 方向权可能集中在老板/制作人； - 主策/策划承担 specification/execution； - JD 可快速暴露 benchmark/职责边界。

Status: HYPOTHESIS. 尚无行业代表性数据，不得写“中国策划基本都没有设计权”。

S-C Physics / systemic gameplay

Generated: - 中国商业项目可能不是技术上不会 physics，而是长期缺乏把 simulation/emergence 当核心产品 substrate 的需求； - 成功品类出现后招聘会快速追随。

Status: HYPOTHESIS. 需历史 JD/产品样本验证。

S-D 数值卡牌韭菜 / value network

Generated: - “数值卡牌韭菜”只指玩家 cohort； - 高变现窗口反向塑造组织、岗位与职业训练； - 玩家 reference set 迁移速度可能快于生产制度。

Status: author-origin taxonomy + Christensen-compatible hypothesis；精确“不到八年”未证。

S-E 五代玩家 × 四代从业者

Promoted: - china-player-worker-generations-009.md Boundary: - 工作标签不是人口统计学客观 cohort； - 边界仍需平台/用户数据。

S-F 赛博地主 / 流量购买

Generated: - distribution-induced design convergence; - 平台/买量可能反向塑造产品。

Status: HYPOTHESIS，不能把“二流流量也得买”写成行业事实。

S-G NExT / 腾讯专家 / 0→1

Generated: - 腾讯主流 production regime 未必适合细分 0→1； - NExT 是内部反制度； - 高履历不等于 team tacit capital； - long-cycle prestige project 可能出现昂贵错误持续。

Promoted: - executive boundary evidence in note 008; - SYNCED evidence in note 011.

S-H Boundary / Tripwire

Generated: - Boundary 应与 Tripwire 等 niche multiplayer FPS production history 对照； - 技术 novelty ≠ sustainable multiplayer ecosystem； - 应审计 liquidity、community、content cadence、error persistence。

Promoted: - notes 011/012; - CASE-029 ledger upgrade.

S-I Gunfire Reborn

Generated: - 中国内部团队也可以走 premium/EA/系统复用路线； - 成功与主创 ownership span 相关。

Promoted: - T9 credits support high ownership span; - formative history still UNKNOWN.

S-J Black Myth / benchmark uncertainty / meritocracy

Generated: - 没有清晰 benchmark 在大多数商业项目里是合理危险信号，但对真正肥尾创新也可能是正常状态； - credential-based screening 可能系统性漏掉不可分类机会。

Status: HYPOTHESIS; “某员工因此离开 Game Science” identity unresolved.

S-K Game Science / Heroes / production-regime formation

Generated: - Game Science 不应编码为典型“腾讯手游团队”； - formative regime 更接近 client MMO； - 手游阶段是 adaptive regime； - premium 转型发生 deliberate unlearning。

Promoted: - note 013.

Not promoted: - “英雄互娱因为看不起/看衰所以急卖股”； - “渠道评级低”； 除非找到直接公开证据。

S-L “37岁腾讯前员工1700万存款仍焦虑”

Class: internet narrative / cultural anecdote.

Use: - platform capital / identity lock-in 的问题线索。

Boundary: - 未核原帖身份、资产与雇佣事实； - 不进入事实 Claim。
