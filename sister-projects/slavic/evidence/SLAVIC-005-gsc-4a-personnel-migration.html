SLAVIC-005 — GSC → 4A 核心人才迁移表

  • Type: Personnel / Capability Migration Ledger
  • Program: 《斯拉夫游戏英雄传说》
  • Status: ACTIVE — FIRST PASS
  • Primary question: 4A Games 的成立，到底迁移了哪些已经在 GSC 内形成的能力？

1. 研究意义

如果只写“几名 GSC 员工离职创办 4A”，会丢掉真正重要的生产事实：

离开的不是随机员工，而是一组可以重新组成完整产品生产核心的跨职能人才。

因此本文件把 4A 的成立视为一次 capability bundle migration：设计、引擎/程序、美术、组织经验与项目信誉同时迁移。

2. 已核核心人物

Andriy / Andrew Prokhorov

GSC role: - S.T.A.L.K.E.R.: Shadow of Chernobyl 核心项目/设计领导角色； - 多个来源称其为 lead game designer / project lead。

4A role: - co-founder； - 后续长期 creative director / project leadership。

Evidence: - Mezha 2026 interview with Prokhorov - https://mezha.ua/en/articles/andriy-prohorov-pro-s-t-a-l-k-e-r-metro-ta-kosmos-314120/ - GameDev DOU summary - https://gamedev.dou.ua/forums/topic/61348/

Evidence class: P1 direct participant + S1 summary

Oles Shyshkovtsov

GSC role: - 核心程序员； - 与 X-Ray / S.T.A.L.K.E.R. 技术体系密切相关。

4A role: - co-founder； - lead programmer / CTO； - 后续成为 4A Engine 技术核心之一。

Evidence: - GameDev DOU interview on S.T.A.L.K.E.R. engine programmers - https://gamedev.dou.ua/articles/developer-stalker-2-about-his-career-and-war/ - 4A / Metro technical retrospectives cited in contemporary coverage

3. 时间线修正

2004 — 独立意图已经形成

Prokhorov 2026 回忆称，他与 Shyshkovtsov、Maksymchuk、Tkachenko 在 2004 年已经决定未来离开 GSC 创办自己的工作室，并提前告知 Sergiy Grygorovych；他们仍承诺完成 S.T.A.L.K.E.R.，因为该项目对未来团队履历重要。

Source: - Mezha 2026 Prokhorov interview

Status: P1 direct recollection

Implication: - “2006 年因为一次工资争吵突然离职”的压缩故事不完整。

January–February 2006 — 裁员/成本削减成为加速器

Prokhorov 回忆，GSC 在 2006 年初决定裁减大量美术与动画人员，因为认为主要内容工作已接近完成。核心成员判断这些人一旦被裁将迅速流失，因此提前启动 4A、开办公室并吸收人才。

Source: - Mezha 2026 Prokhorov interview

Status: P1 direct recollection

Implication: - 4A 的成立至少包含“保全已经形成的团队能力”这一因素。

4. 能力迁移不是单点跳槽

最小迁移包已经覆盖：

  • 设计/项目判断：Prokhorov；
  • 底层技术/引擎：Shyshkovtsov + Maksymchuk；
  • 3D 内容生产：Tkachenko；
  • 共同 S.T.A.L.K.E.R. 项目经验：长期协作关系；
  • 对大型 PC 游戏生产流程的 tacit knowledge：不可从职位名完全观察，但明确随人员迁移。

这意味着 4A 的创立更接近：

一个已经在旧组织内部被训练出来的小型“产品核”脱离母体，自带跨职能能力资本重新组装。

Current status: SUPPORTED

5. 关于“技术继承”的边界

必须严格区分：

  1. 人员和经验继承 — VERIFIED / SUPPORTED；
  2. 技术思想与工程经验继承 — SUPPORTED；
  3. 直接复制 X-Ray 代码形成 4A Engine — CONTESTED / 不得写死。

Oles Shyshkovtsov 后来曾公开批评 X-Ray 在多线程、网络、资源管理和脚本体系上的限制，并否认 4A Engine 只是 X-Ray 改版。历史上存在相关争议，但不能因为人员来自 GSC 就自动推断源代码连续。

6. 组织裂变命题的修正

旧压缩说法

GSC 压榨员工 → 技术骨干集体造反 → 4A 成立。

当前更精确版本

核心成员早有独立意图；长期薪酬/royalty/管理矛盾形成背景；2006 年成本削减和人才裁撤风险成为触发器；一组已经完成协作磨合的设计—技术—美术骨干携能力资本退出，并迅速建立新的生产单位。

Current status: SUPPORTED

这仍然具有“劳工自组织”意义，但目前不应写成正式 unionization。

7. 还缺什么

必须继续核的人员

  • Sergei Karmalsky：在 GSC / 4A 之间的准确迁移时间与职责；
  • early Metro 2033 credits 中更多 GSC alumni；
  • 2006–2007 被 GSC 裁撤后进入 4A 的 artist / animator 名单；
  • 是否存在先兼职帮助 GSC 收尾、同时为 4A 工作的人员。

必须继续核的组织问题

  • 4A 创立后的工资、royalty、加班和决策制度是否真的显著不同；
  • GSC 方面对 2004–2006 冲突的完整版本；
  • THQ / publisher 对 4A 早期团队成形的影响；
  • Metro 2033 首作期团队峰值规模。

8. 当前判词

可以写：

4A Games 不是从零招人做 Metro，而是从 GSC 内部迁出了一套已经被 S.T.A.L.K.E.R. 长周期开发训练过的最小生产核心。这是一例典型的“能力资本从公司资产转化为劳动者可携带资产，再重新组织成新公司”的案例。

不能写：

  • 4A 就是工会起义；
  • 4A 复制了 X-Ray 代码；
  • 所有 4A 员工都来自 GSC；
  • 2006 年一次工资争吵是唯一原因。
